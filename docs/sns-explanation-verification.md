# SNS解説欄の検証（2026-09-17、ローカル変更）

## 実APIと目視確認

- 使用経路: 通常アプリ `http://127.0.0.1:5173/` のSTEP2 → STEP3 → STEP4。読込済みキャラクターシート2枚・5人を使用。文章はOpenAI gpt-6-astra、画像はGPT Image 2.5 Sunburst / xhigh、1024×1536。
- カテゴリ検索「科学・宇宙」: 「古代人も化石収集家？」を生成。解説は化石が古代住民に持ち込まれた**可能性**を保持し、創作の私室・博物館化・夢オチをニュースの事実として説明していない。出典URLを取得。ただし検索APIが返したリンクは省庁トップページで、個別記事への直リンクではなかった。
- 内容照合: [文化観光省の個別発表](https://engelsiz.ktb.gov.tr/TR-474238/66-milyon-yillik-fosil-bulundu.html)とも照合。年代と持込みの可能性は対応。画像の化石はアンモナイト状で、発見された巻貝の形状再現は合格扱いにしない。
- 自由入力（URLなし）: 名前の付箋がはがれたプリンをめぐる創作。「プリン一口の承認待ち」を生成。解説と画像は題材・人物関係に対応。参考リンク見出し・URLとも出力なし。創作の注意書きをユーザー指定により改行・丸括弧へ整形。
- URLありの自由入力: 入力URLだけを使う処理は自動テストで確認。今回はこの条件の追加実API生成はしていない。
- 絵の目視: 両作品とも俯瞰・アオリ・肩越し／斜めの構図があり、表情・手・身体の演技の変化を確認。全コマの完全な構図遵守や解剖学的無欠陥は保証しない。指定の全身ショットが脚先まで入らないコマもある。

## 内部QAラベル・実文字・採否の区別

- カテゴリ画像は既存設定の自動修正ONで初回＋修正候補1枚を生成。比較後に元画像が警告付きで採用された。内部QAの「ミクの眼鏡」指摘は、元画像の目視では明瞭な眼鏡を確認できず、指摘だけで画像欠陥と断定しない。
- 自由入力は追加課金の自動修正をOFFにして画像1枚を生成。内部QAの `surface_text` / `prop_orientation` の未確認はレビュー記述不足のラベルで、画像にその英単語が印刷されたわけではない。元画像が警告付き採用。
- 最終UIの自動修正はOFF、品質・サイズ項目は閉じた状態。モデル・品質・サイズは変更していない。
