# PDF skill distribution boundary

The app's PDF manuals are separate from the optional developer PDF skill.
The `anthropics/skills` PDF skill is not bundled with this app or installed from
the shared `skills-lock.json`. Its upstream notice is proprietary and refers to
separate terms; this project does not grant permission to redistribute it.

Existing local installations may be retained separately while their permission
is reviewed. They must remain untracked. The ignore rule, archive exclusion and
pre-deploy source check prevent accidentally publishing them again.

Source reviewed: [upstream terms at the audited revision](https://github.com/anthropics/skills/blob/8a1541c4a3ffa5a20a5a91de0dcf3f0bab1d1ef4/skills/pdf/LICENSE.txt).
This change does not alter the app's license, third-party rights, existing Git
history, published releases, or generated PDF manuals. Previously published
copies require a separate review; a future release cannot remove past copies.
