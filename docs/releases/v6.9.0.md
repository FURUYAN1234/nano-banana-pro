# Super FURU AI 4-koma System v6.9.0

## 日本語

- 上部の固定枠に「全行程強制ストップ」を追加しました。STEP1～4、画像修正、全自動・ループのAPI通信と後続処理を停止し、取得済みの文章・画像を保持します。送信済み処理の費用は取り消せません。
- STEP2再生成後はSTEP3、STEP3再構築後はSTEP4、画像生成後は修正ボタンを点滅させ、次の操作を案内します。以前の画像が残っていても、新しいプロンプトに対するSTEP4を案内します。
- ChatGPT Web用の貼り付け手順・コピー・TXT保存・制作情報JSONを、薄いオレンジ・黒文字の折り畳みにまとめました。API画像生成ボタンは外から操作できます。
- STEP3がVisualEvidence欄を人物名として扱い、看板の文字を余分な台詞へ数える不具合を修正しました。看板文字は視覚描写に保持し、吹き出し配置の件数・話者・順序チェックは維持します。
- READMEと全機能・Gemini APIマニュアルを更新しました。生成画像には検査の未確認項目が残る場合があるため、公開前の目視確認は引き続き必要です。

## English

- Added a fixed-header Force Stop control for STEP1–4, image repair, full-auto and loop mode. It aborts current API communication and automatic continuation while retaining received text and images. Submitted provider work may still be billed.
- Pulse the next action after STEP2, STEP3 and image generation. Rebuilding a prompt points to STEP4 even when an earlier image remains available.
- Grouped ChatGPT Web paste instructions, copy buttons, TXT saving and production JSON inside an initially collapsed pale-orange control with black text. API image generation remains outside it.
- Fixed STEP3 treating VisualEvidence as a speaker and counting quoted sign text as extra dialogue. Scene evidence remains in visual action; strict balloon count, speaker and order validation stays active.
- Updated the README and full-operation/Gemini manuals. Generated images still require visual inspection when review evidence remains incomplete.
