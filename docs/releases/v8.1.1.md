## Changes / 変更点

- Watermarks are off by default in the public app and new MCP projects. STEP3 remembers the manual choice in the current browser. / 公開版では初回のウォーターマークをオフにしました。手動作画の選択はブラウザーに保存します。MCP制作では作品やページごとに指定できます。
- Role labels are rendered as in-scene lettering. / 役名札を画面内の文字として扱い、吹き出しに混ざる不具合を修正しました。
- The production skill checks original sources, character gaze, and coverless bylines, and explains how to redraw a page from accepted materials. / 制作スキルに、原典・視線・扉絵のない場合の作者名と、採用資料からページ全体を描き直す手順を反映しました。
