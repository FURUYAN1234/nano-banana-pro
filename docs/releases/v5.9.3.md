# Nano Banana Pro v5.9.3

### 日本語

- Hugging Faceへの配布ZIP送信を修正しました。10 MB未満のZIPも通常Gitでは拒否されたため、現存するすべての配布ZIPにGit LFSを適用します。
- 未公開の失敗コミットはローカルの復旧用ブランチに保持し、リモートの公開履歴を基点に再構築します。公開済み履歴の強制書換えは行いません。
- READMEの現行バージョン表記を同期しました。アプリの機能、配布ZIP、ワークフローJSONの内容は変更しません。

### English

- Fixes distribution ZIP uploads to Hugging Face. The Hub rejected regular Git ZIP binaries below 10 MB, so every current distribution ZIP now uses Git LFS.
- Preserves unpublished failed commits on a local recovery branch and rebuilds from remote history without force-pushing published history.
- Synchronizes current-version README text. App behavior, distribution ZIP contents, and workflow JSON contents are unchanged.
