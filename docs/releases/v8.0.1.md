# v8.0.1

The app ZIP now starts from `start_app.bat` at its root, forwarding to the shared Windows launcher. The skill ZIP uses `Launch-Manga.cmd` beside `SKILL.md`; both support the same installed app and Desktop shortcut. / アプリZIPは直下の`start_app.bat`から共通ランチャーを呼び出します。スキルZIPは展開先の`SKILL.md`と同じフォルダーの`Launch-Manga.cmd`を使い、どちらも同じ導入済みアプリとデスクトップのショートカットを利用できます。

README and the full manual explain asking Codex to extract and install the complete skill ZIP, separately register MCP, reload settings and confirm the tools. Downloading a ZIP alone does not activate a skill. Ordinary single-page use needs neither the skill nor MCP control permission. / READMEと全機能マニュアルに、CodexへZIPの展開・スキル一式の導入・別途MCP登録を依頼し、設定の再読込後にツールを確認する手順を記載しました。ZIPの取得だけでスキルは有効になりません。通常の1ページ制作にはスキルもMCP操作許可も不要です。

MCP production functionality remains the v8.0.0 feature set. / MCPの制作機能はv8.0.0と同じです。

The Windows entry uses a process-scoped PowerShell execution policy for its bundled bootstrap, allowing the official downloaded launcher to run with its download-zone attribute. System/user policies and the registry are unchanged; group policy still takes precedence. Release digest validation remains in place. / Windowsの入口では、同梱bootstrapを実行するPowerShellプロセスだけに実行ポリシーを指定し、ダウンロード属性による起動停止へ対応しました。システム・ユーザー設定やレジストリは変更せず、組織のグループポリシーが優先されます。配布物のハッシュ検証は維持します。
