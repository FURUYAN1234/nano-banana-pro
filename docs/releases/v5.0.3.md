# Nano Banana Pro v5.0.3

## 日本語

- 最終プロンプトを STEP 4 画面で直接編集できるようにし、編集内容をコピーと OpenAI / Gemini の画像生成へ同じまま渡すようにしました。
- OpenAI の画像ストリームが最終イベント前に切断した場合でも、すでに受信した有効な途中画像を表示して生成結果を失わないようにしました。
- 内蔵ブラウザで、ランダムシナリオ生成から直接手修正を経た OpenAI `gpt-image-2` と Gemini `gemini-3.1-flash-image` の画像生成を確認しました。

## English

- The final prompt can now be edited directly in STEP 4, and the edited content is used unchanged for copying and OpenAI / Gemini image generation.
- If an OpenAI image stream disconnects before its final event, the app now renders an already received valid partial image instead of losing the generated result.
- In-app-browser verification completed random scenario generation, direct prompt editing, and image generation with OpenAI `gpt-image-2` and Gemini `gemini-3.1-flash-image`.
