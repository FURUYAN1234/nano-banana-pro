# Super FURU AI 4-koma System v7.0.3

## 日本語

- 元の4コマ台本から、AIが内容に合う5〜8コマと配置を選ぶ「実験的コマ割り」を追加しました。初期設定はOFFです。ONにすると詳しい説明を表示し、次のSTEP3で実験用の指示文を別に作ります。
- 横長の見せ場、大小のコマ、縦のぶち抜き、動作のつながりや無言の間などを場面に合わせて指示します。生成は通常と同じSTEP4を使い、保存・履歴・全自動・Web貼り付け用コピーも共通です。元台本と設定が同じ場合、OFFへ戻すと保存済みの4コマ用指示へ戻ります。
- 実験モードでは画像の自動修正を行いません。未確認や作品が成立する軽微な違い、任意演出の欠落だけでは再生成しません。人物を同定できない場合は未確認として扱い、明確な欠陥は別項目の未確認で取り消しません。
- 同じ準備案で作り直した候補は、観察・台詞転記の結果も使って比較します。比較できない場合や改善が確認できない場合は前の選択画像を保持し、取得した画像は直近10件の履歴に残します。検査・比較にもAPI料金がかかります。
- 開発画面で大きな画像履歴がReactの診断情報として複製され、検査中に画面が停止する問題を修正しました。画像・履歴を縮小せず、開発用診断の情報量を制限します。
- READMEとPDFマニュアル3冊の操作説明・版表記・目次を更新しました。AIの検査や候補比較は誤る場合があります。台詞・読む順番・人物・カメラや画風は、利用前に実画像で確認してください。

## English

- Added an optional experimental layout that adapts the original four-panel script into 5–8 panels chosen to fit the story. It starts OFF. Turning it ON opens the detailed explanation; the next STEP3 prepares a separate prompt.
- The layout can use wide highlights, varied panel sizes, tall panels, connected actions and silent beats when appropriate. It uses the usual STEP4, save controls, history, automatic workflow and Web-copy controls. Turning it OFF restores the saved four-panel prompt when the source script and settings still match.
- Experimental mode does not automatically repair images. Uncertainty, harmless differences or absent optional effects alone do not cause regeneration. Uncertain character identity remains unverified, while uncertainty in another check does not erase a supported defect.
- Repeated runs compare candidates using their observations and dialogue transcriptions. If comparison is unavailable or improvement cannot be established, the prior selection is retained and acquired images enter the ten-entry history. Review and comparison also incur API charges.
- Fixed development-screen freezes caused by React cloning large image histories into diagnostic details. Only development diagnostics are bounded; image and history contents are preserved.
- Updated the README and three PDF manuals, including instructions, version labels and the table of contents. AI review and candidate comparison can be wrong. Inspect dialogue, reading order, characters, camera angles and drawing style in the actual image before use.
