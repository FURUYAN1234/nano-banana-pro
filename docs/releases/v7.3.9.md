# v7.3.9 — Action staging and diagnostic recovery / アクション演出と調査ログの改善

- Action endings now ask for large, readable bodily movement on ordinary news topics while preserving reported facts, speakers and dialogue. Ordinary endings may also include a dynamic panel when the scene supports it, without a fixed quota. / アクション選択時は、一般的なニュースでも、事実・話者・台詞を保ちながら踏み込みやひねりなどの大きな身体演技を設計します。通常の結末にも場面に合う動きを許可し、必須コマ数は設けません。
- Scenario review checks both visible action intensity and the selected action payoff. A weak payoff enters a bounded staging repair that preserves spoken dialogue. / 台本検査で動きの強さとアクションの結末を別々に確認し、弱い場合は台詞を保つ演技・配置の修正へ送ります。
- STEP3 balloon-layout recovery now carries through accepted quality warnings while still rejecting malformed dialogue and panel structures. / STEP3の入口と吹き出し配置修復で警告の扱いを統一しました。壊れた台詞構文やコマ構造は引き続き拒否します。
- Failed-run diagnostic JSON retains the original scenario, cast, input, drawing instructions and repair/review evidence after reload. Known credentials and image bodies are excluded; text caps and omissions are explicit. Sharing the JSON shares its retained creative text. / 失敗時の元台本・人物設定・入力・描画指示・修復／検査内容を、リロード後も調査JSONから確認できます。既知の認証情報と画像本体は除外し、文字数上限による省略を明記します。共有すると作品の文章も相手へ渡ります。
- Image quality review uses the model selected for STEP1. README and all three PDF manuals have been updated. / 画像品質検査にもSTEP1の選択モデルを使用します。READMEと3冊のPDFマニュアルを更新しました。

Validation / 検証：2,172 tests, lint, build and built web security verification passed. Normal UI tests used GPT-6 Luna without fallback and GPT Image 2.6 Sunburst at max, 2240×3168. Actual STEP3 recovery, invalid-input rejection and failure-input persistence after reload were verified. / 自動テスト2,172件、lint、build、生成済みWebファイルのセキュリティ検査に合格しました。通常画面からLuna・フォールバックなしとSunburst・maxで検証し、STEP3の修復、異常入力の拒否、リロード後の元入力保持を確認しました。

The six-panel color news Action and four-panel monochrome SeriousAction images completed the standard inspection and single correction path. Final movement, dialogue, speaker correspondence and corrected framing were visually inspected. Initial automated uncertainties remain recorded; no post-repair API PASS is claimed. / ニュース題材のカラー6コマと白黒4コマを通常の検査・修正経路で生成し、修正後の動き、台詞、話者、構図を目視確認しました。初回の自動検査で残った未確認項目は記録に残し、修正後のAPI全面合格とは扱っていません。
