## Nano Banana Pro v5.7.4

### 日本語

- 2026-09-03提供の最新版配布ZIPへ、MiniMax H3のワークフローと4つのカスタムノード一式を差し替えます。
- ワークフロー読込時とProvider変更時にはAPI入力ダイアログを開かず、登録状態だけを更新します。
- Execute／Queueを押した時、ノードで選択中のProviderが未登録ならキュー投入を保留して、そのProviderの入力ダイアログを開きます。認証成功後は保留中の同じ実行を1回だけ続け、ダイアログを閉じた場合は今回の実行だけを中止します。
- APIキーは動作中のComfyUIサーバープロセスのメモリだけに保持します。ワークフローのシート移動や別ワークフローへの切替では残り、ComfyUI終了・再起動で消去されます。
- APIキーをワークフローJSON、配布ZIP、設定ファイル、ブラウザ保存領域、ディスク、ログ、状態表示へ保存・記録しません。認証確認または実行時だけ、ComfyUIサーバーから選択したAPIへ送信します。
- APIセキュリティREADMEとワークフロー作成・検証PC用手順を配布ZIPへ同梱し、STEP4、README、全公開ワークフロー、プロジェクト規約、回帰テストを同じ仕様へ同期します。
- 実行取消時はComfyUIの現在のキューAPI契約に合わせて `false` を返し、認証済みの場合だけ元の実行をそのまま呼び出します。

### English

- Replaces the MiniMax H3 workflow and all four bundled custom-node packages with the latest distribution ZIP supplied on 2026-09-03.
- Loading a workflow or changing Provider only refreshes registration status and never opens the credential dialog.
- On Execute/Queue, an unregistered selected Provider pauses queue submission and opens its dialog. Successful verification resumes that same run once; closing the dialog cancels only that run.
- API keys live only in the running ComfyUI server process memory, survive workflow-sheet or workflow changes in that process, and disappear when ComfyUI exits or restarts.
- Keys are never stored in workflow JSON, the distribution ZIP, configuration files, browser storage, disk, logs, or status text. They are sent from the ComfyUI server to the selected API only for validation or execution.
- Synchronizes the bundled security README, author-PC guide, STEP4, README, every public workflow, project policy, and regression coverage with this contract.
- Cancellation returns `false` to match the current ComfyUI queue API contract; the original queue operation is invoked unchanged only after credentials are ready.
