# Super FURU AI 4-koma System v6.9.2

## 日本語

- 説明文中の引用を台詞に数えてSTEP3が止まる不具合を修正しました。吹き出し配置の不整合は、台詞・状況・カメラを保持してAIが配置だけを修復します。
- プロンプト精査と画像精査の返答形式が壊れた場合、AIが同じ入力で形式を修復します。不明な点を合格と扱わず、重大な欠陥が確認できない画像は保持します。
- 全行程強制ストップが、参照画像付き生成と画像ストリームの受信待ちにも作用するよう修正しました。停止後の古い応答を採用せず、取得済みの成果を残します。
- Gemini画像生成をNano Banana 2.1 (`gemini-nano-banana-2.1`) のInteractions APIへ更新し、Model Chainと料金表示を同期しました。2026-10-07の公式参考単価は1K画像$0.0336／枚、入力$1.50・テキスト／思考出力$7.50／100万トークンです。API料金は別途かかります。

## English

- Fixed STEP3 counting quoted action prose as dialogue. AI repairs inconsistent balloon layouts while preserving dialogue, action and camera instructions.
- Malformed prompt and image review responses now receive an AI format-repair request using the same input. Unknown evidence is not treated as a pass, and images without confirmed material defects are retained.
- Force Stop now interrupts reference-image generation and pending image-stream reads, discards stale responses and preserves acquired work.
- Migrated Gemini images to Nano Banana 2.1 (`gemini-nano-banana-2.1`) through the Interactions API, with synchronized Model Chain and prices. Official reference prices as of 2026-10-07 are $0.0336 per 1K image, $1.50 input and $7.50 text/thinking output per million tokens. API usage is billed separately.
