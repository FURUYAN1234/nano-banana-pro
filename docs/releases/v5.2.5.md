# Nano Banana Pro v5.2.5 - Content-Aware Manga Titles and Safer Image Generation / 内容連動タイトルと画像生成安定化

## 日本語

- STEP2で生成した漫画タイトルへ一律に `!?` を付ける処理を廃止しました。末尾記号なし・`!`・`?`・`!?` のいずれも、タイトルの内容に応じた生成結果をそのまま保持します。
- キャラクター設定に含まれる学校・未成年連想語、幼い体型表現、過度に生々しい身体表現を、成人キャラクターとして安全な画像指示へ汎用的に正規化します。
- OpenAI画像生成では公式の低強度モデレーション設定を明示し、安全拒否の判定、開発時リフレッシュ中のAPI接続保持、キー欠落時の再入力導線を改善しました。APIキー自体は保存しません。
- 通常のSTEP2→STEP3→STEP4経路を実APIで検証しました。新規題材からタイトル「商店街福引で大誤算」を生成し、13,363文字の本番プロンプトを `gpt-image-2` へ1回送信して、商店街・巨大な熊のぬいぐるみ・成人会社員5人を描いた1024×1536の4コマ画像が完成することを確認しました。

## English

- Removed the unconditional `!?` append from STEP2 manga titles. Titles now retain the generated ending: no punctuation, `!`, `?`, or `!?`, according to the content.
- Generically normalizes school/minor-coded traits, childlike body wording, and overly biological anatomy wording into adult-safe image instructions.
- Explicitly uses OpenAI's supported low moderation setting for image generation and improves safety-rejection detection, in-memory API connection continuity during development refreshes, and the re-entry path when a key is missing. API key values are not persisted.
- Verified the normal STEP2→STEP3→STEP4 real-API path. A fresh topic produced the unpunctuated title `商店街福引で大誤算`; one 13,363-character production prompt sent to `gpt-image-2` completed a 1024×1536 four-panel manga depicting an arcade lottery, a giant teddy bear, and five adult office workers.
