## Nano Banana Pro v5.5.0

### 日本語

- STEP4のMiniMax H3・ComfyUI用コピーを専用の最新プロンプト定義へ統一しました。
- 会話音声を優先し、字幕と既定BGMを使わず、指定話者だけが口を動かすよう指示します。
- ComfyUIでは4コマ漫画を `ref_image_0` だけへ接続し、16:9・0.4MP・`normal` schedulerから開始する案内を追加しました。
- 既存のタイトルとクレジット表示を維持し、参照画像の重複接続を避けます。

### English

- Unified the STEP4 MiniMax H3 / ComfyUI copy action on one dedicated current prompt definition.
- Prioritizes intelligible dialogue, omits subtitles and default BGM, and restricts lip movement to the named speaker.
- Documents the ComfyUI starting setup: connect the manga only to `ref_image_0`, use 16:9 at 0.4MP, and select the `normal` scheduler.
- Preserves the existing title and credit rendering while avoiding duplicate reference-image connections.
