# Super FURU AI 4-koma System v7.4.8 / 更新内容

- Full-auto resumes the unfinished STEP using the retained scenario and prompt, including progress made manually. Interrupted API requests restart that STEP. / フルオートを再度ONにすると未完了のSTEPから再開し、手動で進めた台本・プロンプトも引き継ぎます。停止したAPI通信は、その工程を再実行します。
- STEP2 retries preserve the topic, input mode and panel-selection settings. Interrupted STEP1 reuses its retained input files. A completed work and each endless-loop round start a new news-based scenario. / STEP2の再開では題材・入力方式・コマ構成の選択を保持し、STEP1では保持中の入力ファイルを再解析します。1作品の完了後と連続ループの次周回は、新しいニュース作品を始めます。
- Force Stop still cancels pending requests and rejects late responses. Full-auto cannot start a competing request while manual generation is active. / 強制ストップによる通信の中断と遅延応答の破棄を維持し、手動処理の実行中にはフルオートの別処理を重ねて開始しません。
- Long image corrections share composition-preservation rules across the affected panels, retaining each defect, correction and the complete approved content within the request budget. / 複数コマの画像修正では構図保持の共通ルールをまとめ、各指摘・修正内容と承認済み全文を保ったまま送信上限に収めます。
- Pixel-grounded composition failures reach image repair even if the review omits a correction entry. Foreground repairs retain the named character, source and receiving panels, and the continuous-body crossing instruction. / 画像上の根拠がある構図不合格は、検査回答の修正一覧に抜けがあっても修正へ渡します。前景修正では人物名・元コマ・重ね先と、同じ身体を連続させる越境指示を保持します。
- Composition corrections take precedence over local repairs. Preserve panel topology while allowing the targeted whole figure, silhouette and specified bleed margins to change. / 構図修正を局所修正より先に示し、コマの並びを保ちながら対象人物の全体位置・輪郭と指定タチキリの余白を変更できるようにしました。
- Foreground repair identifies source and receiving frame coordinates and the connecting edges. Compact balloon-tail instructions retain exact speech, observed head positions and safe routing constraints. / 前景修正では元コマ・受入コマの座標と接続する辺を指定します。吹き出しの尾は、台詞全文・観察した頭の位置・経路の条件を保って修正説明を短くしました。
- Missing-actor repair names the actors to restore and permits minimal spacing changes so their heads and bodies are visible, preserving existing identities and counts. / 欠けた人物を名前付きで追加する指示を先に示し、既存人物の人数・同一性を保ちながら、頭と身体が見える場所を確保できるようにしました。
- Updated control descriptions, diagnostic specifications, README and PDF manuals. Work state is kept only in the current page session; reloading does not restore it. / 操作説明・調査ログの仕様要約・README・PDFマニュアルを同期しました。作業状態は現在の画面内で保持し、再読み込み後の復元には対応していません。
