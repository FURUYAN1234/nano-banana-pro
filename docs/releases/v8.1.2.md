## Changes / 変更点

- Edit the bottom-left and bottom-right watermark text independently in STEP3. Both fields start with the existing FURU and generation credits. Each field accepts one line up to 80 characters. Leave a field empty to omit that side. / STEP3で左下と右下のウォーターマークを個別に編集できます。初期文言は従来のFURUクレジットと生成情報です。各欄は1行・最大80文字で、空欄にした側は表示しません。
- MCP projects can set the footer text for the whole work or override it for an individual page. Title, author credit and page number retain their own settings. / MCPでは作品共通またはページ単位で文言を設定できます。題字・作者名・ページ番号は個別に設定できます。
- The manga production skill now specifies how to read all finished panels in order, check speakers, events, characters and props across pages, and make a local lettering correction when the drawing can be kept. / 漫画制作スキルに、完成した全コマを読順で通読し、話者・出来事の順序・人物や小道具のつながりを確かめる手順を反映しました。絵を保てる場合は、誤りのある文字だけを直す判断も加えています。
