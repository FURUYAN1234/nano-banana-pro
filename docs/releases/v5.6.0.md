## Nano Banana Pro v5.6.0

### 日本語

- MiniMax H3専用配布ワークフローを、Turbo v4 LoRA・強度1.0・Euler・Beta・8 stepsのJSONへ差し替えました。
- 標準テンプレート向けコピーメニューを添付の改訂文と全文一致させ、各コマの `panel_cast[N]` と識別署名を入力漫画から動的に導出する仕様へ更新しました。
- 専用ワークフローではタイトルをH3へ描かせず、`overlay_title` として抽出して動画生成後に一度だけ合成します。標準テンプレート用コピー文ではShot 1のタイトル仕様を維持します。
- 標準版とTurbo LoRA版で共通の `ComfyUI-NanoBanana-H3` ZIPへ更新し、API選択肢をOpenAI APIまたはGoogle Gemini APIに統一しました。
- APIキーは配布物へ含めず、当時のカスタムノードには資格情報のファイル保存があることを明記しました。この旧保存仕様はv5.7.3で廃止されています。

### English

- Replaced the dedicated MiniMax H3 distribution workflow with the Turbo v4 LoRA JSON using strength 1.0, Euler, Beta, and 8 steps.
- Replaced the standard-template copy instruction with the supplied revised text and added panel-derived `panel_cast[N]` and immutable identity signatures.
- Kept the Shot 1 title for the standard template while the dedicated workflow extracts `overlay_title` and composites it once after H3 generation.
- Updated the shared `ComfyUI-NanoBanana-H3` ZIP for both routes and limited API choices to OpenAI API or Google Gemini API.
- Documented that API keys were excluded from the distribution and described the credential-file behavior present in that older custom node. v5.7.3 removes that legacy persistence behavior.
