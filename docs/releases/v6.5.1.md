# Nano Banana Pro v6.5.1

## 日本語

- 自由入力では、ユーザーが入力した題材または取得に成功したURL本文だけを物語材料として扱います。入力方式名、UIラベル、内部プレースホルダー、前回題材、ニュース専用の日付・鮮度規則は題名・台詞・メタデータ・SNS解説へ入りません。
- 改善回数を使い切っても作品を失敗終了にせず、比較済み候補のうち最良のものを保持します。その後、原文にない内部ラベルだけを決定的に除去し、もう一度検査します。
- 原文自体に同じ語が含まれる正当な題材は変更しません。
- 内部で確定した結末種別をSTEP2とSTEP3の正本にし、文章モデルが返した非互換なオチ名で上書きしません。
- 静寂型（シュール）は、物・設備・舞台の破壊、因果の飛躍、支離滅裂、不条理な画面変化を、後付け説明なしで許可します。説明や標語だけで終わる出力は引き続き不合格です。
- 自由入力、ニュース経路、最良候補保持、決定補正、結末固定、SNS解説、シュール判定を汎用回帰で固定しました。

## English

- Free-input mode now treats only the supplied subject or successfully retrieved URL content as story material. Input-mode names, UI labels, internal placeholders, prior-session topics, and news-only date/freshness rules cannot leak into titles, dialogue, metadata, or SNS copy.
- Exhausting bounded improvement attempts no longer aborts the work. The system keeps the highest-scoring reviewed candidate, removes only leaked internal labels that were absent from the source, and validates the result again.
- Legitimate source material containing the same words remains unchanged.
- The internally resolved ending mode is authoritative across STEP2 and STEP3; an incompatible punchline label returned by the text model cannot replace it.
- Surreal mode may use destruction, causal leaps, incoherence, and absurd visual change without retroactive explanation. Explanation-only or slogan-only endings still fail.
- Generic regressions cover free input, news routing, best-candidate retention, deterministic repair, ending authority, SNS copy, and Surreal evaluation.
