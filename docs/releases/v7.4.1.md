# v7.4.1 — Preserve the scripted camera in STEP3 / STEP3で台本のカメラを保持

- Keep the original camera from the script when building a 5–8-panel layout. If a layout reply proposes a different shot, retain the original staging in that panel so an unnecessary camera rewrite no longer stops STEP3. / 5～8コマの配置を組み立てる際、台本のカメラをアプリが直接引き継ぎます。配置案が別の撮影を返したコマは元の状況も保持し、カメラの書き換えによるSTEP3の停止を防ぎます。
- When a camera direction rejects one angle and chooses another, use the chosen angle for projection. Preserve panel order, dialogue mapping and drawing style. / カメラ指定がある角度を否定して別の角度を選んだ場合は、選ばれた角度で描画指示を組み立てます。コマ順・台詞の対応・画風は保持します。
- Rejected layouts retain their response and validation reason in the diagnostic JSON, subject to its existing redaction and size limits. / 拒否した配置案は、応答と検査理由を不具合調査JSONに保存します。既存の秘匿処理と容量上限は維持します。

Validation / 検証：The normal STEP3 screen sent one GPT-6 Luna request without fallback, then retained all six panels and ten dialogue entries in order. Regression tests exercised a camera rewrite and rejected a mismatched dialogue mapping. / 通常画面からGPT-6 Lunaをフォールバックなしで1回呼び出し、6コマと台詞10件が元の順番で揃うことを確認しました。回帰テストでは配置案のカメラ書き換えを再現し、台詞の対応が不正な案は拒否しました。
