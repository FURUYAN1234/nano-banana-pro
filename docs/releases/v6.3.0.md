# Nano Banana Pro v6.3.0

- ブラウザーの保存先フォルダーへ書き込む完成画像の自動保存を撤去しました。品質確認後の最終採用API画像は、現在のブラウザーセッション内で直近10件の生成履歴へ残り、任意の履歴画像をプレビューへ戻して従来どおり手動ダウンロードできます。保存先の選択やDownloadsフォルダーへの書き込み権限は不要です。 / Removed automatic final-image writing to a browser-selected folder. Quality-selected API images remain in the current browser session's ten-item history; select any history image to restore its preview and download it manually. No destination selection or Downloads-folder write permission is required.
- 強い遠近感は、物語上の見せ場に合う手・顔・重要な小道具・環境の奥行きから焦点を選びます。足だけを前景へ突き出す構図を既定にせず、走る・踏み込む・蹴るなど脚自体が見せ場のときだけ、支持脚と重心を読める短縮遠近法を使います。明示されたCamera/Action、台詞、人物、小道具は保持します。 / Strong perspective now chooses a story-relevant focal form—hand, face, key prop, or environmental depth—instead of defaulting to a foreground foot. A foreshortened foot is used only when the scripted leg action itself is the focal beat, while explicit Camera/Action, dialogue, cast, and props remain preserved.
