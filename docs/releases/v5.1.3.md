# Nano Banana Pro v5.1.3 - Retry-Free Generation / 自動再試行停止

## 日本語

- STEP2のシナリオ生成は、検証失敗時に同じ入力で裏側のAPI再生成を行わず、失敗した検証コードをそのまま表示して停止します。
- `BackgroundAvoid` の禁止語を、実際に描かれる背景の危険判定から除外し、禁止指定そのものによる誤った `background_unsafe` を防ぎます。
- 動的背景設計・シナリオ本文の検証エラーを、通信タイムアウトではなく具体的な日本語案内として表示します。
- STEP4は受信した画像を直ちに表示し、隠れた視覚QAや自動再生成を実行しません。

## English

- STEP2 now stops after one scenario request and shows the concrete validation code instead of silently issuing another API request.
- `BackgroundAvoid` prohibitions no longer trigger false `background_unsafe` results for the pictured setting.
- Dynamic-background and scenario-content validation failures now show specific Japanese guidance rather than a network-timeout message.
- STEP4 renders the received image immediately and does not run hidden visual QA or automatic regeneration.
