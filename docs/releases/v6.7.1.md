# Nano Banana Pro v6.7.1

## 日本語

- STEP2で推論モデルの思考分まで含めて出力上限へ達した場合、空応答として別モデルへ回さず、未完了の理由を表示して停止するよう修正しました。推論モデルは32,768トークン、旧モデルは8,192トークンの上限を使います。
- 入力検証、認証、権限、モデル、利用枠、レート制限、時間切れ、ネットワーク、APIサーバー、空応答、応答形式、内部処理を区別してエラーを表示します。
- API生成画像の下に追加指示欄を追加し、OpenAIとGeminiのどちらでも表示中の画像を1回修正できます。元画像と修正版は生成履歴から選び直せます。
- 修正版は表示前にA4比率を確認します。正しい比率なら再処理せず、ずれた場合だけ自動補正します。

## English

- Fixed STEP2 completion handling so reasoning models that reach their combined reasoning-and-text ceiling stop with an explicit incomplete reason instead of being treated as empty output and falling through to another model. Reasoning models use a 32,768-token ceiling; legacy models retain 8,192.
- Split error messages by input validation, authentication, permission, model, quota, rate limit, timeout, network, API server, empty response, response format, and internal processing causes.
- Added post-generation image instructions for both OpenAI and Gemini. The displayed image can be edited once per submission, while the source and edited result remain selectable in history.
- Edited pages are checked before display. Correct A4 pages pass through unchanged, while only off-ratio results are normalized automatically.
