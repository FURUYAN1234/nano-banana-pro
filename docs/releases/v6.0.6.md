# Nano Banana Pro v6.0.6

## 日本語

- 黒い画像生成実行ボタンの表示を「画像を生成する（STEP 4）」だけに簡潔化しました。
- モデル・品質・サイズは、その下の白い「API生成時の品質・サイズ」ボタンだけに表示します。
- 白い設定ボタンの選択内容表示と、選択変更への即時追従はv6.0.5から引き続き利用できます。

## English

- The black image generation button now shows only “Generate image (STEP 4).”
- Model, quality, and size details appear only on the white API quality and size settings button below it.
- The settings summary still updates immediately whenever the selected quality or size changes.
