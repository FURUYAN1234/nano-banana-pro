# v6.8.2 — Document quotations and shoulder-view identity

## English

Fixed STEP3 treating a quoted document passage followed by wording such as “という記述” as an extra character line, which incorrectly stopped valid BalloonLayout input. Genuine spoken or read-aloud dialogue and strict balloon validation remain; mismatch reports now identify the panel and reason without assuming the input is at fault.

Registered aliases now identify the same person across shoulder-view direction, tail endpoints and cast count. Unresolved names no longer select a different person from dialogue order, and camera position no longer determines prop ownership. Scripted gaze, camera, acting and focal depth remain authoritative. Local anatomy edits explicitly preserve perspective, head turn, gaze, expression, focus and linework while repairing connected form.

Validation: 1,144 local tests, lint and production build passed. The reported source scenario completed STEP3 and API image generation. A separate malformed-head result required three local edits; the accepted edit uses natural rear-view occlusion while retaining the shoulder-view composition. The first two edits were insufficient. AI drawing and automated QA remain fallible; retained warnings are not an all-details pass.

## 日本語

「という記述」などで示した資料の引用を余分な台詞と誤認し、正しいBalloonLayoutでSTEP3が停止する不具合を修正しました。実際の発話・音読と厳密な配置検証は維持し、不一致ではコマと理由を表示します。

肩越しの人物・吹き出しの尾・登場人数で登録済みの別名を同一人物として扱い、名前を解決できない場合に台詞順から別人を割り当てる処理を修正しました。小道具の操作者を撮影位置から決めつけず、台本の視線・カメラ・演技・奥行きを保ちます。顔などの部分修正にも、遠近、顔の向き、視線、表情、ぼかし、線の強弱を維持して接続を直す指示を追加しました。

1,144件のローカルテスト、lint、ビルドが成功。報告された原稿のSTEP3と実API画像生成を確認しました。別の頭部破綻画像は最初の2回の部分修正では不十分で、3回目に肩越しの構図を保った自然な後ろ姿へ直し、採用されました。生成AIと自動検査には誤りが残るため、注意事項を保持し、完成画像は目視で確認してください。
