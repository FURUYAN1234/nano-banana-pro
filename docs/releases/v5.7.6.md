## Nano Banana Pro v5.7.6

### 日本語

- Hugging Face 配布時に、Space専用の `.gitattributes` とLFS/Xet指定を保持するよう修正します。
- 静的サイト用の `.gitattributes` がHF作業コピーを上書きし、既存の配布ZIPを通常Gitバイナリへ戻す不具合を防止します。
- v5.7.5で追加した自動可変尺・Hybrid b25ワークフロー、3フォルダのカスタムノード配布セット、ライセンス表記、プロセスメモリだけのAPIキー保持仕様は変更しません。

### English

- Preserves the Space-specific `.gitattributes` and LFS/Xet rules during Hugging Face deployment.
- Prevents the static-site attributes file from overwriting the HF checkout and turning an existing distribution ZIP back into a regular Git binary.
- Keeps the v5.7.5 variable-duration Hybrid b25 workflow, three-folder custom-node bundle, license notices, and process-memory-only API credential behavior unchanged.
