# Nano Banana Pro v6.2.0

## English

- STEP2 now chooses props from the subject's specific action and cause-and-effect rather than repeatedly extending one generic object. Explicit props in the scenario remain authoritative.
- Scenario enhancement preserves the existing story and does not invent a scroll, accordion, extension, or replacement mechanism merely to intensify a gag. Existing camera work, acting, and panel roles remain available to the image prompt.
- A fresh real API check generated one Color and one Monochrome 1024x1536 GPT Image 2.5 Sunburst page from a new scenario with the Running Gag ending. Neither output used a scroll or accordion mechanism, and both retained strong perspective and acting.
- This is one inspected pair, not a recurrence-rate guarantee. Rendered text, detailed hands and props, foot crops, and exact camera fidelity still require image-by-image visual review.

## 日本語

- STEP2は、汎用の物を何度も伸ばすのではなく、題材固有の行為と因果から小道具を選びます。シナリオで明示された小道具は引き続き最優先です。
- シナリオ強化はギャグを強めるためだけに、巻物・蛇腹・伸長・置換の仕掛けを勝手に足しません。既存の筋、カメラワーク、個別演技、コマの役割を画像プロンプトへ残します。
- 新しい「天丼」シナリオから、GPT Image 2.5 Sunburstで1024x1536のカラー／白黒を各1枚、実API生成して確認しました。どちらも巻物・蛇腹の仕掛けに頼らず、遠近と演技を維持しました。
- これは目視確認した1組であり、再発率を保証するものではありません。画像内文字、細かな手・小道具、足先の見切れ、指定カメラの完全な再現は、引き続き生成ごとの目視確認が必要です。
