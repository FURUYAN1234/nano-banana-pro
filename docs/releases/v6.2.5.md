# Nano Banana Pro v6.2.5

## English

- The Model Chain now derives every active Gemini text, vision, and image route from its runtime configuration.
- OpenAI and Gemini route changes both flow to the visible Model Chain without a separate snapshot edit.
- The required pre-deploy synchronization test covers both providers.
- Occupational uniforms, workwear, and safety gear now stay attached to each on-duty role instead of being flattened into generic formalwear or a shared casual outfit. Visitors and off-duty characters keep their own clothing assignments.
- Monochrome rendering now reserves pure white for lit skin, light walls, ceilings, and light fabric, while limiting screentone or hatching to bounded material midtones and shadows.
- Real OpenAI API validation used GPT Image 2.5 Sunburst / xhigh at 1024×1536 with automatic repair disabled. One color page and one monochrome page both kept the police officer in an occupational uniform and the visitor in private clothes; the monochrome page also retained white light planes without a page-wide grey veil.

## 日本語

- Model Chainは、Geminiの通常文章・Vision・画像生成の全実行経路も実行時設定から導出します。
- OpenAIとGeminiのいずれも、経路を更新すると別のスナップショット編集なしでModel Chain表示へ反映されます。
- 必須のpre-deploy同期テストは両プロバイダーを確認します。
- 勤務中の人物に必要な職業制服・作業服・安全装備を、共通のフォーマル服や全員同じ私服へ置き換えず、人物ごとの役割に結び付けて保持します。来訪者と非勤務者は別の服装指定を維持します。
- 白黒は、肌の明部、明るい壁・天井・布地を純白として確保し、網点・ハッチングを材質の中間調と範囲を限定した影にだけ使う三階調へ整理しました。
- OpenAI実APIでGPT Image 2.5 Sunburst / xhigh・1024×1536・自動修正OFFを使い、カラーと白黒を各1枚検証しました。両方で警察官の職業制服と来訪者の私服を維持し、白黒では明部の白地を残して画面全体の灰色化を避けています。
