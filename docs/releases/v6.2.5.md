# Nano Banana Pro v6.2.5

## English

- The Model Chain now derives every active Gemini text, vision, and image route from its runtime configuration.
- OpenAI and Gemini route changes both flow to the visible Model Chain without a separate snapshot edit.
- The required pre-deploy synchronization test covers both providers.

## 日本語

- Model Chainは、Geminiの通常文章・Vision・画像生成の全実行経路も実行時設定から導出します。
- OpenAIとGeminiのいずれも、経路を更新すると別のスナップショット編集なしでModel Chain表示へ反映されます。
- 必須のpre-deploy同期テストは両プロバイダーを確認します。
