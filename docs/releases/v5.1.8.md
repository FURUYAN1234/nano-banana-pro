# Nano Banana Pro v5.1.8 - STEP2 Three-Minute API Timeout / STEP2 API待機3分化

## 日本語

- STEP2のシナリオ作成と演出強化で、OpenAIおよびGeminiのテキストAPI応答待機上限を2分から3分へ延長しました。
- 3分設定はSTEP2の2経路にだけ渡し、STEP1、STEP3、360度カメラ解析、画像生成の既存待機上限は変更していません。
- 回帰テストで、両プロバイダーに3分設定が伝わることと、STEP2以外へ設定が漏れないことを確認しました。

## English

- Extended the OpenAI and Gemini text API response timeout from two minutes to three minutes for STEP2 scenario creation and enhancement.
- The three-minute setting is passed only to those two STEP2 paths; existing limits for STEP1, STEP3, 360-degree camera analysis, and image generation are unchanged.
- Added regression coverage for provider propagation and for preventing the STEP2 setting from leaking into other steps.
