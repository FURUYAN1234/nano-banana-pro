# Nano Banana Pro v6.4.7

## 日本語

- STEP2の公開時の開始モデルをGPT-6 Astraへ固定しました。検証用にTerraなどへ変更しても現在のページを開いている間だけ有効で、再読込や次回アクセスではAstraへ戻ります。
- ブラウザ保存された古い検証用モデルが公開環境の既定へ持ち越される経路を廃止しました。選択中モデルから下位へ進む既存の失敗時フォールバックは維持します。
- STEP4の画像生成ボタン内に、選択中OpenAI画像モデルの公式API参考単価と基準日を表示します。ボタン下の旧説明文は表示しません。
- STEP2のモデル料金・選び方・再読込時Astra復帰の3行は、段落の既定余白をなくして詰めて表示します。
- 2026-09-22時点の参考単価は、GPT Image 2.5 Sunburst/Flareが画像入力$8（キャッシュ$2）・画像出力$30・テキスト入力$5（キャッシュ$1.25）、GPT Image 2が画像入力$4（キャッシュ$1）・画像出力$15・テキスト入力$2.50（キャッシュ$0.625）です。すべてUSD／100万トークンです。
- 漫画原稿の外形比率をA4の210:297（約1:1.414）へ統一しました。OpenAI APIへ標準1120×1584、大2240×3168を直接要求し、プロンプト・ローカル正規化・保存画像も同じ共通定義を使います。
- 旧2:3／3:4の指示競合を現行の漫画出力契約から除去しました。領域検出ができる画像はA4へ再配置し、検出が曖昧でも全画面を切らずA4キャンバスへ収めます。
- 同一人物へ完了済みの手動作と左右両手の最終動作が重なった場合は、最終瞬間の左手・右手だけを描画対象にし、3本目の手を作らない共通解決を追加しました。画像QAも人物ごとの全可視手を数え、3本以上を人体欠陥として扱います。

## English

- STEP2 now starts from GPT-6 Astra for every public page load. Choosing Terra or another lower-cost model for validation applies only to the currently loaded page; a reload or later visit starts from Astra again.
- Removed the browser-storage path that carried an old validation model into the public default. The existing failure-only fallback from the current selection to lower models remains unchanged.
- The STEP4 image-generation button now shows the selected OpenAI image model's official API list-price snapshot and date. The old explanatory line below the button is removed.
- Removed the default paragraph gaps between the STEP2 price, selection guidance, and Astra-on-reload lines.
- As of 2026-09-22, GPT Image 2.5 Sunburst/Flare list image input at $8 (cached $2), image output at $30, and text input at $5 (cached $1.25); GPT Image 2 lists image input at $4 (cached $1), image output at $15, and text input at $2.50 (cached $0.625). All rates are USD per million tokens.
- Unified the manga manuscript canvas on A4 210:297 (about 1:1.414). OpenAI API requests 1120×1584 or 2240×3168 directly, and prompts, local normalization, and saved images share the same central format definition.
- Removed the active 2:3/3:4 output-contract conflict. Detected page bands are reconstructed on A4; ambiguous pages are contained whole on an A4 canvas without cropping.
- When a character's completed earlier hand gesture conflicts with explicit final LEFT and RIGHT roles, only the final two roles remain visible and no third hand may be invented. Image QA now inventories every visible hand per named character and treats more than two as an anatomy defect.
