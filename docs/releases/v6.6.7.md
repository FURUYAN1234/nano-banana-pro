# Nano Banana Pro v6.6.7

## 日本語

- STEPの進捗窓に、再検査や修正の理由と結果を表示します。修正画像を生成していない場合は、元画像を保持したことを明示します。
- 独立したカメラ検査と総合検査の矛盾や、髪の色味・形の軽微な差だけでは、有料の画像修正を開始しないようにしました。修正指示に重複していた診断文も削減しました。
- 4コマH3用のワークフローJSONとカスタムノードZIPを識別子`20260928-173220`へ更新しました。必要なモデルはH3用4点とACE-Step用1点です。

### 検証と制約

- 全Nodeテスト818件、警告なしのlint、本番ビルドに合格しました。ZIP内109ファイルの整合性・資格情報の混入を確認し、認証未登録・中止・認証後1回再開のゲートを配布JavaScriptで実行検証しました。
- 画像の実API検証では修正版を警告付きで採用しましたが、ローカル版更新による画面再読込後、生成結果の再表示はできていません。すべてのコマが合格したとは主張しません。
- このH3 ZIPは**中間配布**です。36秒・864×480の動画生成と別実行のACE-Step BGMは確認されていますが、統合グラフ全体の実走と別PCでの動作は未確認です。サンプルの終盤2区間の台詞確認も未了で、`quality_status: needs_review`です。完成動画の台詞とBGMを利用者が確認してください。

## English

- STEP progress logs now explain why an inspection or repair ran and what it found. If no replacement image was generated, the log states that the original was retained.
- Conflicting camera reviews and minor hair variations alone no longer trigger a paid image repair. Repair prompts also avoid repeated diagnostic prose.
- Updated the four-panel H3 workflow JSON and custom-node ZIP to identifier `20260928-173220`. It requires four H3 model files and one ACE-Step model file, downloaded separately.

### Verification and limits

- All 818 Node tests, zero-warning lint, and the production build passed. The 109 ZIP entries passed integrity and credential-pattern checks, and the distributed JavaScript credential gate was exercised for missing credentials, cancellation, and one-time resume after registration.
- A live image API run selected a repaired candidate with a quality warning. Its rendered image is no longer displayed after a local version reload, so this release does not claim that every panel passed visual QA.
- The H3 ZIP is an **interim distribution**. A 36-second 864×480 video run and a separate ACE-Step BGM run were verified, but the combined graph has not run end-to-end or on another PC. The last two sample dialogue segments remain unchecked (`quality_status: needs_review`). Review the final dialogue and BGM before use.
