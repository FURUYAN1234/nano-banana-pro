# Nano Banana Pro v5.1.9 - Manga Dialogue Boundary / 漫画セリフ境界の修正

## 日本語

- STEP3 の台本抽出で、`表情・身体`、`動作`、`ポーズ`、`姿勢`、`目線`、`視線` などの構造ラベルを発話者として扱わないようにしました。説明文がそのまま大きな吹き出しになる不具合を防ぎます。
- 同一話者のステージ指示内の引用と正式セリフが実質的に同じ場合だけ、重複した吹き出しを抑制します。異なるセリフは維持します。
- 回帰テストを追加し、実際の ChatGPT 画像 API で 4 コマ出力を生成して、吹き出しの説明文混入と重複のないことを確認しました。

## English

- STEP3 script extraction now treats structural labels such as `表情・身体`, `動作`, `ポーズ`, `姿勢`, `目線`, and `視線` as directions rather than speakers, preventing descriptive prose from becoming oversized speech bubbles.
- Near-identical quoted stage directions and formal dialogue are deduplicated only for the same speaker; genuinely distinct lines remain intact.
- Added regression coverage and verified a four-panel output through the live ChatGPT image API, with no descriptive-prose bubble or duplicate dialogue bubble.
