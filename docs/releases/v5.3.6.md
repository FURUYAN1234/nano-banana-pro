# Nano Banana Pro v5.3.6 - Public License Structure / 公開ライセンス構成

## 日本語

- プログラム・ソースコードを MIT License で明示し、著作権表示と無保証条項を独立した `LICENSE` に追加しました。
- README のライセンス節を、コード、明示された独自創作コンテンツ、名称利用、生成物、第三者ソフトウェアを分離した現行方針に置き換えました。
- `LICENSE-CONTENT.md`、`TRADEMARKS.md`、`OUTPUTS.md`、`THIRD_PARTY_NOTICES.md` を追加し、CC BY-NC-SA 4.0 の対象、名称利用、生成物の扱い、直接依存関係を明確化しました。
- 本変更はアプリの生成ロジック、APIキーの扱い、プロバイダー選択、または画像生成動作を変更しません。

## English

- Added a standalone MIT `LICENSE` for original program source code, including copyright and warranty terms.
- Replaced the README license notice with a current policy that separates code, explicitly identified original content, name use, generated outputs, and third-party software.
- Added `LICENSE-CONTENT.md`, `TRADEMARKS.md`, `OUTPUTS.md`, and `THIRD_PARTY_NOTICES.md` to make the CC BY-NC-SA 4.0 scope, branding policy, output handling, and direct dependencies explicit.
- This release does not change generation logic, API-key handling, provider selection, or image-generation behavior.
