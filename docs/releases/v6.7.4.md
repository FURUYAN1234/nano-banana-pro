# Super FURU AI 4-koma System v6.7.4

## 日本語

- OpenAIのSTEP2にGPT-6.1 Solを追加し、公開版の初期モデルにしました。既存モデルも選択でき、失敗時は選択位置より下のモデルだけへ切り替わります。
- Model Chainとコピー内容を選択中のSTEP2経路へ連動させました。GPT-6 AstraもSelectable（手動選択のみ）として表示し、自動切替先と区別します。
- GPT-6.1系を推論モデルとして扱い、現行の出力上限パラメーターを使用するよう修正しました。STEP1・STEP3・画像生成モデルは従来の経路を維持します。
- 6.1 Solの公式通常単価は入力$2・出力$10／100万トークン（2026-09-30確認）で、Astraの5分の1です。キャッシュ入力だけは10分の1です。品質が常に同等とは保証しません。
- v6.7.3のモザイク／透かしチェック、明るいAPI取得リンク、同梱OpenAI APIマニュアルも含みます。

### 検証

- [V1] 選択・下位切替・拒否応答・Chat/Responses送信パラメーター・Model Chainの38件の関連テストを確認しました。
- [V2] 現在のAPIアカウントで6.1 Solの利用可能性と実応答を確認しました。構成・監査・改善・再監査はすべて6.1 Solで完了し、下位切替はありません。STEP2の参考合計は入力46,575／出力9,996トークン、$0.193110です。画像生成等は別料金です。

## English

- Added GPT-6.1 Sol to OpenAI STEP2 and made it the production default. Existing models remain selectable; failures try only models below the selected entry.
- Model Chain and its copied text now follow the selected STEP2 route. GPT-6 Astra remains visible as Selectable (manual only), separate from automatic fallback.
- Recognize GPT-6.1 as a reasoning family and send the current completion-limit parameter. STEP1, STEP3 and image-model routes are unchanged.
- Official normal prices checked on 2026-09-30 are $2 input/$10 output per million tokens, one fifth of Astra. Cached input alone is one tenth. This is not a guarantee of equal quality.
- Includes v6.7.3 mosaic/footer checkboxes, brighter API links and the bundled OpenAI API manual.

### Verification

- [V1] Passed 38 focused checks for selection, downward fallback, refusals, Chat/Responses parameters and Model Chain.
- [V2] Confirmed organization-scoped availability and real responses. Scenario construction, audit, bounded improvement and re-audit all adopted 6.1 Sol without fallback. STEP2 reference total: 46,575 input/9,996 output tokens, $0.193110; images and other stages cost extra.
- [V3] Generated one Sunburst/xhigh image from that scenario and visually checked 2240×3168 dimensions, four panels, dialogue, full-figure mosaic and both footers. Automatic image repair was off. Foot cropping, the final screen presentation angle and incomplete internal QA evidence remain limitations. No image references were attached; this is not an Astra quality comparison or a universal visual pass.
