# Nano Banana Pro v7.0.9

## English

- Separate printable dialogue from speaker/layout metadata while retaining spoken names and silent panels.
- Improve per-actor POP, watercolor and gekiga directions, reference roles and camera projection without growing the retained prompt. Keep authored acting, expressions and wardrobe.
- Add one collapsed page/panel editor. Whole-page free instructions use the connected provider; panel style/free edits use the OpenAI image API. Detect current frames in reading order, compare candidates before adoption and preserve original history and pixels outside the selected panel.
- Start in 5–8-panel mode, with four-panel mode available. Keep all five-to-eight counts and exclude all-horizontal strip stacks.
- Unify editable fields with square white backgrounds and black text, add spacing around copy controls, and offer STEP1–4 navigation with descriptions. Remove the manual AI reinspection control.
- Generated details and style strength can vary; inspect the actual image. Four-panel, monochrome and Gemini editing are undergoing additional verification after this deployment.

## 日本語

- 台詞として印字する内容と、話者・配置の内部情報を分離しました。台詞中の呼びかけと無言のコマを保持します。
- POP・水彩・劇画を各人物へ伝える描画指示、参照資料の扱い、カメラの投影を改善しました。採用した指示文を長くせず、指定された演技・表情・衣装を保ちます。
- 「ページ全体／コマを選んで修正」に編集を集約しました。全体の自由入力修正は接続先のAPI、コマ別の絵柄・自由入力修正はOpenAI画像APIを使います。現在の画像から読順でコマを表示し、候補を比較して採用できます。元画像を履歴に残し、選択コマ外の画素を保持します。
- 初期選択を5～8コマにしました。4コマへ切替可能で、5・6・7・8コマを保ち、全コマ横長の帯状配置を除外します。
- 手入力欄を角丸なしの白地・黒文字へ統一し、コピーボタン周辺に余白を追加しました。説明付きのSTEP1～4移動メニューを設け、手動のAI再検査ボタンを外しました。
- 生成される細部や画風の強さには差があるため、実画像を確認してください。四コマ・白黒・Geminiの追加修正検証は、この公開後に行います。
