# Super FURU AI 4-koma System v8.2.4

## Changes / 変更点

- STEP2 now accepts rectilinear wide-angle scripts that explicitly exclude fisheye, including 「魚眼にはしない」. Previously the camera check could reject a valid script and block STEP3. / STEP2で「魚眼にはしない」などを正しく読み取り、通常の広角を指定した台本が誤って止まる不具合を修正しました。
- The camera check still requires a high or low viewpoint in automatically designed panels, with the existing exception for eye level explicitly requested by the user. It rejects affirmative fisheye directions. / 自動構成では、利用者が明示したアイレベルを除き、俯瞰かアオリが必要です。魚眼を使う指定は引き続き検査で検出します。

## Installation / 導入

- [Repository and instructions / ソースと導入手順](https://github.com/FURUYAN1234/nano-banana-pro)
