## Nano Banana Pro v5.7.7

### 日本語

- MiniMax H3配布を、提供された自動可変尺・H3生成BGM安定最新版ワークフローへ更新します。
- ワークフローJSONと、Nano Banana／Long-Video／Spectrumの3カスタムノードを含む導入セットを、用途別の別ダウンロードとして公開します。
- APIキーはComfyUIサーバープロセスのメモリだけに保持し、配布物・設定ファイル・ブラウザ保存領域・ディスクへ保存しません。個人用発音辞書はAPIキーと分離してローカル保存されます。
- Spectrumの実行時フック、任意診断の隔離Python子プロセスとuser cacheレポート、Long-Videoのffmpeg要件を導入案内へ明記します。

### English

- Updates the MiniMax H3 distribution to the supplied stable auto-duration workflow with H3-generated BGM.
- Publishes the workflow JSON and the setup bundle containing the Nano Banana, Long-Video, and Spectrum custom nodes as separate purpose-specific downloads.
- Keeps API credentials only in the running ComfyUI server process memory and never in the distribution, configuration files, browser storage, or disk. Personal pronunciation dictionaries remain separate local data.
- Documents Spectrum runtime hooks, its optional isolated Python diagnostics and user-cache reports, and Long-Video's ffmpeg requirement.
