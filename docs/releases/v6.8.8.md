# Nano Banana Pro v6.8.8

## Changes

- Automatic direction uses high/low camera positions and six scene-selected styles: normal, gekiga, watercolor, pop art, pencil sketch and chibi. Rectilinear wide angles remain available; automatic fisheye and eye-level choices are excluded. Explicit user directions and imported styles remain supported.
- Fix camera negation, close-up and telephoto parsing. Preserve local face/body projection instructions through prompt compaction instead of retaining only a tilted background.
- Separate reference identity from panel rendering and restore the established gekiga face instructions. QA keeps insufficient camera/style evidence unverified and does not show unverified results as problem-free.
- Update the H3 workflow and custom-node download to the 20261005233427 package with the existing authentication-model validation repair. Rebuild the manuals and review the README.

## 変更内容

- 自動カメラは俯瞰・アオリを使い、画風は通常・劇画・水彩・ポップアート・鉛筆・ちびキャラから内容に応じて選択します。通常広角は維持し、魚眼・アイレベルを自動候補から除外。明示指定と取り込んだ画風は保持します。
- 禁止指定を採用指示と誤認する問題と、寄り・長焦点の判定漏れを修正。短縮後も顔・身体の投影指示を保持します。
- 参照画像の識別特徴とコマ別描画を分離し、過去の劇画顔指定を復元。画像検査で根拠不足を未確認のまま残し、問題なしと表示しません。
- H3のリンクを20261005233427版のワークフローと認証モデル検証修復済みカスタムノードZIPへ更新。マニュアル再出力とREADME本文監査を実施します。
