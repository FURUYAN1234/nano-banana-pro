## Nano Banana Pro v6.4.5

### 日本語

- 単独の吹き出しは、話者側の空きへ配置し、頭・顔・髪・文字を横切らない最短のしっぽを指定話者の口元・頭部へ接続するようにしました。
- 複数の吹き出しだけ、話者の立ち位置とは独立して右から左の物理順序を固定します。Web貼り付け用の短縮後も、話者、順序、しっぽの接続先を保持します。
- 同じシナリオのAPI生成とWeb貼り付け生成で、単独吹き出しが指定話者側に置かれ、短いしっぽが指定話者へ向くことを確認しました。API画像全体には別コマの文字転記・視覚証拠に未確定警告が残るため、全画質の合格とは扱っていません。

### English

- Places a single bubble in clear space on its mapped speaker's side and connects the shortest unobstructed tail to that speaker's mouth or head without crossing faces, hair or text.
- Keeps fixed right-to-left physical ordering only when a panel has multiple bubbles, independently of character staging. Web prompt compaction preserves the speaker, order and tail endpoint.
- Verified the target single-bubble behavior with one API generation and one Web-paste generation using the same scenario. The API image retains an unrelated warning about another panel's transcription and visual evidence, so it is not reported as a complete visual-quality pass.
