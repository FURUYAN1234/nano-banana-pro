# Nano Banana Pro v6.9.8

## English

Material additions, deletions and panorama participation changes now rebuild recognition and AI-derived character settings from the current references. Manual edits remain intact, only new or failed references need analysis, and obsolete asynchronous results cannot overwrite the current work. Explicit image numbers follow retained image identity; removed targets are marked instead of being redirected. Rebuild the scenario and prompt after material changes, and replace text and attachments already pasted into a Web service.

Recognition uses ordinary name and description fields, with character settings and panorama information in the same visible section. Resetting from STEP2 retains STEP1 materials including the panorama. Resetting during analysis releases busy state. Image-edit drafts survive temporary panel hiding, and recognition-copy success waits for the clipboard result. The stop control is now labelled「解析・生成強制ストップ」.

Image prompts avoid duplicated automatic reference descriptions while retaining manually edited descriptions. Attachment lists map STEP1 material IDs to actual attachment positions, including repair-source offsets; Web metadata records background and prop roles correctly. The README and all three PDF manuals explain these rules and the limits of AI recognition.

## 日本語

素材の追加・削除・360°背景ON/OFF後に、現在の素材から画像ごとの認識とAI由来の人物設定を組み直します。手編集を保持し、新規・前回失敗した素材を解析します。変更前の処理が遅れて完了しても採用しません。自由入力の明示した画像番号は素材に追従し、削除した対象は別の画像へ割り当てず削除済みと表示します。素材変更後はシナリオと指示文を作り直し、Webへ貼付済みの文章・画像も差し替えてください。

認識結果は普通の名前・説明欄で編集でき、人物設定と360°背景も同じ欄へまとめています。STEP2からのやり直しでは360°背景を含むSTEP1素材を保持し、解析中のリセットでは処理中状態を解除します。画像への追加指示の下書きは一時非表示で消えず、認識コピーは書き込み成功後に完了を表示します。停止ボタン名は「解析・生成強制ストップ」へ変更しました。

描画用文章の自動認識説明の重複を減らし、手編集した説明は維持します。STEP1素材番号と実添付番号を対応づけ、修復元画像を先頭に加える場合も区別します。Web用制作情報JSONの背景・小物分類も修正しました。READMEと3種類のPDFに操作とAI認識の限界を反映しています。
