# Nano Banana Pro v5.9.6

## 日本語

- OpenAI画像APIへキャラクターシートと有効な背景参照を添付します。品質修正では元画像も渡し、変更箇所と保持条件を分けて指定します。
- 自動修正は最大1枚。合格した修正版を元画像と比較し、明確な改善がなければ元画像を保持します。
- Web貼り付けを、契約中のサブスクの利用枠で画像API料金を節約する選択肢として説明します。キャラ解析など既に使ったAPIの料金は別途発生します。
- MiniMax H3配布をv1.1.7へ更新し、ZIPと単独JSONの別ダウンロードを維持します。5フォルダ同梱、最大5候補、Windowsの文字コード対策、エラーの資格情報秘匿、導入説明を反映します。

## English

- Sends character sheets and enabled background references to the OpenAI image API. Bounded repairs also receive the original image with separate change and preservation instructions.
- Produces at most one repair image and retains the original unless the passing repair is clearly better in a direct comparison.
- Clarifies subscription-based Web generation as an option to save image API charges, while earlier analysis and other API operations remain separately billed.
- Updates the MiniMax H3 package to v1.1.7 with separate ZIP and workflow JSON downloads, five bundled folders, at most five candidates, Windows encoding fixes, credential-safe errors and corrected installation instructions.
