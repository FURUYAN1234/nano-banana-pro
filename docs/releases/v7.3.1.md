# Super FURU AI 4-koma System v7.3.1

## Changes / 更新内容

- Fixed an issue in standard Gemini four-panel generation where correct speech could be marked as having unverified reading order. The check now reads dialogue and speaker information from the final prompt sent to Gemini. / Geminiの通常4コマ生成で、正しい台詞でも「読順未確認」になる不具合を修正しました。Geminiへ送る最終プロンプトから台詞と話者を読み取って検査します。
- Retain explicit straight-down and upward close-up geometry in the drawing prompt. Quality review checks visible camera cues and can verify a separated balloon tail when it points to a single visible speaker. / 真俯瞰と見上げの接写を描画指示に明示しました。カメラ検査では実画像の上面・下面を確認し、尾が人物に接していなくても、一人に向いていることを確認できれば話者を照合します。
- In OpenAI 5–8-panel STEP3, invalid optional effects no longer stop otherwise valid panel plans. Panel order, camera, and dialogue remain required. / OpenAIの5～8コマのSTEP3で、使えない任意演出だけを除いて描画指示を作れるようにしました。コマ順・カメラ・台詞の検査は維持します。
- Verified the normal Nano Banana 2.1 generation and Gemini 3.8 Flash review with two balloons in one panel, single balloons and a silent panel. All four passed the dialogue and order check. The generated image still requires visual review. / Nano Banana 2.1の通常生成とGemini 3.8 Flashの検査で、吹き出しが2つのコマ、1つのコマ、無言のコマを確認しました。台詞と読順は全4コマが合格しました。生成画像は引き続き目視でご確認ください。
