# Nano Banana Pro v7.0.7

In 5–8-panel mode, six- and eight-panel stories remain available. STEP3 no longer offers or accepts a page that stacks every panel as a full-width horizontal strip for those counts. Other compatible layouts, including mixed rows, remain available; five- and seven-panel layouts are unchanged. If the image model draws the excluded arrangement despite the approved plan, image review warns and retains the result for inspection.

5～8コマ生成では、6コマ・8コマの物語も引き続き作れます。STEP3では、この二つのコマ数で全コマを横長の帯にして縦積みする配置を候補から外し、配置案としても受け付けません。横長と分割を混ぜる配置などは利用でき、5コマ・7コマの配置は変えません。画像AIが指定に反して全横長で描いた場合、画像を保持したまま検査で警告します。
