# Super FURU AI 4-koma System v8.1.0

## English

- The public manga skill uses each work’s author credit, watermark settings, actual AI involvement, and user-selected social links. Personal preferences stay in a separate local file.
- The diagnostic log labels inspection and automatic error alerts separately.
- High-resolution OpenAI image edits count the actual multipart line endings before sending. Automatic repair tightens repeated instructions while preserving the approved dialogue, camera directions, acting, and composition.
