# Nano Banana Pro v6.4.8

## 日本語

- STEP2の既存品質検証後に、1〜2コマ目の種、3コマ目までの読者予測、4コマ目の視覚的な反転・回収・帰結・再解釈を監査します。
- 初稿が弱い場合は4コマ目だけでなく1〜4コマ全体を一度だけ再構成し、既存検証と再監査の両方を通った場合だけ採用します。失敗時は元の検証済み候補を警告付きで保持します。
- シリアスには安いギャグ反転を強制せず、ドキュメンタリーには元入力にない事実・数値・時系列を追加しません。
- Web貼付用の短縮プロンプトにもA4漫画原稿の正確な標準1120×1584／大2240×3168を保持します。API版は選択寸法へ厳密に正規化し、Web版はアプリ後処理外のため小さなA4近似誤差を許容します。
- 台本で明示された文字だけを厳密に固定し、未指定の背景面には場所に自然な文字を、可読／装飾、短文／長文、量・密度を問わず自由に描けます。台本にない文字だからという理由で面を抑制・簡略化しません。
- 各コマの全登場人物を1人1体・1奥行き位置へ固定し、画像QAが名前ごとの実出現数を台本のCAST COUNTと照合します。前景／背景やコマ端の見切れをまたぐ同一人物の重複も検出対象です。
- FourPanel MiniMax H3のワークフローJSONと3カスタムノード配布ZIPを識別子`20260922104144`へ更新しました。供給ZIPの全105ファイル検証、6区間・36秒・864×480・24fps、manifestの`complete`／`quality_status: pass`、184回帰、音声再精錬4ステップ・denoise 1.0を配布契約へ反映しました。
- 内蔵ブラウザのTerra実APIで初稿監査、全4コマ再構成、再監査、安全な元案保持を確認しました。Sunburst/xhighのAPI画像は1120×1584へ正規化され、Web出力1055×1491はA4比との差0.0719%でした。
- 重複修正版の同一プロンプトをWeb貼付版とSunburst/xhigh API版で再生成し、両方の4コマ目で5人を各1回だけ描画し、背景文字量・OTS構図・画面密度がほぼ同等になることを目視確認しました。

## English

- Added a mode-aware STEP2 review for setup seeds in panels 1–2, reader prediction by panel 3, and a visible reversal, payoff, consequence, or reframe in panel 4.
- A weak first candidate receives one full four-panel rewrite. The repair is adopted only after both the existing validators and a second payoff review pass; otherwise the validated original remains with a warning.
- Serious endings do not require a cheap comic reversal, and documentary endings may not invent facts, figures, or chronology.
- The compact Web-copy prompt now preserves the exact A4 manuscript tiers, 1120×1584 and 2240×3168. API output is normalized to the selected exact canvas; small near-A4 variance remains acceptable for Web output outside the app normalizer.
- Only explicitly scripted lettering remains exact. Unspecified background surfaces may freely contain natural setting-appropriate lettering—readable or decorative, short or long, in any amount or density—and are not suppressed or simplified merely because that lettering was not scripted.
- Every named actor is locked to one body in one depth position per panel. Image QA compares observed identity instances with each scripted `CAST COUNT`, including duplicates split across foreground, background, or a panel edge.
- Updated the FourPanel MiniMax H3 workflow JSON and three-custom-node distribution ZIP to identifier `20260922104144`. The release contract preserves verification of all 105 supplied files, the six-segment 36-second 864×480/24fps run, manifest `complete` / `quality_status: pass`, 184 regressions, four audio-refinement steps, and denoise 1.0.
- A live in-app-browser Terra run exercised review, full rewrite, second review, and safe original retention. A Sunburst/xhigh API image normalized to 1120×1584; the Web result measured 1055×1491, 0.0719% from the A4 ratio.
- The corrected prompt was regenerated through both ChatGPT Web paste and Sunburst/xhigh API. Visual comparison showed exactly one instance of each of the five panel-4 characters in both outputs, with near-equivalent background lettering, OTS staging, and scene density.
