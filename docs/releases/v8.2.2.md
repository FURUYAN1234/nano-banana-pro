# Super FURU AI 4-koma System v8.2.2

## Changes / 変更点

- The bundled manga skill ties visible features to the speaker or action when people in similar outfits, viewed from behind or partially occluded, could be confused. It asks for a readback at page size. / 同梱の漫画制作スキルは、似た服装や後ろ姿、重なりで人物を見分けにくいコマで、画面に見える特徴を話者や動作と結び付け、完成ページで確認します。
- After a successful MCP disconnect, manual controls unlock even if restoring the preceding view fails. A warning identifies this situation. / MCP切断に成功した後、切断前の画面の復元に失敗しても手動操作のロックを解除し、警告を表示します。
- Panel edits remove newly introduced symmetric blank bands only when the inset matches the source panel aspect ratio. Existing borders and genuine aspect-ratio differences keep proportional fitting, and pixels outside the selected panel are preserved. / 元コマ比率の絵を囲む対称な空白帯が修正候補に新たに加わった場合、その帯を除きます。元の枠と比率差を保つ余白は維持し、対象矩形の外の画素は保持します。
- The operation manual, OpenAI setup guide and Gemini setup guide were regenerated for this version. The operation manual now describes the public default for the product watermark. / 操作、OpenAI接続、Gemini接続の3冊を更新し、操作マニュアルのウォーターマーク説明を公開版の初期設定に合わせました。
