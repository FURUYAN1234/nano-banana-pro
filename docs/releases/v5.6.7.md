## Nano Banana Pro v5.6.7

### 日本語

- 物理的な場面根拠がある時だけ、奥行き・影・焦点・反射・屈折・動感を既存の固定長カメラ枠へ置換する条件付き映像テクニックを追加しました。
- 明示カメラ、登場人物、動作、解剖、可読文字を常に優先し、根拠不足または競合時は従来プロンプトをそのまま維持します。
- STEP4の可視QAは、生成候補と添付キャラクターシートを直接比較し、服装・髪型・眼鏡などの同一性不一致を1回限定修正の対象として検出します。

### English

- Added conditional cinematic techniques that replace an existing fixed-length camera slot only when the scene has physical support for depth, shadow, focus, reflection, refraction, or motion cues.
- Explicit camera direction, cast, action, anatomy, and readable text always win; unsupported or conflicting scenes retain the baseline prompt unchanged.
- STEP4 visual QA now compares the generated candidate directly with attached character sheets and detects wardrobe, hairstyle, eyewear, and other identity mismatches for the single bounded repair attempt.
