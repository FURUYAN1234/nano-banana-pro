## English

- Reopen adopted panel edits using verified source geometry only when every pixel outside the edited panel is unchanged. Whole-page edits discover the updated panels afresh. Keep original images in history.
- Improve monochrome instructions: preserve white lit skin, canonical dark-skin bases, bounded screentones and black shadows. Correct skin classification leaking into adjacent appearance fields and keep existing hair/skin/clothing tone assignments during edits. Neutralize residual API color without resizing or changing the color workflow.
- Disable editing while generation or inspection is running. Clarify STEP progress and spacing, and update elapsed time during panel edits. Use white/black for the emotional-prompt copy button.
- Remove the standalone external-manga import UI and the large inline technique-guide preview. Retain API/history editing and the color API technique references.
- Real API verification covers OpenAI four-panel color/monochrome and native six-panel monochrome, plus Gemini four-panel color/monochrome page and panel edits. The user accepted the current native monochrome drawing baseline. Generated style, camera and detail fidelity still vary; inspect candidates before adoption.

## 日本語

- 接続中のOpenAI・Gemini画像APIでコマ別修正ができます。Geminiは4コマ限定、OpenAIは5～8コマにも対応します。
- コマ外の全画素が一致する場合に限り、検証済みの元コマ枠を引き継ぎ、採用後も再選択できます。ページ全体修正後は新しいコマ枠を読み取ります。元画像は履歴に保持します。
- 白黒の白肌の明部、褐色肌の地色、影のスクリーントーン・黒ベタを整理しました。隣の外見項目まで読んで肌を誤分類する不具合と、修正時の髪・肌・衣装の明暗割当を改善しました。API画像に残る色味は白黒時だけ除き、解像度とカラー経路は保持します。
- 生成・検査中の修正操作を無効にし、STEP進捗・余白・コマ修正中の経過秒を改善しました。エモーショナルプロンプトのコピーボタンを白地・黒文字にしました。
- 独立した外部漫画読込UIと、Web補助欄の大きな描法見本プレビューを外しました。API・履歴からの修正と、カラーAPIの描法参照は保持します。
- OpenAIの4コマカラー・白黒とネイティブ6コマ白黒、Geminiの4コマカラー・白黒で、ページ／コマ修正を実API検証しました。白黒5～8コマの現状の絵は本人確認済みです。画風・カメラ・細部の再現には生成差があるため、候補を比較して採用してください。
