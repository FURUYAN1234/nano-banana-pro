# Nano Banana Pro v6.0.5

## 日本語

- STEP4の「API生成時の品質・サイズ」ボタンに、現在選択中のOpenAI画像モデル・品質・サイズを常時表示します。
- 品質またはサイズを変更すると、折り畳み状態の表示にも即時反映されます。Google AI使用時は「Google AI：自動設定」と表示します。
- 長い設定名でも開閉表示を圧迫しない2行構成とし、狭い画面でも確認しやすくしました。

## English

- The STEP4 API quality and size button now always shows the selected OpenAI image model, quality, and dimensions.
- Changing either selector updates the collapsed summary immediately. Google AI mode is labeled as automatically configured.
- A compact two-line layout keeps the open/close affordance readable when settings names wrap on narrow screens.
