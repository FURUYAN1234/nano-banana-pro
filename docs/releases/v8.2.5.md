## Changes / 変更点

- OpenAI STEP1–3 Chat Completions now retry the first model once after a network failure before the HTTP response. If the retry also fails, the configured route continues. / STEP1〜3のOpenAI Chat Completionsで、初回のHTTP応答前に通信が切れた場合は、最初のモデルで1回だけ再試行します。再試行も失敗した場合は、設定されたモデル経路に従います。
- Updated the README and PDF manuals with the retry behavior and current edition. / READMEとPDFマニュアルに、再試行の条件と対応版を反映しました。
