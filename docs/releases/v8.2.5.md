# Super FURU AI 4-koma System v8.2.5

## Changes / 変更点

- OpenAI free layouts support diagonal borders, inset panels, and character breakouts across a shared diagonal. / OpenAIの自由配置では、斜め枠、差し込み小コマ、斜めの枠を越える人物を指定できます。
- Single-page generation downloads a PNG with embedded production details. MCP groups the page images and JSON files in a project folder. / 通常画面の1ページ漫画は制作情報付きPNGでダウンロードし、MCPではページ画像とJSONを作品フォルダーに保存します。
- If an MCP heartbeat is briefly interrupted, the app checks the existing connection again. / 一時的にMCPの接続確認が途切れたときは、同じ接続で確認をやり直します。
- OpenAI STEP1–3 Chat Completions now retry the first model once after a network failure before the HTTP response. If the retry also fails, the configured route continues. / STEP1〜3のOpenAI Chat Completionsで、初回のHTTP応答前に通信が切れた場合は、最初のモデルで1回だけ再試行します。再試行も失敗した場合は、設定されたモデル経路に従います。
- Updated the README and PDF manuals with the retry behavior and current edition. / READMEとPDFマニュアルに、再試行の条件と対応版を反映しました。
