# Nano Banana Pro v5.1.1 - Visual Anatomy QA / 視覚解剖QA

## 日本語

- 画像生成後に、設定済みのVision対応プロバイダーが4コマをコマごとに検査します。
- 余分・欠落・分離・別人物への誤接続の腕や手を検出した画像は、修正ロック付きで一度だけ自動再生成します。
- QA応答が壊れている場合、または再生成後も不合格の場合は、問題の画像を表示せずエラーとして停止します。

## English

- After image generation, the configured vision-capable provider reviews every manga panel.
- Images with extra, missing, detached, or wrong-body arms or hands are regenerated once with an anatomy repair lock.
- Malformed QA responses and a second rejected image fail closed instead of displaying the defective result.
