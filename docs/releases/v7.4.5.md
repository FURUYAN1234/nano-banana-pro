# Super FURU AI 4-koma System v7.4.5

## Changes / 更新内容

- Free-layout stories now choose the position and shape of the main scene from the story's action, discovery or ending. Removed the single right-side full-height example that encouraged similar page layouts. / 自由コマ割りでは、動作・発見・結末など物語の見せ場から大コマの位置と形を選びます。同じ配置へ寄りやすかった右側全高の単一作例を外しました。
- Up to six recent layouts in the current session help choose among equally suitable structures. Story effectiveness and explicit directions take priority; there is no forced rotation or random layout assignment. / 同じ画面内の直近6作品の配置を参考に、内容に合う候補から構成を選びます。話の効果と明示指定を優先し、順番制やランダムな配置にはしません。
- Large figures, panel overlaps and full bleed remain available. Legacy mode retains four horizontal panels. No extra comparison API request or retry solely for layout similarity was added. / 大きな人物・枠越え・タチキリを維持し、レガシーモードは横長4コマ固定です。構成比較の追加APIや、配置が似ているという理由だけの再生成は増やしていません。
- Updated the README and bundled manuals. Verified three ordinary-input scenarios and two generated manga pages through the normal API workflow. / READMEと同梱マニュアルを更新しました。通常入力から3題材のシナリオと2作品の漫画画像を実APIで確認しました。

## Verification / 検証

- 2,283 automated tests, zero-warning lint and production build passed. / 自動テスト2,283件、警告ゼロのlint、本番ビルドに合格しました。
- Image acceptance included direct whole-page review. Automatic image QA had unverified items; this release does not guarantee exact geometry or perfect model output. / 実画像はページ全体を目視確認しました。自動画像検査には未確認項目があり、配置の完全一致や生成結果の無誤りを保証するものではありません。
