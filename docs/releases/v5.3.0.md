# Nano Banana Pro v5.3.0 - Generic Hand and Prop Kinematics / 汎用手・小道具運動学

## 日本語

- 特定の小道具名、持ち方、ジェスチャーに依存しない一つの手・小道具運動学契約を、ChatGPT/OpenAI と Gemini の両方の STEP3 プロンプトへ適用しました。
- 元の Action 文を改変せず、人物基準の左右、片手につき一つの同時役割・接触、小道具の所有者分離、連続動作後の最終支持状態、掌・親指・指・手首の連続性を指定します。
- これにより左右反転、切断、重複、変形した手を抑えます。ただし生成画像モデルの解剖をピクセル単位で保証するものではありません。
- 長い ChatGPT 用プロンプトでも 15,000 文字の Web コピー上限内で同等の契約を保持し、既存のカメラ、視線、背景、衣装、タイトル、透かしの指示を維持します。
- 実際の OpenAI `gpt-image-2` 画像生成で、二手でのスマホ保持、新聞を指す手、スマホとピースサインの同時ポーズを含む 4 コマ画像を確認しました。

## English

- Applied one situation-agnostic hand and prop kinematics contract to both ChatGPT/OpenAI and Gemini STEP3 prompt families instead of branching on individual props, grips, or gestures.
- The contract preserves the scripted Action while specifying subject-relative sides, one simultaneous role/contact per hand, separate prop ownership, final supported state after sequential actions, and palm/thumb/finger/wrist continuity.
- It reduces mirrored, detached, duplicated, and malformed hands, while not claiming pixel-perfect anatomy from a generative image model.
- Long ChatGPT prompts retain an equivalent compact contract within the 15,000-character Web-copy limit while preserving existing camera, eye-line, background, wardrobe, title, and watermark instructions.
- A real OpenAI `gpt-image-2` four-panel run was visually checked with two-hand phone holding, a newspaper-pointing hand, and a phone-plus-peace-sign pose.
