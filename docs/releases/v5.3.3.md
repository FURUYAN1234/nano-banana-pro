# Nano Banana Pro v5.3.3 - Image Quality Failsafe / 画像品質フェイルセーフ

## 日本語

- STEP4は最初の画像を先に保存・表示してから、人物の解剖学、手の左右、小物の所有と機能面の向き、吹き出し本文、話者名混入、余計な文字を可視品質レビューします。
- 具体的な品質NGが検出された場合だけ、問題箇所に限定した修正版画像を最大1回生成します。修正版がPASSなら採用し、未合格または取得失敗なら保存済みの元画像に戻して、品質警告付きで後続の全自動工程を継続します。
- 品質レビューが判定不能の場合は追加の画像API呼び出しを行わず、元画像を保持して具体的な警告とともに継続します。初回画像の認証・通信・画像欠落など、利用可能な画像成果物がない失敗だけは従来どおり停止します。
- READMEと回帰テストを更新し、元画像PASS、修正版PASS、修正版NG、判定不能、修正版取得失敗の各分岐を固定しました。

## English

- STEP4 now saves and displays the first image before visibly reviewing anatomy, hand laterality, prop ownership and functional orientation, speech-bubble text, speaker-name leakage, and unrelated text.
- Only a concrete quality failure triggers one issue-limited repair image. A passing repair replaces the original; a failed or unavailable repair restores the saved original and lets downstream full-auto work continue with a quality warning.
- If visual QA is unverified, the app makes no additional image API call, keeps the original image, and continues with a concrete warning. Initial authentication, transport, or missing-image failures still stop because no usable image artifact exists.
- Updated the README and regression coverage for original PASS, repaired PASS, repaired NG, unverified QA, and failed repair retrieval.
