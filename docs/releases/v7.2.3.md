# Super FURU AI 4-koma System v7.2.3

STEP1 character name fields and profile name headings now synchronize in both directions. Correct an unread or mistaken name in either place; the linked character sheets, profile text and recognition copy update together. / STEP1の人物名欄と人物設定の名前見出しが双方向に連動します。読めなかった名前や誤読をどちらで直しても、同じ人物のシート・人物設定・認識結果のコピーへ反映します。

Clearing a name before retyping preserves its link. Empty names and names already used by another character show an editable warning and block copying. Other characters and non-character material labels are kept separate. Renamed profiles retain their source-image links, so removing the last reference removes the correct profile. / 名前を消して入力し直す間も対応を保持します。空欄や別人との同名には警告を表示し、解消するまでコピーを止めます。他人物や背景・小物の素材名を混同せず、改名後も参照画像がすべて外れた人物の設定を正しく削除します。

Local STEP1 verification with GPT-6 Luna now stops on failure instead of switching models, matching the existing local STEP2/STEP3 validation policy. Public model routes are unchanged. README and the three PDF manuals describe the current version. / ローカルSTEP1のGPT-6 Luna検証も、既存のSTEP2・STEP3と同じく、失敗時に別モデルへ切り替えず停止します。公開版のモデル経路は従来どおりです。READMEとPDFマニュアル3冊を現行版へ更新しています。
