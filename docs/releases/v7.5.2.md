# Super FURU AI 4-koma System v7.5.2

## Changes / 更新内容

- [text-only-cast] Build API and Web-copy prompts from usable STEP1 character text when no character-reference images are supplied. Preserve names, appearance and clothing instead of claiming nonexistent attachments. / 人物参照画像がない場合も、十分なSTEP1人物設定からAPI用・Webコピー用の指示文を作り、存在しない添付画像を参照せず名前・外見・服装を保持します。
- [reference-priority] Keep character-image identity priority when images exist; background and style examples are not character sheets. Empty or insufficient input remains invalid. / 人物画像がある場合の同一性優先を維持し、背景・描法見本を人物シートとして扱いません。空欄・不十分な入力は引き続き拒否します。
- [story-handoff] Document Story Maker’s separate STEP1 settings and STEP2 scenario handoff, followed by STEP3 prompt building and STEP4 generation. / Story Makerの人物設定をSTEP1、台本をSTEP2へ貼り、STEP3で指示文を作ってSTEP4で画像化する手順を説明します。
- [cast-count] Keep a character’s separate scripted appearance when a connected figure from another panel crosses into the same panel; require visual evidence before excluding that crossing body from the local count. / 別コマの人物が枠を越えていても、そのコマで別の動作をする同名人物を人数から除外しません。越境した身体の除外には、実画像での接続と人物同定の根拠を必要とします。
- [normal-style] Use the existing normal color/monochrome drawing recipe when character images are absent, and give the same basis to the image check. / 人物画像がない場合の通常画風に既存のカラー・白黒の描画基準を使い、画像検査にも同じ基準を渡します。

- [app-links] Open Character Maker from STEP1 to prepare character sheets, or Story Maker from STEP2 to create a scenario. The outlined buttons explain the destination and return path and open a separate tab, preserving this page. The same links are available on the initial API connection screen. / STEP1のキャラクターメーカーボタンで人物シートを、STEP2のStory Makerボタンで台本を準備できます。枠線付きボタンには用途と戻し先を説明し、作業中の画面を残して別タブで開きます。初期のAPI接続画面からも同じリンクを使えます。

- [intake] Make sheet-image drop the primary STEP1 action, highlight its full drop boundary, and use one multiline character field for recognition and Story Maker profiles. Reject incomplete or unrelated pasted formats while retaining the editable input. / STEP1はシート画像ドロップを主操作として範囲を明示し、認識結果とStory Maker人物情報を共通の複数行欄へ表示します。不完全・別形式の貼付は入力を保持して拒否します。
