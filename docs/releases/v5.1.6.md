# Nano Banana Pro v5.1.6 - API Refresh Protection / API更新時の接続保護

## 日本語

- Vite/Fast Refresh が実行されても、すでに接続済みのOpenAI/Geminiエンジンに対して起動時のAPI初期化を再実行しません。これにより、開発中の更新でメモリ上のAPIキーが空に戻る不具合を防ぎます。
- 保持するのは `window` 上の真偽値だけで、APIキーそのものを `localStorage`、`sessionStorage`、またはファイルへ保存しません。
- シナリオ強化の品質再試行は最良の安全候補を保持し、品質警告でもSTEP3・STEP4へ継続します。通信・プロバイダー・安全ポリシーの失敗はエラーのままです。

## English

- Vite/Fast Refresh no longer replays the mount-time API bootstrap against an already connected OpenAI or Gemini engine. This prevents a development update from clearing the in-memory API key.
- The guard stores only a boolean on `window`; it never stores an API key in localStorage, sessionStorage, or files.
- Scenario-enhancement quality retries retain the strongest safe candidate and continue through STEP3 and STEP4 with a warning. Transport, provider, and safety-policy failures remain errors.
