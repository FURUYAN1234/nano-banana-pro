### English

- Synchronizes the Hugging Face LFS ZIP targets and byte-preserving workflow JSON/SHA-256 files from the current `public/.gitattributes` distribution list instead of fixed historical filenames.
- Keeps GitHub Pages distribution bytes as ordinary static assets while tracking ZIPs only in the HF LFS/Xet bridge.
- For the 2026-09-07 MiniMax H3 Fused4 + SLA external-API distribution published in v5.8.8, the ZIP SHA-256 is `1020857E4DBE0B65603D23721D073242FD24F66D33257F1D73CC3DA0EE7B16D4` and the workflow SHA-256 is `2839ED348E9334807A9BA7E807D297C32CBAEE8824691943C9D00DE1E7EADEBB`.
