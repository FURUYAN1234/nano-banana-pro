# Super FURU AI 4-koma System v8.2.3

## Changes / 変更点

- If a character changes into a story-specific outfit, approve the updated character sheet and assign it to the relevant pages before drawing. / 作品用に着替える人物は、その衣装の設定画を確認・採用し、対象ページに割り当ててから作画します。
- Check the speaker's eyeline against the intended listener in the finished panel. Verify balloon attribution separately. / 対話コマでは、吹き出しの話者と、話者の目や顔が向く相手を別々に確認します。
- Before accepting a localized edit, compare the outer bounds and the area occupied by artwork to catch unwanted inner bands or double borders. / 部分修正の採用前に外枠と枠内の絵を元のコマと見比べ、意図しない白帯・黒帯や二重枠を確認します。
- The updated skill is included in the Windows application ZIP and the standalone skill ZIP. The PDF manuals reflect the current distribution. / 更新したスキルはWindows向けアプリZIPと単体スキルZIPに入っています。PDFマニュアルも現行の配布版に合わせました。
