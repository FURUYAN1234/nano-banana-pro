# Nano Banana Pro v6.9.5

## English

STEP1 previously accepted too many character-sheet images and could fail later in STEP3. It now shows the current count and remaining capacity, and rejects an entire over-limit addition before analysis API requests or changes to existing images and settings.

- The shared OpenAI/Gemini limit is 14 character-sheet images without a 360° background, or 10 with it enabled. Background activation is also refused when it would exceed the limit.
- Style JSON does not count as an image. Identical image data counts once, and rejected files can be selected again after adjusting the references.
- A sheet containing several people counts as one image. There is no fixed rejection limit based on people; crowded references can still cause identity, drawing or dialogue errors.
- Updated STEP1 guidance, the English / Japanese README and all three PDF guides. Existing oversized states and Gemini requests are also checked before generation.

Validation: focused intake and version regression checks, lint and build; actual STEP1 over-limit rejection and retained state; normal OpenAI character analysis, STEP2, STEP3 and one 2240×3168 image generation using a two-person sheet. Automatic image repair was OFF. The generated image was retained with an existing image-QA warning about panel-two balloon order; this release does not guarantee generated image accuracy.

## 日本語

STEP1でキャラシート画像を多く読み込み、STEP3で枚数エラーになる問題を修正しました。現在の枚数と残り枠を表示し、上限を超える追加は解析APIを呼ぶ前に一括で拒否します。既存の画像・設定は保持します。

- OpenAI／Gemini共通で、背景なしはキャラシート14枚、360°背景ONは10枚までです。上限を超える背景ONへの切り替えも拒否します。
- 作風JSONは枚数に含めず、画像データが同一の重複は1枚として扱います。資料を調整した後、同じファイルを選び直せます。
- 1枚に複数人が載っていても画像は1枚です。人数による固定の拒否上限はありませんが、資料の密集による人物の混同・描き分け・台詞対応の誤りは起こり得ます。
- STEP1の説明、英語／日本語のREADME、3冊のPDFを更新しました。旧状態の超過入力とGeminiの送信枚数も生成前に確認します。

検証：読み込み・版更新の回帰検査、lint、ビルド、実画面での超過追加拒否と既存状態の保持を確認しました。2人を載せたシート1枚から、通常のOpenAI解析・STEP2・STEP3・2240×3168画像1回の生成を実行しました。画像の自動修正はOFFです。生成画像には既存の品質検査による2コマ目の吹き出し順の警告が残り、画像を保持しました。生成画像の正確さを保証するリリースではありません。
