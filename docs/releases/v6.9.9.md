# Nano Banana Pro v6.9.9

## English

Final API images now download automatically as PNGs with generation-time production metadata in manual, full-auto and endless modes. Intermediate repair candidates and history selection do not cause duplicate downloads. Manual saving opens a destination picker where supported. Chrome setup guidance appears near saving and before enabling automatic modes; a free two-image download test is available without an API key. Downloads require browser permission and destination-confirmation settings; the app cannot confirm disk completion.

STEP1 restores current image numbers on hover and places compact per-image recognition and character settings in one scrolling area. Adding or deleting references updates numbering while preserving each image's edits. Schema 4 records reference recognition, manual edits, cast and active panorama information in Web companion JSON and API PNG metadata. API records retain the generation-time snapshot. Large PNG downloads use a temporary Blob URL. README and all three PDF guides describe the current workflow and limitations.

## 日本語

API生成の最終画像を、手動・全自動・連続モード共通で、生成時点の制作情報入りPNGとして自動保存します。途中の修正候補や履歴の選び直しでは重複保存しません。手動保存は対応ブラウザーで保存先を選べます。PNG保存付近と自動モード開始時にChromeの設定を案内し、APIキーなしで確認用PNGを2枚保存する無料テストも用意しました。保存場所の確認をOFFにし、利用先の自動ダウンロードを許可する必要があります。アプリからディスクへの保存完了は確認できません。

STEP1の画像にマウスを重ねると現在の番号を表示し、画像ごとの認識と人物設定を同じ枠内でコンパクトにスクロールできます。素材の追加・削除時は番号を更新し、各画像の手編集との対応を保持します。スキーマ4のWeb用JSONとAPI画像内の制作情報には、素材の認識・手編集・人物設定・有効な360°背景の情報を記録します。API画像は生成時点の記録を保持し、大きなPNGも一時的なBlob URLで保存します。READMEと3種類のPDFを現行仕様と制限へ同期しました。
