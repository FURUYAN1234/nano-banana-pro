# Super FURU AI 4-koma System v8.2.0

## English

- An explicitly assigned eye-level camera in a book page now survives STEP2, layout, drawing and review. The page outline can put a panel's medium and camera in consecutive sentences. Ambiguous camera instructions still trigger the existing check.
- When a character crosses a frame, the line and gutter stop behind the visible body and clothing and resume outside the silhouette. Full and compact prompts use the same rule, and image review checks the visible intersection.
- In the color and monochrome test pages for *Waltz After Closing*, the boot and trouser leg crossed from panel 6 into panel 7 with the border behind the leg. Both pages were generated with the app's MCP workflow.

## 日本語

- 本文ページで明示したアイレベルを、台本・構成・作画・査読まで引き継ぎます。コマ番号とカメラが構成案の隣り合う文に分かれていても、そのコマの指定として扱います。
- 人物がコマ枠を越えるときは、腕・脚・衣装など、見えている輪郭の内側で枠線と溝を止め、外側で再開するよう作画指示を揃えました。査読では実際に枠線と身体が重なる箇所を確認します。
- 新規作例『閉館後のワルツ』をMCP経由でカラー・白黒各1ページ作り、6コマ目から7コマ目へ伸びた脚の後ろで、両版とも枠線が途切れることを確認しました。
