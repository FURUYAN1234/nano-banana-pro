# Nano Banana Pro v5.9.9

## 日本語

- Gemini用4コマの脚本ロックを、台詞本文と印字しない話者情報を分ける形式に統一します。ト書きにある右肩・左肩越しの人物指定を、会話の補助指示が反転させる不具合も修正します。
- Gemini APIの画像生成にも、読み込み済みのキャラクターシートを添付します。360°背景が有効で4コマ分の切り出し画像がそろっていれば、それらも送信します。
- キャラと背景の用途説明をAPI送信時だけ追記します。編集欄の本文とコピー内容は変更しません。既存の任意の品質修正にもキャラシートを添付します。
- OpenAIの画像参照・モデル選択、Geminiの背景参照、修正回数は変更しません。参照画像を送っても人物や台詞の完全な一致は保証されないため、生成結果を確認してください。
- 実APIでキャラシート2枚の送信と画像生成を確認しました。追加検証でも余分な台詞や人物重複が残りました。これらを解消済みとするリリースではありません。

## English

- Gemini four-panel script locks now separate printable dialogue from speaker metadata. Explicit left/right shoulder viewpoints in action descriptions are recognized so conversation assistance does not reverse the named shoulder owner.
- Gemini API image generation now includes loaded character sheets, alongside the existing four background crops when the 360-degree background is enabled and all crops are ready.
- Image-role descriptions are appended only for the API request. The editable prompt and copied text remain unchanged. Existing optional quality-repair regeneration also receives the character sheets.
- OpenAI references and model selection, Gemini background references, and repair limits remain unchanged. Reference inputs do not guarantee exact character or dialogue reproduction; review the generated image.
- Real API checks confirmed transmission of two character sheets and image generation. Extra dialogue and duplicated characters remained in the follow-up image; this release does not claim those rendering defects are resolved.
