# Super FURU AI 4-koma System v7.3.7

## Action and panel layout / アクションとコマ割り

- Both serious and gag endings now offer an Action option. Other endings can still stage action when the story calls for it. / シリアスとギャグの両方で「アクション」を選べます。他の結末でも話に必要な動きを描けます。
- In 5–8-panel mode, an explicitly requested frame spanning two rows is carried into layout planning. Limbs and heads may extend beyond an inner frame when the scene calls for it. Camera instructions retain the requested viewing direction and perspective. / 5〜8コマでは、明示した縦2段の一枠をコマ割りへ反映します。演出に応じた手足や頭の枠越えも扱えます。視点の方向と遠近は描画指示に残します。
- Draw sound effects as part of the artwork, outside speech balloons. Silence instructions take priority. / 擬音はフキダシの外に描き文字として入れます。無音の指定を優先します。

## Image review and repair / 画像検査と修正

- Check dialogue ownership from the visible tail and the speaker it points to. A clear sideways tail alone is allowed. Calculate the repair prompt budget using the references actually sent with the repair. / 尾の向きと先の人物を照合します。正しい話者を指す横向きの尾は許容します。修正指示の上限は、その修正で送る参照資料に合わせて計算します。
- Reviewed real API outputs for six drawing styles in color and monochrome and a four-panel gag with two speakers. The reviewed samples retained the dialogue and speaker assignments. Angles and rendering can vary between generations. / カラーと白黒の6画風、話者が二人いるギャグ4コマの実API出力を確認しました。検証画像では台詞と話者の対応を保持できました。角度や描き方は生成ごとに変わります。
