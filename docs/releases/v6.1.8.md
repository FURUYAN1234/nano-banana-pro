# Nano Banana Pro v6.1.8

## English

- GPT-6 Astra is the primary OpenAI route only for STEP2 scenario creation and optional enhancement, with GPT-5.6 Sol and the established GPT-4.1 chain as fallbacks.
- Character analysis, prompt review, and image generation retain their existing model routes.
- Four-panel image QA now distinguishes a readable front from an actively operated rear for two-sided props; insufficient visual evidence remains unverified rather than being treated as a defect.
- Prompt-budget compaction preserves active final-panel staging, distinct physical action, and readable facial acting.

## 日本語

- GPT-6 AstraをSTEP2のシナリオ作成・任意強化だけの優先経路にし、GPT-5.6 Solと既存のGPT-4.1系へ段階的にフォールバックします。
- キャラクター解析、プロンプト査読、画像生成のモデル経路は従来どおりです。
- 四コマ画像QAは、額縁など二面小道具の「見せる表」と「操作する裏」を区別します。画像根拠が足りない項目は不具合と断定せず未検証にします。
- プロンプト予算の圧縮後も、最終コマの能動的な配置、異なる身体動作、読める顔演技を保持します。
