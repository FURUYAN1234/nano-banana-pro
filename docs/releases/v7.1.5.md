# Nano Banana Pro v7.1.5

画像自動修正OFFでは品質検査を行わず、ONでは総合検査1回と重大な破綻の修正を最大1回行います。軽微な違い・根拠不足だけでは再生成せず、修正後の再検査や候補比較APIを追加しません。

コマ修正は元のコマ全体を使い、返却画像全体を同じ座標・寸法に収めます。候補を直接採用・破棄でき、採用画像を制作情報入りPNGで保存します。README・全機能マニュアル・APIガイドを同期しました。

検査時間の短縮や生成画像の完全な品質を保証する変更ではありません。

Automatic image repair OFF skips quality review. ON runs one comprehensive review and at most one correction for material defects, without reinspection or candidate-comparison API calls. Minor or uncertain differences do not trigger regeneration.

Panel edits send the complete original panel and fit the complete returned image into its original coordinates and dimensions. Candidates can be adopted or discarded directly, and adopted artwork is saved as a PNG with production metadata. README, manuals, API guides and diagrams match this release. No inspection-latency improvement or universal image-quality guarantee is claimed.
