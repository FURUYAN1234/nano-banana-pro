# Nano Banana Pro v6.0.0

## 日本語

- 「ギャグを保ってAI精査」を追加しました。接続中の文章APIで、脚本と競合する構図・視線などの補助指示だけを調整します。シュールな出来事、感情のずれ、無反応、意図が曖昧な破綻は保持します。任意操作で追加料金・待ち時間があり、変更理由・前後比較・元に戻す操作を用意しました。
- 品質警告でシナリオ・プロンプト出力を止めず、取得済みの最良候補を保持して続行します。無言コマを明示でき、精査失敗時も元の指示文をコピー・生成できます。
- Web貼り付け用にも、脚本優先、コマ内の瞬間、情報を見せる順序、小道具の状態と持ち主、参照画像の役割を明示します。脚本にあるシュールな変化を整合性指示で消さないようにしました。
- API品質の下に画像サイズを分け、手動の品質・サイズ選択をリロードまで保持します。標準サイズは1024×1536です。Webへコピーする指示文にはAPIサイズを混ぜません。
- 画像QAに実際の最終プロンプトを渡し、タイトル・台詞・手・小道具の確認内容を表示します。未確認は警告として扱います。AI精査・QAの誤判定や画像の描画不良は残り、max品質や大きいサイズが正確さを保証するものではありません。

## English

- Added optional comedy-preserving AI prompt review through the connected text API. Only conflicting auxiliary staging and gaze directions can change; script, dialogue and ending remain intact. Surreal events, emotional mismatch, absent reactions and ambiguous intent are preserved. Reasons, before/after text and undo are available; review incurs additional cost and latency.
- Quality warnings retain the best available scenario and continue prompt/image delivery. Explicit silent panels are supported. Review failures preserve the original, and copying or generation remains available during review.
- Web-copy instructions clarify script priority, panel timing, reveal order, prop state/ownership and reference-image roles. Continuity guidance must preserve scripted surreal changes.
- API image size is separate from quality, defaults to 1024×1536, and manual choices last until reload. API size settings do not alter Web-copy prompts.
- Image QA receives the actual final prompt and reports title, dialogue, hands and prop observations. Missing evidence remains advisory. AI reviews can misjudge outputs, and larger sizes or max quality do not guarantee accuracy.
