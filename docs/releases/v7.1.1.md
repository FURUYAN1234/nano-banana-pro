# Nano Banana Pro v7.1.1

## English

- Add separate OpenAI model selectors for STEP1 image analysis, STEP2 scenario and enhancement, and STEP3 prompt construction and review. Each starts at GPT-6 Luna; Model Chain shows the active routes. Local Luna validation stops on failure for STEP2 and STEP3.
- Add up to 60 seconds of STEP2 voice input. Stopping sends the recording to the connected OpenAI or Gemini transcription API and appends editable text. Recordings are not stored in app history; API charges may apply.
- Add an optional button that loads two bundled JPEG character sheets through the ordinary STEP1 material path. STEP1 analysis may incur provider charges.
- Stack progress, controls and help in the workflow header, clarify the current ON/OFF state of automatic modes, and improve control spacing. Add a linked demo image to the README.
- The local focused checks and earlier real OpenAI/Gemini API observations cover the changed controls and routes. Generated images still require visual review; this release does not claim a new image quality guarantee.

## 日本語

- OpenAIのSTEP1画像解析、STEP2台本・強化、STEP3描画指示・確認のモデルを個別に選べるようにしました。初期値はそれぞれGPT-6 Lunaです。Model Chainには有効な経路を表示し、ローカル検証のSTEP2・STEP3ではLunaの失敗時に別モデルへ切り替えず停止します。
- STEP2に最大60秒の音声入力を追加しました。録音を停止すると、接続中のOpenAIまたはGemini APIで文字起こしし、編集可能な文章を追記します。録音はアプリ履歴へ保存せず、API料金が発生する場合があります。
- 同梱JPEGキャラシート２枚を通常のSTEP1素材登録へ渡す任意のボタンを追加しました。後続の解析にはAPI料金が発生する場合があります。
- 上部の進捗・操作・補助を縦に整理し、自動モードの現在のON/OFF表示とボタン間隔を改善しました。READMEにデモサイトへの画像リンクを追加しました。
- 変更箇所のローカル検査と既存のOpenAI・Gemini実API観測結果を確認しました。生成画像の採否は実画像で判断し、今回の版で画質の普遍的な改善を保証するものではありません。
