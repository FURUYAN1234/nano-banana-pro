# Nano Banana Pro v6.6.2

## 日本語

- STEP4の番号付き分割コピーボタン同士に12pxの間隔を設けました。ボタンの高さと青から薄い青への順番表示は維持しています。
- 「全文を一括コピー」の上下には20pxの余白を設け、ボタンを黄色に変更しました。分割コピーとの押し間違いを減らします。
- コピー成功後は押した番号のボタンだけチェック印と「コピー完了」を約2秒表示します。全文コピーとTXT保存も完了文言と控えめな内側の影を出し、元のボタン色を保ちます。
- Web貼付の説明を分割ボタンの上に統合し、重複する手動生成ガイドを削除しました。全文コピーの直下にTXT保存を置き、淡い無彩色にして視認性を改善しました。制作情報JSONはその下へまとめ、画像生成指示文ではなく制作条件を引き継ぐ別記録である理由を表示します。
- 「ChatGPT Webへの貼り付け手順」見出しを追加し、全文コピーのボタンに合計文字数を表示しました。TXT保存は「全文プロンプトを.txtで保存する」に改め、制作情報JSONとの間を16px空けました。
- 実画面で分割間12px、全文コピーの上下20pxを測定しました。プロンプト本文、分割文字数、API生成経路は変更していません。

## English

- Added 12px of space between the numbered STEP4 copy buttons while retaining their compact height and progressively lighter blue colors.
- Set the full-copy action apart with 20px of space above and below and an amber face to make accidental selection less likely.
- After a successful copy, only the pressed numbered button shows a check mark and “コピー完了” for about two seconds. Full copy and TXT save use matching text and subtle inset feedback without changing their base colors.
- Consolidated Web paste guidance above the numbered actions and removed a duplicate hint. TXT save now sits directly below full copy in a readable light neutral color; the separate production-record JSON follows with its purpose explained.
- Added a larger Web-paste heading, the total character count on full copy, a clearer TXT-save label, and 16px of separation before the JSON action.
- Measured the spacing in the running app. Prompt content, chunk lengths, and the API image route remain unchanged.
