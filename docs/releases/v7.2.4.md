# Super FURU AI 4-koma System v7.2.4

Removed the header badge that retained the last model name with a generic “text generation” description. Use each STEP's model selector and processing log to check its model. / 最後のモデル名と定型の「テキスト生成」を残すヘッダーバッジを削除しました。モデルは各STEPの選択欄と処理ログで確認します。

Added a “不具合調査ログ” button beside STEP4. Its panel opens directly below the Super FURU title frame and on the crash screen. It records version/settings, execution and request IDs, HTTP results, response model IDs when supplied, error codes and reduced source locations. An AI operating the browser can read it, or the user can save/copy its JSON. Logs are not automatically sent to an external service. / 「4 画像生成」の横に「不具合調査ログ」ボタンを追加しました。Super FURUのタイトル枠の直下、またはクラッシュ画面に説明枠が開きます。版・設定、実行と通信のID、HTTP結果、応答に含まれるモデルID、エラーコードと発生元を記録します。ブラウザーを操作するAIが読めるほか、JSONの保存・コピーで渡せます。外部サービスへの自動送信はしません。

Records stay in the same browser/origin for seven days, with oldest-first eviction at 2 MiB of event data or 2,000 events. Pruning runs on startup/read/write and hourly while open. Storage failure falls back to bounded memory with a visible warning. API keys, headers, image bodies, full input/prompt text and full exception messages are excluded. / 同じブラウザー・同じURLの保存領域に7日分を残し、記録データ2MiBまたは2,000件を超えると古い方から削除します。起動・閲覧・記録時と画面を開いている間は1時間ごとに整理します。保存できない場合は一時記録へ切り替え、警告します。APIキー、ヘッダー、画像本体、入力・プロンプト全文、例外メッセージ全文は保存しません。

Real API validation exposed an execution-ID split during STEP1 file intake; the corrected logger keeps preparation, request and completion linked and records the actual sent image count. HTTP success and an ended busy state remain separate from content/quality acceptance. / 実API検証で見つかったSTEP1取り込み中の実行IDの分断を修正し、準備・通信・終了を対応させ、実際の送信画像数を記録します。HTTP成功や処理終了と、内容・品質の合格は区別します。

The whole panel, including explanations and actions, scrolls beneath its fixed title area. Smaller text, adjacent close controls and spacing before auto-save settings keep it readable. The JSON retains its white background and black text. New errors open the panel automatically; normal results and cancellation do not. / 説明・操作を含む枠全体を固定エリア内でスクロールできます。文字を小さくし、見出しの横と枠の下端に閉じるボタンを置き、自動保存欄との間に余白を設けました。JSONは従来どおり白背景・黒文字です。新たなエラー時は自動で開き、正常終了や中断では開きません。

The manual sits to the left of STEP1; Model Chain sits to the right of the log button. Removed the title icon and SOCIAL tagline, reduced title spacing and made the engine label larger without its pill border. One fixed block now spans the top controls through the Super FURU frame, extended through the log when open. Its measured height reserves page space and STEP navigation clearance; node replacement during development cannot retain a detached zero-height measurement. / マニュアルは解析の左、Model Chainは調査ログの右へ移動しました。タイトルのアイコンとSOCIAL表記を削除し、余分な空行を詰め、エンジン表示は丸枠を外して少し大きくしました。上部操作欄からSuper FURU枠まで、ログを開くとログ下端までを一つの固定枠とし、実際の高さで本文の余白とSTEP移動位置を確保します。開発時に要素が置き換わっても、古い要素の高さ0を引き継がないようにしました。

Every schema-version-2 export includes readable UTC times and operation names, a generic four-stage application specification, investigation steps, evidence limits and a response outline distinguishing confirmed facts, inferences and unknowns. Older retained events gain readable context when read. The specification contains no personal names or source-material names. Users can pass the whole JSON with a brief symptom. The API connection dialog is now centered, with responsive width and overflow handling. / schemaVersion 2のJSONにはUTC時刻・操作名、固有名詞を含まない4段階の仕様要約、調査手順、証拠の限界、確認済み・推測・未確認を分ける回答指針を毎回同梱します。保持中の古いイベントにも閲覧時に読みやすい時刻・操作名を付けます。JSON全体と簡単な症状を渡して調査できます。API接続窓は画面中央に配置し、狭い画面にも収まる幅とスクロールに対応しました。
