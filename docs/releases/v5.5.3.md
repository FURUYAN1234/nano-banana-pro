## Nano Banana Pro v5.5.3

### 日本語

- STEP4のMiniMax H3案内を、標準ComfyUIワークフローでプロンプトだけを使う手順と、Nano Banana画像変換からMiniMax H3動画化までを一連で扱う専用ワークフローJSONの手順に分離しました。
- 専用JSONはSTEP4からダウンロードでき、公開サンプル漫画を初期選択した状態で配布します。H3生成プロンプトとNano Banana画像変換指示は空欄です。
- 配布JSONにはAPIキー、個人画像、生成済み動画を含めません。必要なComfyUI本体、モデル、カスタムノード、Gemini・OpenAI APIまたはLM Studioの利用条件を案内します。

### English

- Split the STEP4 MiniMax H3 guidance into a prompt-only path for a standard ComfyUI workflow and a dedicated workflow-JSON path for the end-to-end Nano Banana image-conversion and MiniMax H3 video flow.
- The dedicated JSON is downloadable from STEP4, starts with the public sample manga selected, and leaves both the H3-generation prompt and Nano Banana image-transform instruction empty.
- The distributed JSON contains no API keys, personal images, or generated videos, and documents the required ComfyUI runtime, models, custom nodes, and Gemini, OpenAI, or LM Studio options.

### Verification

- Verified the exact H3 prompt copied by the STEP4 control in the in-app browser.
- Verified the workflow-JSON download in the in-app browser, then parsed the saved JSON and matched its SHA-256 with the distributed asset.
- Added regression coverage for the separate UI paths, native download element, workflow sanitation, and shared action appearance.
