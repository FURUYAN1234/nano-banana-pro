# Nano Banana Pro v6.8.7

## Changes

- Keep the outer page frame inside the canvas in API and Web-paste instructions. Camera direction follows the scene rather than a fixed rotation; motivated motion blur remains available.
- Focus on the speaker, reaction or main action while preserving readable evidence and physical contact. Cast-count checks no longer require every person and background object to share the same focus.
- Choose styles and endings from the scene and its causal payoff. Recent completed endings inform repeated-mechanism checks without quotas or forced novelty.
- Automatic repair OFF also disables policy repair. When ON, an unchanged, previously rejected or invalid proposal is withheld from the image API and its reasons inform another proposal. Preserve valid prompts and obtained images; count revision reviews and image requests separately.
- Update the README and PDF manuals. Generated image fidelity remains variable; the inspected image was accepted with a low-angle foot-crop warning. API recovery with the new feedback loop has not been demonstrated live.

## 変更内容

- API・Web貼り付け用の指示で、外枠四辺をキャンバス内に収める指定を統一。カメラは場面に応じて選び、固定方位の巡回を廃止しました。動作に合うモーションブラーも利用できます。
- 話者・反応・主動作へ焦点を置き、必要な文字や接触を読めるように指定。人数確認のため全員や背景まで同じピントに揃える指示を見直しました。
- 絵柄と結末は場面と因果から選択。直近の完成作品と同じ仕組みの繰り返しを確認し、均等ノルマや新奇さだけの変更を避けます。
- 自動修正OFFを安全判定後の修正にも適用。ON時の無変更・拒否済み文への逆戻り・必須設定違反は画像APIへ再送せず、不採用理由を次の案へ渡して検討を続けます。有効な指示文と取得済み画像を保持し、修正検討と画像再生成の回数を分けて表示します。
- READMEとPDFマニュアルを更新。画像の完全再現は保証しません。確認画像はアオリの足先見切れを注意事項として条件付き採用しています。新しい再検討方式による実API復旧成功は未実証です。
