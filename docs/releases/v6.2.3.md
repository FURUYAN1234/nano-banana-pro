# Nano Banana Pro v6.2.3

## English

- The visible Model Chain now matches the active OpenAI scenario route: GPT-6 Astra, GPT-5.6 Sol, then the established GPT-4.1 chain.
- STEP4 now distinguishes the verified-model default (GPT Image 2.5 Sunburst), an explicitly selectable alternative (GPT Image 2.5 Flare), and the GPT Image 2.0 fallback selection used when 2.5 is unavailable.
- The pre-deploy check now compares the snapshot against text, scenario, vision and image-setting routes, so a route-only change cannot leave the displayed chain stale.

## 日本語

- 画面のModel Chainを、STEP2のOpenAI実行経路であるGPT-6 Astra、GPT-5.6 Sol、既存のGPT-4.1系へ同期しました。
- STEP4では、認証済み時の初期選択であるGPT Image 2.5 Sunburst、明示選択できるGPT Image 2.5 Flare、2.5が利用できない場合のGPT Image 2.0初期選択を区別して表示します。
- pre-deployチェックは、通常テキスト、シナリオ、Vision、画像設定の各経路をスナップショットと比較します。経路だけが変わって表示が古いまま残る状態を検出できます。
