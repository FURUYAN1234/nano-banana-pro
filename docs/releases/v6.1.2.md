# Nano Banana Pro v6.1.2

- Added a persistent Color/Monochrome selector to STEP3. Color remains the default; STEP1/STEP2 resets retain the selection, while a full settings reset returns it to Color. Changing mode clears the old prompt and current preview without starting generation. / STEP3に保持式のカラー／白黒切替を追加しました。初期値はカラーで、STEP1・STEP2からのやり直しでは選択を保持し、全設定リセットでカラーへ戻ります。切替時は古いプロンプトと現在のプレビューを消去しますが、自動生成は開始しません。
- Monochrome uses the same contract for API and Web copy: white paper and lit skin, black ink and fills, black-on-white halftone or hatching, pressure-varied G-pen lines, dynamic staging, and simplified nonessential background detail. Source colors from arbitrary character sheets are treated as identity metadata and converted to stable ink or tone regions. / 白黒ではAPIとWeb貼付に同じ指示を使い、白い紙面と肌の明部、黒インクとベタ、白地の網点またはハッチング、強弱のあるGペン線、動きのある構図、不要な背景細部の整理を指定します。任意のキャラクターシートの色は同一性情報として扱い、固定した黒・白・網点領域へ変換します。
- Actual OpenAI API and ChatGPT Web-paste runs used the rebuilt STEP3 prompt with the same two character-sheet images. Visible pink and other source hues were removed in both final samples. The PNG channel values were not mathematically exact monochrome or binary, and the Web result did not preserve every requested cast and panel detail. / OpenAI APIとChatGPT Web貼付の実生成では、再構築したSTEP3プロンプトと同じキャラクターシート2枚を使用し、最終作例から目視できるピンク等の色残りが消えました。一方、PNGの画素値は数学的に厳密な白黒二値ではなく、Web結果は指定した全人物とコマ構成を完全には保持しませんでした。
- Simplified STEP3/STEP4 copy: the prompt heading is `最終プロンプト`, the edit guidance sits below the status log, the API-only implementation note is removed, and the generation button reads `APIで画像をアプリ内で生成する（STEP4）`. / STEP3・STEP4の表示を整理し、見出しを`最終プロンプト`、編集案内を状況確認窓の下へ配置し、API専用の実装説明を削除、生成ボタンを`APIで画像をアプリ内で生成する（STEP4）`へ変更しました。
- This release does not add a finishing-image import, pixel-conversion tool, or publisher preflight. The separately distributed FourPanel v6.0.9 workflow JSON and custom-node ZIP are unchanged. / 仕上げ用画像読込、画素変換、投稿先向け入稿検査は追加していません。別配布のFourPanel v6.0.9ワークフローJSONとカスタムノードZIPは変更していません。
