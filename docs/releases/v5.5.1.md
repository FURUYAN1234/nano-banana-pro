## Nano Banana Pro v5.5.1

### 日本語

- MiniMax H3の会話優先・話者口パク固定・字幕なし・既定BGMなしを維持しました。
- 各コマで全員に役割に合った動きと個別反応を指示し、静止画のような背景人物を避けます。
- 4カットで寄り引き、横移動、縦移動、回り込みを使い分け、回り込みなどの非直線移動は開始・中間・終了状態まで指定します。
- カメラは話者を隠さず、話者の口パクを保ちながら動くよう調整しました。

### English

- Retained dialogue-first audio, speaker-bound lip sync, no subtitles, and no default BGM for MiniMax H3.
- Requires role-appropriate movement and individual reactions for every visible character in each panel.
- Varies push-pull, lateral, vertical, and orbiting camera paths across the four shots, with start, midpoint, and end states for non-linear moves.
- Keeps the named speaker legible during camera motion instead of removing movement for dialogue.

### Verification

- The new MiniMax H3 acting-and-camera regression test failed before the prompt change and passed afterward.
- Existing MiniMax H3 helper coverage remains in the same focused test suite.
