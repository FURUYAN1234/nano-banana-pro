# Nano Banana Pro v6.2.1

## English

- Reference-sheet clothing is excluded from the identity context passed to STEP2 scenario creation and direction enhancement. Names, face and hair traits, personality, voice and relationships remain available.
- Automatic outfits now follow the user subject, source, event, role, location and season. Explicit wardrobe input remains authoritative. School attire is retried when the input does not ground it; an invented student role cannot supply that grounding. Actual school contexts and professional uniforms remain valid.
- When an Outfit is set, both Color and Monochrome image-prompt paths also exclude reference-clothing fields, including the image-cast fallback. JSON-form scenario responses retain Outfit metadata.
- A fresh GPT-6 Astra scenario with an empty outfit field selected smart casual for a long-life celebration at a community hall. GPT Image 2.5 Sunburst / xhigh created one Color and one Monochrome 1024x1536 page, both visually in casual attire. This confirms the corrected path for this input, not a universal output guarantee.
- The two images still have non-wardrobe limitations: multiple sweets weaken the one-serving gag, some requested full-body/camera framing is incomplete, and detailed identity/prop fidelity remains image-by-image review work. Automatic image repair was off; no repair image was generated.

## 日本語

- STEP2のシナリオ作成・演出強化へ渡すキャラ情報から、キャラシートの参考衣装を除外します。名前、顔・髪の特徴、性格、口調、関係性は維持します。
- 自動衣装はユーザー入力・原文・行事・役割・場所・季節から選び、手入力衣装を最優先します。入力に根拠のない学校制服は再試行対象とし、生成した学生役を根拠には使いません。学校行事や職業制服は引き続き有効です。
- Outfitが確定している場合、カラー・白黒の画像プロンプト経路とキャスト抽出フォールバックからも参考衣装欄を除外します。JSON形式のシナリオ応答でもOutfitメタデータを保持します。
- 衣装欄を空欄にした市民会館の長寿祝いで、GPT-6 Astraはきれいめの私服を選択しました。GPT Image 2.5 Sunburst / xhighでカラー・白黒各1枚を1024×1536で生成し、両方の私服を目視確認しました。これは今回の入力での修正経路の確認であり、すべての出力を保証するものではありません。
- 2枚には衣装以外の未達もあります。一人分の菓子が複数に見えること、指定した全身・カメラフレーミングの未達、人物・小道具の細部忠実度は生成ごとに目視確認が必要です。自動画像修正はOFFで、修正画像は生成していません。
