# Super FURU AI 4-koma System v8.0.4


Book-detail authoring now actively considers large foreground figures and connected panel crossings around the strongest story moment. Two- and three-panel pages compare free layouts instead of beginning with fixed vertical stacks and empty crossing arrays. / 複数ページの詳細台本で、物語の見せ場から大きな前景人物や一続きの枠越えを検討します。2・3コマも固定の縦積みと空の越境配列から始めず、自由配置を比較します。

Up to six preceding comic-page structures guide layout comparison. Only coarse geometry and emphasis are carried over; characters, dialogue and cameras are excluded. Explicit composition and intentional repetition take priority. / 直前の最大6ページの構成を比較資料として使います。引き継ぐのは配置と見せ場の骨格だけで、人物・台詞・カメラは含めません。明示構図と意図した反復を優先します。

Crossings are not a per-page quota. Quiet scenes can retain their stillness with scale contrast inside frames. The accepted story, exact dialogue, camera and drawing style remain unchanged; natural border crossings and minor proportional differences alone do not require regeneration. / 全ページに枠越えを強制しません。静かな場面は枠内の大小差でも表現できます。承認済みの物語・台詞・カメラ・描線を保持し、自然な枠越えや比率の微差だけで再生成しません。

Visible physical body references resolve unique qualified short names, and an explicitly named party anchors collective camera/action references. Mixed cast counts use physical bodies; quoted, offscreen and depicted figures remain distinct. / 省略された敵名を身体参照から照合し、名前を明示した集団をカメラや動作の集合表現へ対応させます。人と獣の混成人数は身体数で表し、引用・画面外・画中の人物とは区別します。

Costume/material project exports can be linked to the current work's save folder, preserving all existing PNG/JSON pairs and future saves under its materials. Originals and conflicting files remain protected. / 衣装・資料の別作品を現行作品の保存先へ関連付け、過去と以後のPNG・同名JSONを「資料」へまとめられます。元ファイルを保持し、異なる保存先内容は上書きしません。

Document quotations remain source lettering unless explicitly spoken, and silent foreground bodies are retained. Provisional reference labels and scripted role names use scene-based casting instead of a new confirmation UI. / 書類の引用を不要な台詞へせず、無言の前景人物を保持します。参照の仮名と台本の役名の違いは場面から対応を補い、新しい確認UIは追加しません。

Book authoring explicitly compares a full- or half-body foreground placed before surrounding panels with an in-frame large-panel design; a limb-only crossing does not replace a page-dominant figure. Title-off instructions now honor explicitly authored full-bleed edges without removing margins from other edges. / 本の台本では、大きな全身・半身を小コマより先に置く案と、枠内の大コマで見せる案を比較し、部位だけの越境でページ大の人物を代用しません。タイトルOFF時も、明示したタチキリ辺を優先し、他の辺の余白は保ちます。

History selection saves the chosen image with its own retained generation context and normalizes the checkpoint and post-save UI to one selected item. Wrong generation metadata is still rejected; a failed save does not switch the displayed image. / 履歴選択では対象画像自身の生成情報で保存し、保存時と保存確認後の画面を1件だけ選択した状態へ揃えます。異なる生成情報は引き続き拒否し、保存失敗時に表示画像を切り替えません。

Candidate verification covered the normal two-page monochrome image flow, the original reported STEP3 quotation/silent-role case after actual material recognition, and keyless selection/export of existing four-panel histories. The history test retained the original OpenAI provenance and verified saved/displayed source pixels plus exact scenario, prompt and settings. These scopes do not imply every API branch was exercised with the final bundle. / 候補では、白黒・全2ページの通常画像経路、実際の素材認識後に元の引用・無言役を使うSTEP3経路、既存4コマ履歴のキーなし選択・保存を確認しました。履歴試験では元のOpenAI生成情報を保持し、表示・保存画像の画素と台本・指示文・設定の一致を確認しています。これらを最終bundleの全API分岐の検証と同一視しません。

The final monochrome two-page sample used a tall right-hand hero scene with two smaller scenes on the left; a large connected torso/hip/leg crossing was visible in the first image from the normal scenario→prompt→image flow. Cast and boot defects were then corrected with ordinary image edits. This does not prove a root fix for gaze/anatomy generation. / 最終の白黒・全2ページ作例は、右の縦長大コマと左の小コマ2つを使い、通常の台本→指示文→画像の初回から胴体・腰・脚の大きな一続きの越境を確認しました。人物とブーツ形状の誤りは、その後の通常の画像修正で直しています。視線や人体生成の根本修正を実証したという意味ではありません。 A subsequent color comparison used the final v8.0.4 runtime through the normal image flow: one generation, one automatic repair and one ordinary image edit corrected real duplicate/missing cast. The reviewed result retained a large connected body crossing, boots/shield contact, five returning actors and the ending. It is not a one-shot or universal-quality guarantee. / 続いて最終v8.0.4の通常画像経路でカラーも比較し、初回生成・自動修正1回・通常の画像編集1回で人物の重複と欠落を直しました。採用画像は、大きな一続きの身体の枠越え、ブーツと盾の接触、終コマの5人、結末を保持しています。一発生成や全入力での品質保証ではありません。

Receiving-panel cast counts exclude mentions of a foreground body owned by another scene while retaining an actor who genuinely acts or speaks again in the local scene. Long registered names are not mistaken for shorter foreground-owner aliases; an explicitly registered name wins over a derived alias. The actual retained snapshot was revalidated/recompiled before and after the fix: local counts changed only from6/6/5 to6/5/5, with dialogue, cameras and the final reappearance preserved. This was deterministic validation, not a new API image run with the latest code; the connected image-generation tab retained its earlier bundle. / 別場面が所有する前景身体への言及を受け側の人数へ重複加算せず、その場面で実際に行動・発話する再登場は残します。長い登録名の内部を短い前景所有者の別名と誤認せず、派生別名より明示登録の正式名を優先します。保存済みの実snapshotを修正前後の正規validator/compilerへ通し、人物数だけが6/6/5から6/5/5へ変わり、台詞・カメラ・終コマの再登場は保持されることを確認しました。これは決定的な処理の検証であり、接続キーを保持した画像生成タブは以前のbundleのままです。最新コードを読み込んでAPI画像生成した証拠とはしていません。

When image production is also requested, the scenario skill carries conditional composition checks into the handoff: place the principal body action before surrounding beats when suitable, distinguish its crossing silhouette from later actors, check leg→shoe→contact continuity, and correct material defects while retaining a strong layout. It imposes no fixed coordinates, cast, drawing style or per-page crossing quota. / 画像制作も依頼された場合の引継ぎでは、場面に適すれば主動作の身体を先に置いて周辺場面を組み、越境身体と別時点の人物を区別し、脚→靴→接触面を確認します。強い構図を保って実害のある箇所だけを直し、固定座標・人物・画風や毎ページの枠越えを課しません。
