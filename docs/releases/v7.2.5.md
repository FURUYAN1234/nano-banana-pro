# Super FURU AI 4-koma System v7.2.5

Fixed STEP1 character matching when a reference name includes a label such as `仮名` or `Temporary Name` and the corresponding profile heading has already been normalized. Photo references can now use the same name-label handling as character sheets. / STEP1で、画像側の人物名に「仮名」「暫定名」などのラベルが付いていると、ラベルを除いた人物設定の見出しと一致せず解析エラーになる処理を修正しました。写真の人物参照にも、人物設定と同じ名前ラベルの処理を適用します。

Full character names take precedence over aliases. Aliases must identify one character, and ambiguous or missing matches still produce an analysis error. / 正式な人物名の一致を別名より優先します。別名から人物を特定する場合も候補を一人に絞り、複数候補や対応の欠落は解析エラーにします。

The README, manual source and diagnostic export specification describe the updated matching behavior. / README、マニュアル原稿、調査ログに同梱する仕様説明へ照合処理を反映しました。

Verified in the normal STEP1 flow with GPT-6 Luna. Adding a photo with three people preserved all five existing profiles and their edits. The added profiles supported two-way renaming and copying, then were removed when their source photo was removed. / 通常のSTEP1をGPT-6 Lunaで検証しました。3人が写る写真を追加しても、既存5人の設定と手編集を保持します。追加した人物の双方向の改名とコピー、写真を削除した際の人物設定の取り除きも確認しました。
