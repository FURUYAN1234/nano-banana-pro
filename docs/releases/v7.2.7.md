# Super FURU AI 4-koma System v7.2.7

- **Background simplification / 背景の簡略化**: STEP4 adds an optional background treatment, off by default. When enabled, location and movement panels retain a few landmarks, while dialogue and reaction panels can use broad shapes and color fields. The prompt preserves each panel's character drawing style, story props and lettering. / STEP4に「背景を簡略化・デザイン化」を追加しました。初期状態はOFFです。ONでは場所や移動を示すコマに目印を残し、会話や反応のコマでは背景を大きな色面や図形に整理します。人物のコマ固有の絵柄や描き込み、物語に必要な小物と文字は維持するよう指示します。
- **API and Web / API・Web対応**: The same editable final prompt is used for ordinary API generation and Web paste. Switching the option off restores the original prompt. / 通常のAPI生成とWeb貼り付けは、同じ編集可能な最終プロンプトを使います。OFFに戻すと元の指示文に戻ります。
- **Four-panel A4 layout / 4コマのA4配置**: When fitting panels to the page width would create large blank strips, the app fits the entire original page to retain its panel spacing. / 横幅に合わせてコマを配置すると白帯が広がりすぎる場合は、元ページ全体をA4に収めてコマ間隔を保ちます。
- **Verification / 検証**: Compared on and off in the regular workflow with two character reference sheets and five characters: a six-panel OpenAI example and a four-panel Gemini example. In the selected comparisons, backgrounds became simpler while visible character detail was retained. Generations vary; check the actual image. / キャラシート2枚・5人の通常ルーチンで、OpenAIの6コマとGeminiの4コマをON／OFF比較しました。最終比較例では、人物の描き込みを残したまま背景の整理を確認できました。生成ごとに結果は変わるため、実際の画像をご確認ください。
