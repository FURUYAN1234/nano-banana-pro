# Nano Banana Pro v7.1.3

## English

- Click a completed STEP in the top progress bar to return to it while keeping inputs, scenarios and generated work. Keyboard activation is supported.
- Share navigation with the existing STEP4 return menu. Block navigation during processing, stopping, full-auto mode or disconnection; current and unfinished steps remain informational.
- Keep destination headings below the fixed header and fit the progress tiles on narrow screens. Update the README and all three PDF guides.
