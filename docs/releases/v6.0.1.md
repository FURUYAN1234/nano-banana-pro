# Nano Banana Pro v6.0.1

## 日本語

- STEP3のプロンプト構築時にギャグを保つAI精査を自動実行します。任意の精査ボタンを廃止し、適用できない提案や通信失敗では元の指示を保持して続行します。台詞・オチ・意図されたシュールな出来事は保護します。
- 人物と物体の境界、画面や資料の表裏、読む人物とカメラの位置、物体に固定した印字の向きを共通指示へ追加しました。人物不一致の検査には位置・識別特徴・参照根拠を要求します。
- APIの通常修正版にNGや判定不能が残っても直接比較し、改善を確認できた候補を警告付きで保持します。同じ装飾印字の問題が通常修正後も確認された場合だけ、読めない印字模様にする最終候補を1回追加できます。台詞・タイトル・物語に必要な文字は対象外です。通常1回＋条件付き1回の追加画像と検査にはAPI料金が発生します。
- STEP4のAPI品質・サイズ、Web用の画像比率修正・アップスケール、動画化の案内を折り畳みに整理しました。画像生成ボタンを上へ移し、ログの文字サイズと行間を揃えました。
- 検証：全Nodeテスト・lint・ビルドを実施。内蔵ブラウザの実OpenAI画像APIで完成画像と警告付き継続を確認しました。最終試行では背文字の問題が残り、QA応答の解析に失敗したため追加修正は発動しませんでした。条件付き印字修正の実画像効果は未確認です。誤検出・見逃し・描画不良がなくなることを保証する更新ではありません。

## English

- STEP3 now performs comedy-preserving review automatically before delivering the prompt. The optional review control is removed. Invalid suggestions or failed review requests preserve the original instructions and continue; dialogue, ending and intentional surreal events remain protected.
- Shared prompts clarify object/body boundaries, functional front/back surfaces, reader/camera placement and object-fixed print orientation. Character mismatch claims require localized identity and reference evidence.
- Completed API repairs are compared even with residual failed or unresolved QA. A confirmed improvement is retained with a warning. A recurring confirmed incidental-print defect may trigger one final illegible-print-texture candidate after the ordinary repair; dialogue, title and story-required text remain protected. Up to one ordinary plus one conditional additional image and reviews incur API charges.
- STEP4 quality/size, Web aspect/upscale help and video guidance use collapsible sections. The image-generation button is placed above them and log typography is aligned.
- Validation includes Node tests, lint, build and real OpenAI image generation in the in-app browser. The final run retained a completed image with a warning: spine-lettering concerns remained and the QA response could not be parsed, so no extra repair ran. Live effectiveness of the conditional print fallback is unverified. This release does not eliminate false detections, missed defects or drawing errors.
