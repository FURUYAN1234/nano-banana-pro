# Nano Banana Pro v6.1.9

## English

- Monochrome prompt construction now retains dramatic lighting as directional black shadows, white rim highlights, contrasting screen masses, camera perspective, contact shadows, and full-body acting rather than flattening those qualities when source color is removed.
- Style-specific proportion directions that do not depend on color are shared by Color and Monochrome; Serious Documentary continues to preserve the reference proportions.
- The compact Web prompt retains the same physical-depth and lighting direction as the full API prompt.
- A live GPT Image 2.5 Sunburst monochrome sample confirmed stronger foreground depth while retaining background setting. Exact dialogue, hands, props, camera fidelity, and parity with Color remain subject to per-image visual review; this release does not guarantee identical visual strength.
