# Nano Banana Pro v6.3.5

## 日本語

- 4コマの台詞を右から左、上から下の読順に固定し、各吹き出しの尻尾を指定話者の口・頭へ対応付ける共通ルールを強化しました。人物の位置やカメラが変わっても、台詞と話者を近さで入れ替えません。
- ChatGPT/Geminiの短縮プロンプトにも話者・尻尾対応を残し、画像品質QAが台詞の話者違いを独立して検出できるようにしました。
- 既存のカメラ演出、画像内の実文字確認、ギャグ／シリアスの演出分岐を維持したまま、関連回帰テスト、全テスト、lint、production buildを通過しました。

## English

- Strengthened the shared four-panel rules to keep dialogue in right-to-left, top-to-bottom reading order and to bind every speech-bubble tail to its scripted speaker's mouth or head. Characters and camera changes no longer allow proximity-based speaker swaps.
- Preserved speaker-tail mappings in compact ChatGPT/Gemini prompts and added an independent image-QA check for wrong dialogue speakers.
- Kept existing camera direction, rendered-text review, and gag/serious branching intact; focused regressions, the full test suite, lint, and the production build pass.
