# Super FURU AI 4-koma System v8.0.3

Startup now shows update, download, extraction and launch stages. An already verified current installation starts without rehashing every dependency; failed interactive launches keep the explanation visible. / 起動時に更新確認・ダウンロード・展開・起動の段階を表示します。検証済みの同じ版は全依存ファイルの再検証を省き、対話起動に失敗した場合は理由を画面に残します。

The API dialog places the usage, OpenAI API and Gemini API manuals in one row and the skill download below the center. Narrow screens use a single column. / API接続画面は使い方・OpenAI API・Gemini APIの3マニュアルを横に並べ、次の段の中央にスキル取得を置きます。狭い画面は縦一列です。

The bundled manga skill focuses on scenario construction and revision for one-page, short, medium and long stories. It includes self-contained references, keeps drawing style with the app, and asks for the author's chosen name. Skill-only updates also follow the release and announcement workflow. / 同梱スキルは1P・短編・中編・長編のシナリオ構築と改稿に特化し、資料を内蔵します。描画はアプリに任せ、作者名は利用者の指定を確認します。スキルだけを更新する場合も、公開と告知の手順を通します。

Outline planning receives effective settings for every page. Cover title, watermark and mosaic flags now agree with saved metadata; monochrome covers carry the same mode lock as their image request. Actual scenario-model provenance is retained across book-page application and recognition. / あらすじ作成へページ別の有効設定を渡します。表紙の題字・ウォーターマーク・モザイク設定を保存情報と一致させ、白黒表紙は画像送信まで同じモードを保ちます。ページ適用や認識後も実際のシナリオ生成モデルを保持します。

Meaningful plan changes retire stale active scripts, prompts and generated images, with previous drafts retained in project history. Identical plans preserve accepted pages and manual edits. / 計画の意味が変わった場合は古い台本・指示文・生成画像を失効させ、以前の編集状態は作品の履歴へ退避します。同じ計画では採用済みページと手編集を保持します。

Cast counting resolves unambiguous shortened Japanese names in actor clauses and qualified nonhuman names in visible body/action references. Silent background actors are retained; quoted mentions, shared names and absent characters are not treated as visible bodies. / 人数判定は、日本語名の一意な短縮主語と、非人間の修飾名を身体・動作の参照から照合します。無言の背景人物を保持し、引用だけの言及、共有名、不在人物は出現の根拠にしません。

The three PDF manuals are synchronized to v8.0.3. A required release gate checks the latest manga-skill review and its exact content hash. / PDF3冊をv8.0.3へ同期しました。公開前の必須検査で、最新のスキル見直し記録と内容ハッシュを照合します。

Production CSS now scans only application sources and the entry HTML, so tests and local documents cannot change the distributed styles. / 配布用CSSの検出対象をアプリのソースと入口HTMLに限定し、テストやローカル文書の有無で生成スタイルが変わらないようにしました。

Official Standard prices for the 16 configured OpenAI/Gemini models were checked on 2026-11-17; stored numeric rates are unchanged. Batch discounts remain separate. / 2026年11月17日にOpenAI・Geminiの設定済み16モデルの公式Standard料金を確認し、保存済みの数値単価に変更はありません。Batch割引とは区別しています。
