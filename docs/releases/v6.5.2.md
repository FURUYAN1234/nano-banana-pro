# Nano Banana Pro v6.5.2

## 日本語

- STEP2のOpenAIシナリオモデルにGPT-6 SolとGPT-6 Lunaを追加しました。既定は引き続きGPT-6 Astraです。
- 選択したモデルから後続候補だけへフォールバックし、GPT-6／GPT-5.6系は現在のChat Completionsパラメータで実行します。
- プルダウンの括弧書きと下部の参考単価を、2026-09-23時点の公式短文コンテキスト・標準処理価格に合わせました。参考値にはツール料金、キャッシュ割引、税、長文コンテキスト加算、処理モード差額を含みません。
- GPT-6 Lunaを明示選択した実STEP2 API検証では、開始・最終採用とも同モデルで完了しました。GPT-6 Astraは使っていません。

## English

- Added GPT-6 Sol and GPT-6 Luna to the STEP2 OpenAI scenario-model options. GPT-6 Astra remains the default.
- Fallback now proceeds only to candidates after the selected model, and GPT-6/GPT-5.6 models use the current Chat Completions parameters.
- Updated the model-menu parentheticals and reference prices to the official short-context standard-processing rates as of 2026-09-23. The estimates exclude tool charges, cached-input discounts, taxes, long-context premiums, and processing-tier differences.
- A live STEP2 API verification explicitly selected GPT-6 Luna; both the initial and final adopted model were Luna, with no GPT-6 Astra use.
