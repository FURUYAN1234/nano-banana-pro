# Super FURU AI 4-koma System v6.9.4

## 日本語

- CSPでスクリプト実行とAPI通信先を制限し、HTML内イベント属性・埋め込みフレームを禁止しました。他サイトのフレーム内では操作画面を表示しません。
- 依存ライブラリを更新し、現在のnpm監査にある本番・開発依存の警告を解消しました。公開CLIは未修正の依存経路を避けるためgh-pages 6.1.1へ暫定固定しています。旧依存の非推奨警告は残ります。
- 毎回のデプロイで最新の依存監査・共通セキュリティ検査・生成済みCSP検証を必須にしました。OpenAIとGeminiの公式通常料金も再確認します。
- READMEとPDFマニュアルへ防御の範囲を追記しました。ブラウザー拡張機能・同一オリジンの別ページ・端末侵害まで完全に防ぐ保証ではありません。

## English

- Added a Content Security Policy restricting scripts and API connections, blocking inline event attributes and embedded frames. A separate guard hides the application inside another site's frame.
- Updated production and development dependencies to clear current npm audit findings. Temporarily pinned the deployment CLI to gh-pages 6.1.1 to avoid an unpatched dependency path; legacy dependency deprecation warnings remain.
- Required fresh dependency audits, shared security checks and built-CSP verification on every deployment, alongside official OpenAI and Gemini standard-price review.
- Updated README and PDF manuals with the protection scope. These controls do not guarantee protection against browser extensions, compromised same-origin pages or compromised devices.
