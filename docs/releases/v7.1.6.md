# Nano Banana Pro v7.1.6

OpenAIのフルオートで、ネタの出来事・会話・場面転換を読み取り、4コマまたは必要最小限の5〜8コマをSTEP2内で選ぶようにしました。ランダムや交互では選びません。選択理由を表示し、実際のコマ数と番号を検証してSTEP3・STEP4へ引き継ぎます。

フルオートOFFでは従来どおり手動で選びます。Geminiは4コマ固定です。自動切替でもモード別の履歴を保持し、停止後の古い応答は採用しません。選択専用のAPI呼び出しは追加していません。README・マニュアル・フロー図を同期しました。

OpenAI full-auto now chooses four panels or the minimum necessary five to eight from the story's events, dialogue and scene transitions within STEP2. Selection is content-based, never random or alternating. The reason is displayed, and validated panel counts and numbering flow into STEP3 and STEP4.

With full-auto OFF, manual selection works as before. Gemini remains four-panel only. Automatic switching preserves separate mode histories and rejects stale responses after cancellation. No separate classification API call was added. README, manuals and workflow diagrams describe the updated behavior.

ViteをWindows開発サーバーの脆弱性に対応した7.3.7へ更新しました。

Updated Vite to7.3.7, which fixes the reported Windows development-server vulnerabilities.
