# Nano Banana Pro v6.0.7

## 日本語

- STEP4のFourPanel NonLM配布を `FourPanel_NonLM_4step_20260912170621_v6.0.7.json` と5カスタムノード同梱ZIPへ更新しました。
- 「軽く要約＋必要な台詞だけ延長」により、基本5秒へ収まらない台詞だけ最大15秒まで延長します。音声と映像が同時に不合格でも構造化したショット差し替えを行い、同一区間で映像不合格が2回続くと話者を読み取りやすい単純構図へ切り替えます。
- 受領候補のv5.9.8表記を、現行Nano Banana v6.0.6の次版v6.0.7へ訂正しました。古い生成先URLと承認識別子も配布ワークフローから除去しています。T2V・I2V・Ref2Vの別製品は変更していません。
- 機能が同一の受領候補では39秒・7区間のGPU/API生成と利用者による音声確認が完了しています。最終v6.0.7 ZIPからの新規GPU生成と別PC実行は未検証です。
