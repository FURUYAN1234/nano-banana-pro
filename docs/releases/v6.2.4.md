# Nano Banana Pro v6.2.4

## English

- OpenAI text-route definitions are now the single source of truth for the visible Model Chain. Updating a normal, scenario, or vision route updates the matching STEP1–3 OpenAI display without a separate snapshot edit.
- STEP4 derives its default, selectable, and fallback entries from the OpenAI image settings.
- The pre-deploy check now blocks a release when the route-to-display synchronization contract fails.

## 日本語

- OpenAIの通常文章・STEP2シナリオ・Vision経路を、画面のModel Chainの唯一の定義にしました。経路を更新すると、対応するSTEP1〜3のOpenAI表示も別の複写作業なしで追随します。
- STEP4は、OpenAI画像設定の初期選択・明示選択・代替選択から表示を導出します。
- 実行経路と表示の同期契約に失敗した場合、pre-deployチェックはリリースを停止します。
