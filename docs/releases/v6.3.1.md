# Nano Banana Pro v6.3.1

## 日本語

- 画面・看板などの文字を毎コマで全文表示することを既定にせず、情報提示に必要なコマへ割り当てる汎用ルールを追加しました。
- 同じ小道具の再登場では、側面・背面・遠景を許可し、画面文字の可読性が明示カメラを動かさないようにしました。
- 吹き出し・字幕と物に印字された文字を分離し、既存の台詞・明示文字・反復指定は保持します。
- 実API画像で、文字を保持したまま俯瞰・寄り・床に近い視点・広い引きを確認しました。強いアオリ、望遠圧縮、左右の配置には未達が残るため、次回の宿題として記録しています。

## English

- Added a generic lettering-per-beat rule so every panel does not need to show recurring screen or sign text in full.
- Recurring props may appear from the side, back, or at a distance, while readability never moves an explicitly placed camera.
- Speech bubbles and captions are separated from printed object text; existing dialogue, explicit lettering, and scripted repetition remain protected.
- A real API image confirmed overhead, close, near-floor, and wide framing while retaining required text. Strong upward projection, telephoto compression, and one horizontal placement remain follow-up work.
