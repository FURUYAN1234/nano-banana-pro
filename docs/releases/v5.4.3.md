# Nano Banana Pro v5.4.3 - MiniMax H3 Publication OCR Titles / MiniMax H3作品公開用OCRタイトル

## 日本語

- STEP4に、既存のMiniMax H3／ComfyUI用コピーとは別の「MiniMax H3・作品公開用プロンプトをコピー」を追加しました。コピーした固定指示文は、別PC・別ブラウザの画像対応チャットでも使えます。
- 添付した4コマ画像からOCRでタイトルだけを取得します。タイトルはコマ枠外にあってもOCR対象ですが、枠外の文字を物語素材には使いません。動画の物語・人物・台詞・動作・舞台は、4つのコマ内だけから扱います。
- 冒頭には作品に応じて判読しやすいタイトルを短くフェード表示し、途中の文字表示は許可しません。終端には `ネームから～` と `note.com/happy_duck780` の2行だけを控えめに表示してフェードアウトします。Nano Bananaのウォーターマークは追加も参照もしません。
- タイトルを確実にOCRできないときは、動画用プロンプトを作らず、日本語でタイトルだけを確認します。

## English

- STEP4 now includes a separate “MiniMax H3 publication prompt” copy action that can be pasted into an image-capable chat on any PC or browser.
- The copied instruction OCRs only the title from the attached four-panel manga, including a title outside the panel grid. Outside-grid text is never story material; story, characters, dialogue, action, and setting come only from the four panels.
- It permits a short, adaptive-contrast opening title, no mid-video overlay text, and only the exact two-line ending credit `ネームから～` / `note.com/happy_duck780`. It never adds or refers to a Nano Banana watermark.
- If title OCR is unreliable, the prompt-authoring chat asks only for the title in Japanese rather than inventing one.
