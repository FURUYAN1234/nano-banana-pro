# Nano Banana Pro v6.5.9

## 日本語

- OpenAI API画像生成の既定サイズをA4大 2240×3168へ変更しました。A4標準 1120×1584も引き続き選択できます。
- モノクロを、白地・黒ベタ・単一スクリーントーンの漫画原稿三階調として再設計しました。明るい肌は白地を主量にして必要な面影だけを限定し、褐色肌は顔・身体・手のひらまで同じ網点を連続させ、頬の網点は明示された赤面または感情の頂点だけに限定します。
- 参照上の黒髪・最暗髪は黒ベタを主量にし、細い白ツヤだけで形を出す規則を追加しました。焦点人物・重要な手・小道具はGペンの強弱を強め、周辺背景の線とトーンを抑えて視線を分離します。
- 強い短縮遠近でも、肩→肘→手首→手の接続と上腕・前腕の短縮を検査し、手だけを大きくして腕を不自然に長くしない共通規則を追加しました。
- フルオートでSTEP2直後にSTEP3へ進む場合も、STEP1の解析モデル名がフッターへ混入しないよう、STEP2の最終採用モデルを専用記録へ即時保存します。カラー／白黒とも同じSTEP2モデル名を表示します。
- 通常は頭髪をコマ内へ収め、絵的に枠外へ飛び出す場合は枠線を頭髪の背後へ回して、切断・断片の重複・枠内外の位置ずれを防ぐ指示と検査を追加しました。
- 被写界深度のぼけだけでは人物が背景へ埋もれる場合、照明・場所・白黒トーンを保ちながら、背景を薄く低彩度にし、人物のGペン輪郭を強められるようにしました。
- 4コマの視線誘導を、入口→主役→反応／小道具→次の吹き出し／コマへつなぐ優先規則として強化しました。話の面白さ、オチの間、表情と身体演技を最優先に保ちます。
- 1枚絵のWebコピー用プロンプトを、品質重視の10,000文字ソフト上限へ変更しました。API送信ガードは32,000文字のままです。
- 自動修正がOFFの通常生成では「修正リトライを停止」を表示せず、自動修正ONで生成中のときだけ表示するようにしました。
- Gemini接続時は、STEP2ボタン直前にシナリオモデルの用途と公式参考単価を1行表示し、STEP4には画像モデル、API搬送サイズ、A4正規化後サイズ、品質切替の有無、画像単価を明記しました。
- Gemini画像APIへは、吹き出し位置を制御する内部記号を自然文へ変換してから送信します。修正プロンプト専用上限を65,000文字へ広げ、長い4コマ指示でも自動修正候補を生成できるようにしました。一般のAPI送信ガードは32,000文字のままです。
- 画像QAで、日本語名とキャラクターシートに併記したローマ字名を同一人物として扱い、話者違いの偽陽性による不要な再生成を防ぎました。
- デプロイ前の公式情報照合で、Gemini文章・VisionのModel Chainを`gemini-3.8-flash`→`3.7-flash`→`3.6-flash`→`3.5-flash`→`3.5-flash-lite`→`3.1-flash-lite`へ更新しました。STEP2表示は3.8 Flashの2026年末までの導入価格$0.75/$3.75に同期し、3.8で非推奨の`temperature`送信を除去しました。
- OpenAI実画像で4コマ目の吹き出し左右が逆転したため、短縮後も「吹き出し本体を人物より先に数値スロットへ固定し、その後で尾を話者へ結ぶ」契約を保持する回帰修正を追加しました。
- Gemini実画像では、枠なしタイトル、正確な全台詞、4コマの読順、カメラ、小道具、手、A4余白を目視確認しました。修正版で台詞が退行したため、比較で初回候補を保持しました。

## English

- Made the large A4 canvas, 2240×3168, the default for OpenAI API image generation. The standard 1120×1584 A4 canvas remains selectable.
- Reworked monochrome output as a true three-tone manga manuscript: white paper, solid black, and one bounded screentone. Light skin stays predominantly unprinted, screened skin remains continuous across face, body, hands, and palms, and cheek tone is reserved for scripted blush or a deliberate emotional peak.
- Hair that is black or darkest in the reference now uses a substantial solid-black base with only narrow white shine cutouts. Stronger G-pen hierarchy separates focal faces, important hands, and story props from lighter background linework and tone.
- Added a shared foreshortening check that traces shoulder → elbow → wrist → hand and enlarges a near hand by compressing, never lengthening, the upper arm and forearm.
- STEP 2 model provenance is now stored synchronously and separately from the shared UI model badge, so full-auto STEP 2 → STEP 3 cannot stamp the earlier STEP 1 model into the footer. Color and monochrome use the same adopted STEP 2 model.
- Added generation and QA rules that normally keep complete hair silhouettes inside panels, while allowing deliberate border breakthroughs only when the border passes behind one continuous, aligned silhouette.
- When depth-of-field blur is not enough to separate a person from the background, prompts may lighten and desaturate the background and strengthen the subject's G-pen contour while preserving lighting, setting evidence, and monochrome tone rules.
- Raised professional manga visual flow to a priority rule: panel entry → primary focal point → reaction or prop → next bubble or panel. Story interest, comedic timing, expressions, and body acting remain more important than decorative neatness.
- Raised the single-image Web-copy prompt soft budget to 10,000 characters for quality-focused direction. The API request guard remains 32,000 characters.
- The “stop repair retries” control now appears only while automatic repair is enabled and generation is in progress.
- On Gemini, a one-line STEP2 strip now identifies the scenario model, purpose, and official reference price. STEP4 identifies the image model, API transport size, normalized A4 size, lack of a quality selector, and per-image price.
- Internal bubble-position tokens are converted into natural language before the Gemini image request. Gemini repair prompts have a dedicated 65,000-character budget so long four-panel instructions can reach the repair image call; the general API request guard remains 32,000 characters.
- Image QA now treats Japanese cast names and the romanized aliases printed on character sheets as the same speaker, preventing false speaker-mismatch repairs.
- The deploy-time model audit updated Gemini text and vision routing to `gemini-3.8-flash`→`3.7-flash`→`3.6-flash`→`3.5-flash`→`3.5-flash-lite`→`3.1-flash-lite`. The STEP2 strip now shows the 2026 introductory $0.75/$3.75 price for 3.8 Flash, and requests no longer send its deprecated `temperature` parameter.
- A live OpenAI image exposed reversed balloon placement in panel 4. The compact prompt now retains a regression-tested contract to freeze numeric balloon-body slots before actors and only then route tails to speakers.
- A live Gemini image was visually accepted for its unframed title, exact dialogue, reading flow, cameras, props, hands, and A4 margins. Candidate comparison retained the original because the repair regressed one line.
