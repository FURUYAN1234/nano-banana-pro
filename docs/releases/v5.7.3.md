## Nano Banana Pro v5.7.3

### 日本語

- 配布する `ComfyUI-NanoBanana-H3` から資格情報ファイルの読書きを削除し、APIキーを現在動作中のComfyUIサーバープロセスのメモリだけに保持します。
- キーはワークフローのシート移動では残り、ComfyUI終了・再起動で消去されます。ワークフローJSON、配布ZIP、設定ファイル、ディスクには保存しません。
- ワークフロー読込時、プルダウンで選択中のProviderが未登録の場合だけ、そのProviderのAPI入力ダイアログを自動表示します。
- STEP4、README、全公開ワークフロー、配布ZIP内のREADME・検証記録・ワークフロー説明を同じ仕様へ更新します。
- APIキーは認証確認または実行時だけ、接続中のComfyUIサーバーから選択した外部APIへ送信されます。
- 今後のMiniMax H3配布ではAPI資格情報を最重要チェック項目とし、旧資格情報ファイルの安全な処理と終了・再起動後の消去確認を含むワークフロー作成PC用手順を同梱します。

### English

- Removes credential-file reads and writes from the distributed `ComfyUI-NanoBanana-H3` node and keeps API keys only in the currently running ComfyUI server process memory.
- Keys survive workflow-sheet changes and are erased when ComfyUI exits or restarts. They are never saved in workflow JSON, the distribution ZIP, configuration files, or on disk.
- When a workflow loads, the API dialog opens automatically only if the Provider already selected in the dropdown is not registered in that ComfyUI process.
- Synchronizes STEP4, README, every public workflow, and the bundled README, verification record, and workflow note with the same credential contract.
- A key is sent from the connected ComfyUI server to the selected external API only for validation or workflow execution.
- Makes credential handling the highest-priority gate for future MiniMax H3 distributions and bundles an author-PC guide covering legacy-file cleanup and post-restart erasure checks.
