# Super FURU AI 4-koma System v6.7.5

## Changes / 更新内容

- **Mosaic target scope / モザイク対象の区別:** Reference sheets provide character identity, not copyright-mask targets. Automatic masking applies only to existing-work subjects actually depicted in the approved panel Action. Sheet presence, labels, art style or familiar likeness alone must not mask unrelated original cast. / キャラクターシートは本人の外見を参照する資料として扱い、自動モザイク対象リストと混同しません。台本のActionで実際に描く既存作品の人物だけを自動遮蔽し、参照の存在・説明文・画風・外見の類似だけでオリジナルの登場人物を隠しません。
- **Intentional masking / 意図したモザイク:** An explicit scripted mask on a cast subject remains valid within its specified subject and region. Unrelated cast and required text remain readable. / 原文で本人へのモザイクを明示した場合は、その対象・領域の指定を維持し、別のキャラクターや必要な文字へ広げません。
- **Shared gates / 共通の検証:** The scope is carried through scenario, final render, reference attachment and QA/repair. / シナリオ、最終描画、参照添付、QA・修復の共通境界に適用します。
- **OpenAI default / OpenAI初期選択:** Both development and production use GPT-6.1 Sol initially. Existing eleven choices, Astra-first order and downward fallback are retained. / 開発版・公開版ともGPT-6.1 Solを初期選択とし、既存11モデル、Astraを先頭とする順序、下位へのフォールバックを維持します。

## Validation / 検証

Focused local tests verify the targeting contract and preserve intentional masking. Actual image acceptance and publication are verified separately before release completion. / ローカル回帰で対象契約と意図的なモザイクの維持を確認します。実画像の遵守と公開完了はリリース前に別途確認します。
