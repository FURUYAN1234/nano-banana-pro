# Nano Banana Pro v6.3.3

## 日本語

- STEP3の直前に、SNS投稿向けの編集可能な「解説」欄とコピー操作を追加しました。カテゴリ検索では生成時に取得した検索出典を参考リンクとして表示し、自由入力では入力されたURLだけを表示します。URLがない自由入力では参考リンク自体を表示しません。
- 解説は漫画のシナリオ・画像プロンプトから分離され、漫画内の創作をニュースの事実として書かないようにします。実在のニュースや事件ではない創作には、本文と改行で分けた丸括弧の注意書きを使います。
- 演出強化では解説の編集内容を保持し、新規シナリオ、結末変更、リセット、連続生成の新周回では前の解説を消去します。検索出典が漫画タイトルへ混ざる表示も除去しました。

## English

- Added an editable SNS posting explanation panel and copy action immediately before STEP3. Category search displays source links returned during generation, while manual input displays only URLs supplied by the user. Manual input without a URL displays no reference-link section.
- Posting copy is separated from the manga scenario and image prompt so fictional manga events are not presented as news facts. Fictional material uses a parenthesized disclaimer on its own line after the body text.
- Direction enhancement preserves edited posting copy; a new scenario, ending change, reset, or a new continuous-generation cycle clears the prior copy. Search citations are also stripped from visible manga titles.
