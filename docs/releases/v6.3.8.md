# Nano Banana Pro v6.3.8

## 日本語

STEP2のシナリオ生成中に、前回の結果や次工程が残って見えるため、現在の状態が分かりにくくなる問題を修正しました。

- シナリオ要求中はSTEP2ボタン直下の実際の進捗・エラーログを表示し、古いシナリオ結果、Generation Preview、STEP3を隠します。
- シナリオが完了すると結果、場所・服装・オチのプレビュー、STEP3を表示し、次に押すSTEP3を穏やかな明暗変化で案内します。
- READMEの画像QA・吹き出し読順・失敗時の救済操作の説明に英語を併記し、日本語説明と対応させました。

実APIではOpenAI GPT-6 AstraのSTEP2生成を1回確認し、昭和の商店街という背景指定と異世界の騎士服・魔法使い服という明示衣装がシナリオ内で別々に保持されることを確認しました。この確認はシナリオ段階のものであり、最終画像での衣装再現を保証するものではありません。

## English

This release makes the active state of STEP2 scenario generation easier to understand by preventing stale downstream controls from remaining visible.

- While a scenario request is active, the app keeps the real progress or error log directly below STEP2 and hides the previous scenario result, Generation Preview and STEP3.
- When generation finishes, the scenario result, location/outfit/punchline preview and STEP3 return, and a restrained brightness pulse identifies STEP3 as the next action.
- The README now pairs its Japanese explanation of image QA, speech-bubble reading order and failure-only recovery with matching English text.

One live OpenAI GPT-6 Astra STEP2 request confirmed that a Showa-era shopping-street setting and explicit fantasy knight/wizard outfits remain separate fields in the generated scenario. This is scenario-stage evidence only and does not guarantee wardrobe reproduction in the final image.
