# Super FURU AI 4-koma System v7.0.4

## 日本語

- 実験的コマ割りの重複する描画指示を圧縮し、参照画像の説明分を先に確保しました。元の台本・台詞・カメラ・画風の指示を保ちます。
- 各コマの位置と場面を同じブロックにまとめ、ページ上の左右と場面内の左右を区別して指示します。
- 5〜8コマでは元の展開と結末を保ちながら、台詞・掛け合い・動作・表情を膨らませられます。無言コマを必須にはしません。
- 32,000文字を超えるプロンプトも、Web用の文字数表示・全文／分割コピー・TXT・制作情報JSON保存を使えるよう修正しました。API送信の上限は維持します。
- Gemini 3.8／3.7／3.6のモデルバッジを修正し、転送先と重複する廃止済みFlash候補を整理しました。画像モデルとFlash-Liteは変更しません。
- STEP3中の履歴表示を「プロンプト作成中」に修正し、READMEとPDFマニュアルを更新しました。通常4コマは従来の生成経路を使い、実験スイッチの初期値はOFFです。

## English

- Consolidated repeated experimental drawing rules and reserved space for reference-image instructions while preserving source dialogue, camera directions and styles.
- Bound each scene to its physical page frame and distinguished page positions from left/right staging inside a scene.
- Expanded layouts can enrich dialogue, action and reactions while preserving the original progression and ending. Silent panels are optional.
- Restored character counts, full/split Web copying, TXT export and production JSON saving for prompts above 32,000 characters. The API submission limit remains enforced.
- Corrected Gemini 3.8/3.7/3.6 badges and removed retired Flash fallback aliases that redirect to existing candidates. Image models and Flash-Lite remain unchanged.
- Clarified STEP3 history status and updated the README and PDF manuals. Normal four-panel generation keeps its existing route; experimental layout starts OFF.
