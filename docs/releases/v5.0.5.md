# Nano Banana Pro v5.0.5

## 日本語

- 同一人物が資料などの小道具を置いた後に腕組みする指示を検出し、途中動作ではなく最終ポーズだけを描くロックを追加しました。
- 小道具は机などの面で自立し、両手は小道具から完全に離れ、人物には自然につながる腕2本と手2つだけを描くよう固定しました。
- 別人物の小道具操作と腕組みにはロックを適用せず、既存の台本・会話・構図を変更しない回帰テストを追加しました。
- 実際の OpenAI `gpt-image-2` 生成で、サエコの腕組み、資料の自立、手・腕・資料の非融合を確認しました。

## English

- Added a generic final-pose lock for a character who places a prop and then crosses their arms, so the transient placement action is not drawn together with the final pose.
- The prop remains self-supported on its surface, both hands fully release it, and exactly two naturally connected arms and hands remain on the character.
- The lock does not apply when prop handling and crossed arms belong to different characters; regression coverage preserves existing scripts, dialogue, and composition.
- A live OpenAI `gpt-image-2` generation verified Saeko's natural crossed arms, self-supported file, and no hand, arm, or prop merging.
