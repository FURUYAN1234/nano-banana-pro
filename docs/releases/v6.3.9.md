# Nano Banana Pro v6.3.9

## 日本語

STEP3でプロンプト構築を始めた直後、進捗の場所が分かりにくい問題を修正しました。

- 「画像用の指示文（プロンプト）を構築する（STEP 3）」を押すと、STEP3内の実際の進捗ログへ滑らかに移動します。
- 最終プロンプトが完成した時だけSTEP4の先頭へ移動します。完成済みプロンプトの手動編集では画面位置を変えません。
- 進捗ログをSTEP4からSTEP3へ移し、API待機中の経過秒数を操作の近くで確認できます。
- READMEのSTEP3進行とSTEP4遷移説明を英日で同期しました。

## English

This release makes the STEP3-to-STEP4 handoff easier to follow.

- Pressing “Build image prompt (STEP 3)” smoothly moves the view to STEP3’s real progress log.
- The view moves to the start of STEP4 only after a final prompt is ready; manual edits of a completed prompt do not move the view.
- The progress log now lives in STEP3, beside the action that starts the API review, including the elapsed wait time.
- The README now documents the STEP3 progress and STEP4 transition in English and Japanese.
