# Super FURU AI 4-koma System v8.1.6

- **Color manga from a script alone.** STEP3 places the story and STEP1 cast descriptions first when the OpenAI color page request contains zero images. Each panel receives the original action, camera and dialogue from STEP2. Standard color panels use thick foreground contours and finer tapered G-pen strokes on faces, hair and fingers. / **文字素材だけのカラー漫画。** 画像が0枚のときは、あらすじとSTEP1の人物設定に続けて、各コマにSTEP2の動作・画角・台詞を渡します。通常のカラーコマは手前の輪郭を太く、顔・髪・指先を細く抜くGペンタッチで描きます。
- **Reference images and panel media.** The page builder counts character, prop, background, technique and previous-page images when choosing the rendering instructions. Each assigned panel medium keeps its own rendering directions. / **参照画像と描法。** 人物・小物・背景・描法見本・前ページの画像を実際の送信内容で数え、コマごとに指定した描法を適用します。
- **Author and footer.** On a titled first comic page, a requested author credit appears once beside the title, above the first panel. Each footer field can be enabled independently, including a single visible credit. / **作者名と下端の表示。** 題字のある本文1ページ目は、第1コマの上、題字の右下に指定した作者名を一度だけ添えます。下端の製品ウォーターマークを片側だけ表示する設定も、品質検査で正しく読み取ります。
