# Super FURU AI 4-koma System v7.2.1

## English

The final prompt preview now shows the same complete text as full copy, numbered copy parts and TXT export, including reference-image instructions and applicable monochrome finishing instructions. The editable prompt body remains available in a separate disclosure. Invalid preparation clears the preview and displays an error while retaining the body.

The existing five- to eight-panel integrity check still requires rebuilding STEP3 after source or prompt edits. Image-generation routes, API limits and automatic repair thresholds are unchanged. The three PDF manuals describe the updated preview and editing controls.

The correction phase now labels the finished inspection duration separately from the advancing STEP4 total. Shared repair instructions clarify that observed cast-count and camera defects may be changed in the affected panels while already-correct content stays protected.

## 日本語

「最終プロンプト」に、全文コピー・番号順の分割コピー・TXT保存と同じ全文を表示します。参照画像の説明と、該当時の白黒仕上げ指示も含みます。編集用の本文は「本文を編集」に分けて保持します。全文を準備できない場合は、本文を残したまま表示欄を空にし、理由を表示します。

5～8コマでは従来の整合性チェックを維持し、元台本や指示文を変更した場合はSTEP3の再構築が必要です。画像生成経路、API文字数上限、自動修正の判断基準は変更していません。PDFマニュアル3冊も表示と編集操作の説明を更新しました。

修正画像生成中は、確定した検査時間を「検査終了」と表示し、STEP4全体の時間と区別します。共通の修正指示では、人物数・カメラの誤りが報告されたコマについて、その誤りを保持せず修正することを明示しました。正常な部分の保護と修正回数の上限は維持します。
