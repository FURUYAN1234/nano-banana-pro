# Nano Banana Pro v5.9.8

## 日本語

- OpenAI APIキーの接続確認で取得するモデル一覧に `gpt-image-2.5-sunburst` がある場合、STEP4の初期選択を GPT Image 2.5 Sunburst / xhigh にします。ない場合は GPT Image 2.0 / high を初期選択します。
- この判定は既存のキー事前確認を再利用し、キーやモデル一覧をブラウザストレージへ保存しません。
- モデル一覧に表示されることは画像生成や品質設定の成功を保証しません。画像生成時のエラー後に、モデルの自動切替や自動再送信は行いません。

## English

- When the verified OpenAI model list includes `gpt-image-2.5-sunburst`, STEP4 initially selects GPT Image 2.5 Sunburst / xhigh; otherwise it initially selects GPT Image 2.0 / high.
- The change reuses the existing key preflight and does not store the key or returned model list in browser storage.
- Listing a model does not guarantee that image generation or a quality setting will succeed. Image-generation errors do not trigger an automatic model switch or retry.
