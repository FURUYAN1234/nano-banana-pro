# Nano Banana Pro v6.6.0

## 日本語

- 発話本文と話者ルーティング用メタデータを分離し、話者名や制御用情報が吹き出し文字へ混ざる経路を修正しました。引用付き台詞と長文圧縮を含む両AI経路に回帰検査を追加しました。
- Web貼付用の4コマ構成を、横長の全幅コマが縦1列に並ぶ指定として両AIで共通化しました。
- 特定の人物や衣服に依存しない衣装連続性ルールを追加しました。衣装・付属品の有無、数、形、取付位置を人物ごとに全コマで共有し、台本上の着脱と、遮蔽・画面外による非表示を区別します。
- 衣装QAは、同じ人物の同じ衣服部位を別コマで明瞭に比較できる場合にだけ具体的な不一致として扱います。人物特定や表示状態の根拠が足りない場合は未確認とし、自動修正を避けます。
- カラー／白黒、ChatGPT／Gemini、参照画風と長文圧縮後の経路をテストしました。実画像の連続性はOpenAI画像を1枚生成して確認しました。今回の画像には衣装の細部差と自動検査で未確認の項目が残るため、完全一致は保証しません。

## English

- Separated visible dialogue from speaker-routing metadata to prevent speaker names or control fields from leaking into speech balloons. Added regressions across both AI routes, including quoted dialogue and long-prompt compaction.
- Unified the Web-paste page-layout instruction for both providers: four full-width horizontal panels stacked in one vertical column.
- Added a generic wardrobe-continuity rule independent of any named character or garment. Each character's garment and accessory presence, count, shape and attachment are shared across panels; scripted changes and occlusion or cropping are treated separately.
- Wardrobe QA reports a concrete discrepancy only when the same character and exposed garment region can be compared clearly across panels. Missing identity or visibility evidence stays unverified and is excluded from automatic repair.
- Tested color and monochrome, ChatGPT and Gemini, reference-style prompts and long compaction. One OpenAI image was generated for visual review. Minor wardrobe differences and unverified QA items remain in that image; perfect consistency is not guaranteed.
