# Nano Banana Pro v5.2.8 - Manga Composition Variety / マンガ構図バリエーション

## 日本語

- 通常の4コマ生成で、画角・高低・傾きに加え、被写体基準の水平方向をSTEP2から指定します。4コマ内の平面的な真正面構図は最大1コマに抑え、肩・腰・顔の軸を変化させます。
- 両手を使う動作は、指定された行動・小道具・登場人物・セリフを維持したまま、手前と奥の深度または高さをずらして、両手を同じ距離で前へ広げる構図への偏りを抑えます。
- OpenAI画像生成中の待機表示を実際の処理ログと同じ「通常2〜10分」に統一しました。通常のSTEP2→STEP3→STEP4実API経路で、斜めローアングル、肩越し、前景アップ、斜め広角を含む1024×1536の4コマ画像を確認しました。

## English

- Normal four-panel generation now specifies subject-relative horizontal camera direction from STEP2, alongside shot size, elevation, and tilt. It limits flat front-on staging to one panel and varies shoulder, hip, and face axes across the page.
- Two-hand actions retain the requested action, props, cast, and dialogue while staggering hand depth or height, reducing the repeated pose where both hands face forward at the same distance.
- Aligned the OpenAI image-generation wait overlay with the current "normally 2 to 10 minutes" runtime expectation. Verified the normal STEP2→STEP3→STEP4 real API path with a 1024×1536 four-panel image using oblique low-angle, over-the-shoulder, foreground close-up, and oblique wide staging.
