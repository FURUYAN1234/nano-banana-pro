- Added a bold 18px reminder above the save test: complete Chrome's automatic-download settings, then click the test button below. Its yellow/orange pulse has a clear bright/dim difference; the text is noninteractive.
- Changed the free two-file save-test button to white with black text and added spacing below the reminder. Reduced-motion preferences disable the pulse.
- Synchronized the README and all three PDF manuals to v7.0.2 and refreshed the official standard-price check date.
- Verified the normal Gemini API path and two actual PNG saves in Chrome. Cancellation during STEP2/STEP3 API communication was also verified, but the previously reported unavailable Stop button remains unreproduced with an unknown cause. This release contains no change to Stop behavior.

- Removed unnecessary Vite SSR startup from the plain-JavaScript Gemini API contract tests. The same client and all allowed/rejected assertions remain covered; application API routes are unchanged.
