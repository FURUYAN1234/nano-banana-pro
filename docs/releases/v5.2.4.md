# Nano Banana Pro v5.2.4 - Markdown Visual-Section Isolation / Markdown視覚節の分離

## 日本語

- `**表情:**`、`**身体/間合い:**`、`**演出:**`、`**背景:**` のMarkdown節を、台詞およびキャラクター配置の候補から除外しました。
- 視覚指示は `Action` に保持し、`**セリフ:**` 節にある明示台詞だけを吹き出し契約へ渡します。
- 通常のキャラクターシート解析フローで、実OpenAI `gpt-image-2` による4コマ生成を実施。各コマ1つ、合計4つの指定吹き出しだけが描画され、表情・身体・演出・背景の説明文バブルは出ないことを確認しました。

## English

- Excludes Markdown visual sections such as `**Expression:**`, `**Body/Spacing:**`, `**Direction:**`, and `**Background:**` from dialogue and character-placement inference.
- Keeps visual directions in `Action` and routes only explicit dialogue under the `**Dialogue:**` section into bubble contracts.
- Verified through the normal character-sheet analysis flow with a real OpenAI `gpt-image-2` four-panel generation: one intended bubble per panel, four total, and no expression, body, direction, or background prose rendered as bubbles.
