# Nano Banana Pro v5.9.4

### 日本語

- STEP4にGPT Image 2.5 Flare・Sunburstのhigh / xhighと、未認証時の予備となる2.0 / highの選択欄を追加しました。選択はリロードまで保持します。
- 同一プロンプト・自動修正OFF・各条件1枚の実API比較に基づき、初期値をSunburst / xhighにしました。全用途での優位を保証するものではありません。
- 個人認証の手順と未完了・審査中の2.0手動選択を案内し、Web貼り付けとAPI生成の設定を区別しました。
- 自動品質修正は既定ON、追加画像は最大1回です。修正版が検査に合格しても元画像と直接比較し、改善が明確な場合だけ採用します。同等・不明・比較失敗では元画像を保持します。自動判定は誤りがあり得ます。
- Action内の無言の人物が人数指定から抜ける不具合を修正しました。既存のWeb貼り付けプロンプト契約とH3配布物は変更していません。

### English

- Adds STEP4 choices for GPT Image 2.5 Flare and Sunburst at high/xhigh, plus GPT Image 2.0 / high as a manual alternative during verification. Selection lasts until reload.
- Defaults to Sunburst / xhigh based on a same-prompt, one-image-per-setting API comparison with automatic repair off; this does not establish universal superiority.
- Explains individual organization verification and manual 2.0 selection, and visually separates API settings from Web-copy prompts.
- Automatic quality repair defaults on with at most one additional image. A passing repair is compared directly with the original and adopted only for a clear improvement; ties, uncertainty, or comparison failure retain the original. Automated judgments remain fallible.
- Fixes silent actors in Action lines being omitted from cast constraints. Existing Web-copy prompt contracts and H3 distribution files remain unchanged.
