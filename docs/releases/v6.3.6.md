# Nano Banana Pro v6.3.6

## 日本語

- 不合格画像をAIが検査結果と過去の失敗履歴から解析し、同じ修正方針を繰り返さない最大3回の限定修正を追加しました。
- 全候補が不合格でも、比較した履歴の中から最良候補を警告付きで採用して後続処理を止めないようにしました。明示的な停止操作は継続を中断します。
- 4コマの吹き出しを話者の画面位置から独立した右から左のスロットへ固定し、パネル1・3を含む各コマでB1を右端、後続を左側へ配置します。画像QAは実画像内の左から右の文字在庫を確認できない場合を未確認として記録します。
- 原因解析、候補比較、最良候補継続、吹き出し順を回帰テストで検証しました。

## English

- Added bounded AI failure analysis with up to three repairs. Each analysis uses the observed QA evidence and prior failure history to avoid repeating the same repair strategy.
- When every repair candidate fails, the workflow compares the recorded candidates, keeps the best available image with a warning, and continues downstream processing. An explicit stop action still cancels continuation.
- Speech bubbles now use right-to-left slots independent of speaker position: B1 is the rightmost bubble and later bubbles move left in every panel, including panels 1 and 3. Image QA records the reading order as unverified when the rendered left-to-right text inventory cannot be confirmed.
- Added regression coverage for failure analysis, candidate comparison, best-candidate continuation, and bubble ordering.
