# Nano Banana Pro v5.1.2 - Scenario Integrity / シナリオ処理整合性

## 日本語

- 手動入力モードでは、入力内容を未検証の外部ニュースとして断定せず、「ユーザー提供トピック」として扱います。
- 実行していないニュース検索・データベース走査の進捗表示を廃止しました。
- 再生成時は、実際に失敗した検証項目（例: 動的背景設計）を表示します。
- 本文の表現衛生による書き直し後も、動的背景・視覚的証拠・最終コマ配置の検証を最後まで実行できるよう再試行枠を分離しました。

## English

- Manual input is treated as user-provided topic text, not an unverified external news fact.
- Removed progress messages that claimed news searching or database scanning when no such request ran.
- Retry progress now names the actual failed check, such as dynamic background design.
- A content-hygiene rewrite no longer exhausts the final scenario validation opportunity for background, visual evidence, or final-panel staging.
