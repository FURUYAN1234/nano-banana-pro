# Nano Banana Pro v5.1.0 - Rich Panel Composition / リッチ画面構成

## 日本語

- `v5.0.9` の次を番号規則どおり `v5.1.0` に訂正しました。誤った `v5.0.10` は撤回対象です。
- 4コマ漫画の各コマに固定環境アンカーと複数の物理的背景手掛かりを残し、人物の顔・手・視線・行動を明瞭に保ちます。
- リリース更新ツールと事前検査で、2桁の minor/patch を拒否し、末尾 `9` からの桁上げを強制します。

## English

- Corrected the successor to `v5.0.9` to `v5.1.0` under the release numbering rule; the erroneous `v5.0.10` is being withdrawn.
- Each manga panel retains a fixed environmental anchor and multiple physical setting cues while faces, hands, eye lines, and actions stay clear.
- The release updater and predeploy check now reject two-digit minor/patch components and enforce carrying after a trailing `9`.
