# Super FURU AI 4-koma System v7.2.2

## English

STEP1 now removes a source-bound character profile, including its edits, when that character has no remaining reference image. A replacement sheet is analysed again, so a new result for the same name cannot be hidden by the removed sheet’s stale edits. Edits for characters with surviving references and manually added characters are preserved.

The normal browser workflow was checked with real GPT-6 Luna image analysis: load two bundled sheets, edit profiles, remove one sheet, add a different sheet, then re-add a sheet containing the removed names. The removed edits did not return; retained and manual-only edits remained. README and all three PDF manuals have been synchronised with this behavior.

The lint and publishing dependencies were updated for the patched minimatch release (11.0.1); the dependency audit now has zero findings.

## 日本語

STEP1で人物の参照画像が1枚も残らなくなった場合、その人物の設定を手編集も含めて削除します。差し替えシートは新たに解析するため、同じ名前を認識しても、削除したシートの古い編集が新しい結果を上書きしません。参照画像が残る人物と、手入力だけで追加した人物の編集は保持します。

通常のブラウザー操作とGPT-6 Lunaの実画像解析で、同梱シート2枚の読込、人物設定の編集、1枚の削除、別画像の追加、削除した人物と同名を含むシートの再追加を確認しました。古い編集は復活せず、残した人物と手入力人物の編集は保持されました。READMEとPDFマニュアル3冊も今回の挙動へ同期しています。

開発・公開ツールの依存ライブラリも修正版minimatch 11.0.1へ更新し、依存ライブラリ検査の指摘を0件にしました。
