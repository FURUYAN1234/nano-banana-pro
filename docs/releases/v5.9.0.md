# Nano Banana Pro v5.9.0

### 日本語

- Hugging Face では、10 MiB 以下の配布ZIPを通常のGitファイルとして配信し、LFS/Xetの別認証転送を不要にしました。10 MiBを超える将来の配布ZIPだけは引き続きLFSで追跡します。

### English

- Delivers distribution ZIPs of 10 MiB or less as ordinary Git files on Hugging Face, avoiding a separate authenticated LFS/Xet upload; only future ZIPs over 10 MiB remain LFS-tracked.
- Synchronizes byte-preservation rules for ZIPs, workflow JSON, and SHA-256 sidecars from `public/.gitattributes`, preventing line-ending conversion on both GitHub Pages and Hugging Face.
- For the 2026-09-07 MiniMax H3 Fused4 + SLA external-API distribution, the ZIP SHA-256 is `1020857E4DBE0B65603D23721D073242FD24F66D33257F1D73CC3DA0EE7B16D4` and the workflow SHA-256 is `2839ED348E9334807A9BA7E807D297C32CBAEE8824691943C9D00DE1E7EADEBB`.
