## Nano Banana Pro v5.7.2

### 日本語

- v5.7.1で追加したMiniMax H3高速版ワークフローと必須カスタムノード4点の配布内容を維持します。
- Hugging Face向け配布ZIPだけをLFS／Xetブリッジ経由で保存するよう、公式デプロイ処理を修正しました。
- GitHub PagesではZIPの実バイトを直接配布し、Hugging Faceでも同じ取得バイトを返す構成を検証対象にします。

### English

- Retains the accelerated MiniMax H3 workflow and four required custom-node packages introduced in v5.7.1.
- Corrects the official deployment process so only the Hugging Face distribution ZIP is stored through the LFS/Xet bridge.
- Keeps the GitHub Pages ZIP as direct bytes and verifies that Hugging Face returns the same downloadable bytes.
