# Nano Banana Pro v5.4.2 - MiniMax H3 Readings and Motion / MiniMax H3読み・動き

## 日本語

- STEP4のMiniMax H3／ComfyUIコピー指示は、各日本語台詞の原文を `<d>[Japanese] ...</d>` にそのまま残し、同じ話者のひらがな・カタカナのみの読みガイドを併記します。これにより、漢字の読み間違いを減らします。
- 読みが画像と文脈から確定できない場合は、推測した動画用プロンプトを出さず、該当台詞の読みを短く確認します。
- 各ショットでは、場面に合うアニメーション原則を1〜3個だけ選び、躍動感を付けながら、静かな場面・原作・物理的な整合性を壊す過剰な動きは避けます。
- コピー・ボタン横には、ユーザー向けに既定仕様を「15秒・16:9・BGMあり・日本語音声・標準の躍動演出」と簡潔に表示し、個別指定があれば優先することを示します。
- 既存の4手順Ref2VA導線、時間指定、連続BGM契約、通常の画像生成、プロバイダー選択、APIキーの扱いは変更していません。

## English

- The STEP4 MiniMax H3 / ComfyUI copied instruction now keeps each Japanese line verbatim in `<d>[Japanese] ...</d>` and adds a kana-only reading guide for the same speaker, reducing incorrect kanji readings.
- If a reading cannot be determined from the manga and its context, the helper asks for that reading rather than generating a potentially incorrect video prompt.
- Each shot selects only one to three compatible animation principles to improve energy without forcing motion that conflicts with a quiet beat, the source manga, or physical continuity.
- Next to the copy button, the default user-facing specification is stated concisely as 15 seconds, 16:9, BGM enabled, Japanese voice, and standard lively direction; individual settings override these defaults.
- The existing four-step Ref2VA workflow, timed-direction rules, continuous BGM contract, normal image generation, provider selection, and API-key handling are unchanged.
