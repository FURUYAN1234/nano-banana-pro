# Nano Banana Pro v6.1.7

- Abstract four-panel beats can now omit scenery without losing a requested overhead view: body shortening and upper prop faces preserve the projection. Explicit Japanese overhead cues are recognized alongside English camera terms. / 背景を省略する抽象コマでも、身体の短縮と小道具の上面で指定された俯瞰を保ちます。日本語の「俯瞰」「上から」も英語カメラ指定と同様に認識します。
- Explicit Action gaze targets now take priority over conversational fallback staging. When no individual gaze is specified, ordinary speakers and listeners still look at one another. Direct address remains limited to the named in-story addressee. / Actionで明示された視線先を会話用の補助配置より優先します。個別の視線指定がない通常会話では、話者と聞き手の相互視線を維持します。読者等への視線は、台本で明示された人物だけに限定します。
- Prompt assembly normalizes Windows CRLF input before extracting the location, outfit, panels and dialogue, so the same scenario retains those fields in both color and monochrome routes. / プロンプト組立て前にWindowsのCRLF改行を正規化し、カラー・白黒の両方でLocation、Outfit、コマ、台詞を同じ台本から保持します。
- The shared reading-rhythm direction continues to contrast detailed setting shots with intentional abstract beats while keeping required props, contacts, reactions and individual acting. / 共通の読みの強弱指示は、描き込む場所描写と意図的な抽象コマの差を付けつつ、必要な小道具、接触、反応、個別演技を保持します。
