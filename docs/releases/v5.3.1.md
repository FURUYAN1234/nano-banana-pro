# Nano Banana Pro v5.3.1 - API Session and Manga Quality Gate / APIセッションと漫画品質ゲート

## 日本語

- 初回のAPIキー入力が一時的な通信失敗で未接続のままになる問題を修正しました。検証済み接続はブラウザメモリ内の単一セッションに保持し、一時エラーは同じ入力のまま1回だけ再試行します。キー値は保存・表示しません。
- 背景の7項目スキーマと背景専用の再試行を廃止し、`Location` と明示的な時刻・天候だけを低優先度で維持する軽量運用へ変更しました。人物の解剖学、手・腕の左右、小道具の所有関係、吹き出しの正確さを優先します。
- STEP4後に、人物の余分な腕や手、左右入れ替わり、小道具の誤所有、台詞以外の吹き出し文字、話者名混入、余計な文字を検査する可視品質ゲートを追加しました。画像は先に表示し、品質NGでも自動再生成は行いません。
- 内蔵ブラウザで実際の OpenAI `gpt-image-2` 生成を2回実行し、両方で `gpt-4.1` の人物・手・小物・吹き出し品質判定がPASSしました。

## English

- Fixed first-entry API connection handling: one verified browser-memory session now owns the credential, and a transient preflight failure retries the same input once without requiring a reload. The key value is neither stored nor displayed.
- Removed the seven-field background schema and background-only retry path. Only concrete `Location` plus explicit time or weather cues remain as low-priority continuity, below anatomy, hand/arm laterality, prop ownership, and bubble accuracy.
- Added a visible post-generation quality gate for extra or malformed arms/hands, left/right swaps, incorrect prop ownership, non-dialogue bubble text, speaker-name leakage, and extra text. The generated image remains visible and the app never auto-regenerates after a failed check.
- Ran two real OpenAI `gpt-image-2` generations in the in-app browser; both passed the `gpt-4.1` person, hand, prop, and bubble quality review.
