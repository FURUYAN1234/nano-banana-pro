# Nano Banana Pro v6.8.4

## 日本語

- 括弧付きの正式な話者名で台詞が欠落し、STEP3が「吹き出し配置と抽出台詞の不一致」で停止する不具合を修正しました。
- キャラクターシートの登録人物を自動モザイクの対象から除外する指示を、画像生成・検査・修正で統一しました。登録情報が変わった古い指示文は再構築を求めます。明示した人物や部位のマスク指定は保持します。
- 画像検査で、登録名の丸括弧と隅付き括弧の表記差を別人扱いしないよう修正しました。
- 1枚絵の追加指示を短縮し、同じ未送信欄に追記して参照画像と一度に送る手順をマニュアルへ反映しました。

同じ7枚のシートと報告台本で実API生成を確認し、不要モザイクの解消を確認しました。生成画像の文字や描写の完全一致を保証する変更ではありません。保存前に画像と検査結果を確認してください。

## English

- Fixed missing dialogue and STEP3 balloon-count failures for registered speaker names containing bracketed titles.
- Shared the registered-cast exclusion for automatic mosaic across generation, QA and repair. Stale prompts must be rebuilt when registered identities change; explicit subject/region masking remains available.
- QA now recognizes bracket-style variants of complete registered names without merging distinct people or titles.
- Shortened the single-image add-on prompt and documented sending it together with the user scene and references in one unsent message.

A real API run using the same seven reference sheets and reported script confirmed that unintended mosaic was removed. Generated text and visual fidelity still require review; this release does not guarantee perfect image compliance.
