# Super FURU AI 4-koma System v7.0.1

## 日本語

- STEP4のChatGPT Web用折り畳みに、4コマ動画化ボタンの下へ間隔を空けて1枚絵エモーショナルプロンプトのコピーボタンを移動しました。折り畳み名にも用途を追記しました。
- 初回の自動保存確認ボタンを黄色・オレンジで目立たせ、緩やかな点滅を追加しました。OSの「動きを減らす」設定時は点滅を止めます。
- 無料の2枚保存テスト終了後、利用者が実保存を確認して閉じると、リロードまで設定ボタンを隠し、全自動・連続ループの開始確認を省略します。追加のチェック欄や保存先フォルダの読み取り要求はありません。未実行・途中終了・要求失敗では確認済みにしません。
- Chromeの保存先変更、設定項目の展開操作、直接開くアドレスと貼り付け手順を案内しました。アプリはブラウザーへのダウンロード要求まで行い、実保存完了は自動検知できません。
- README本文と3冊のPDFをv7.0.1へ更新しました。既存のAPI生成・シナリオ・素材認識・制作情報の保存経路は保持しています。

## English

- Moved the single-image emotional prompt copy button into the STEP4 ChatGPT Web disclosure, below four-panel video guidance with additional spacing, and updated the disclosure label.
- Highlighted the required first-use save check in yellow/orange with a gentle pulse that respects reduced-motion preferences.
- After the free two-file test, users confirm that both files are saved and close the guide. The settings button and full-auto/endless startup prompts are then omitted until reload. No extra checkbox or folder-reading permission is requested; incomplete or failed test requests do not confirm the session.
- Clarified Chrome download-folder settings, the expandable permissions menu and the direct settings address with paste instructions. The app requests downloads but cannot detect completed disk writes.
- Updated the README body and all three PDF manuals to v7.0.1, preserving existing API generation, scenario, reference-recognition and production-metadata saving routes.
