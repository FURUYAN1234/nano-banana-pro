# Nano Banana Pro v5.0.8 - Visual Evidence Priority / シナリオ証拠の優先配置

## 日本語

- `VISUAL STORY EVIDENCE LOCK` をプロンプト末尾から `STRICT SCRIPT LOCK` の直後へ移動しました。
- 描画品質・スタイル・大まかな場所指定より前に置くことで、シナリオ固有の物証と背景が優先されます。
- 余分な空行をなくし、ChatGPT/OpenAI と Gemini の両プロンプト系統で同じ配置を保証します。
- 実OpenAI `gpt-image-2` 検証では、ゲームギア本体、単3電池パック、乾電池売場の棚、山積みの電池カゴを含む家電量販店の4コマ漫画を生成しました。

## English

- Moved `VISUAL STORY EVIDENCE LOCK` from the prompt tail to directly after `STRICT SCRIPT LOCK`.
- The scenario-specific visual evidence and setting now take priority before rendering quality, style, and broad setting guidance.
- Removed the extra blank separation and guarantee the same placement for both ChatGPT/OpenAI and Gemini prompt families.
- A live OpenAI `gpt-image-2` validation generated a four-panel electronics-store manga with a Game Gear, AA battery packs, battery shelves, and a basket piled with batteries.
