# Nano Banana Pro v5.0.6

## 日本語

- STEP2の背景プリセットを、安全性を確認した24種類へ拡充しました。従来の自由入力もそのまま利用できます。
- お題と雰囲気に合う安全な背景候補を優先するランキングを追加し、ホラー・流血・人体内部・生体的な背景候補は除外します。
- 選択した背景の環境アンカーをシナリオと最終画像プロンプトへ引き継ぎ、4コマを通して場所・天候・時間帯・主光源・代表的な小道具を維持します。
- 実際の OpenAI `gpt-4.1` と `gpt-image-2` を使い、`雨の駅前`、`発車案内板`、`濡れたタイル`を反映した1024x1536の縦4コマ画像を確認しました。

## English

- Expanded STEP2 to 24 curated, safety-checked background presets while preserving the existing free-text location input.
- Added topic- and mood-aware ranking for safe background candidates, excluding horror, gore, body-interior, and organic-body scenery.
- Carries stable environmental anchors from the selected location into the scenario and final image prompt, preserving location, weather, time of day, primary lighting, and recurring props across all four panels.
- Verified a live 1024x1536 vertical four-panel image through OpenAI `gpt-4.1` and `gpt-image-2`, with the rainy station entrance, departure board, and wet tiles visibly recurring.
