# Super FURU AI 4-koma System v7.3.8

## Action across panels / コマをまたぐアクション

- The serious and gag Action options now plan movement before the final panel. An early action changes where a person or object is, and the ending shows the result. / シリアスとギャグの「アクション」では、途中のコマから人物や物が動き、その変化が結末につながるよう台本を組み立てます。
- Scenario review checks whether that movement carries across panels. When only staging needs repair, the app edits the affected panel fields and preserves the title and dialogue. / 台本の検査で、途中の動きが結末につながっているかを確認します。演出だけを直す場合は、必要なコマの項目だけを差し替え、見出しと台詞を保持します。
- Verified movement across panels in color and monochrome API samples. In the monochrome sample, all nine lines survived and one panel needed an additional edit to make the balloon tails clear. / 実APIでカラーと白黒の作例を確認しました。白黒の作例は台詞9本を保持し、吹き出しの尾が曖昧だった1コマを追加修正しました。
