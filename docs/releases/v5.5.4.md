## Nano Banana Pro v5.5.4

### 日本語

- 公開Pages上の「ComfyUIワークフローJSONをダウンロード」ボタンを、Raw GitHubのクロスオリジンURLではなく、同じ公開Pages配下の配布JSONへ接続しました。
- これによりブラウザの標準 `download` 属性が有効になり、ボタン操作でJSONファイルを保存できます。
- ワークフロー内に表示するGitHub Rawの配布URLは維持しています。

### English

- Changed the public Pages "Download ComfyUI Workflow JSON" button from a cross-origin GitHub Raw URL to the same-origin Pages workflow asset.
- This keeps the browser-native `download` attribute effective so the JSON file is saved by the button action.
- The GitHub Raw distribution URL shown inside the workflow itself remains available.

### Verification

- Reproduced the missing public download event on v5.5.3 in the in-app browser.
- Added a regression that forbids the cross-origin Raw URL for the UI download action, then verified the correction locally before publication.
