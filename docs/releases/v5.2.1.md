# Nano Banana Pro v5.2.1 - Staging-Gag Dialogue Routing / 演出・ギャグ台詞振り分け

## 日本語

- `ギャグ演出:` と `演出ギャグ:` を構造ラベルとして認識し、後続の演出説明を話者名や吹き出し本文へ誤変換しないよう修正しました。
- 箇条書き、空白、区切り文字、対応する括弧付きのラベル形式も同じ視覚Actionとして処理します。
- 実OpenAI `gpt-image-2` で4コマ漫画を生成し、2〜4コマ目の演出説明が四角い台詞枠へ混入しないことを確認しました。

## English

- Recognizes both `gag staging` label orders as structural metadata so following visual direction prose is never converted into a speaker or speech-bubble text.
- Handles Markdown bullets, whitespace, separators, and matching wrapped-label forms as the same visual Action instruction.
- Generated a live four-panel manga through OpenAI `gpt-image-2` and verified that panel 2-4 staging prose does not appear as rectangular dialogue captions.
