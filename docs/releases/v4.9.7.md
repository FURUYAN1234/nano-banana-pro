# Nano Banana Pro v4.9.7 / Nano Banana Pro v4.9.7

## English

- Split STEP2 scenario enhancement into seven independent controls: expressions, body acting, visual effects, background, camera work, dialogue rewrite, and gag direction.
- Made each control modify only its selected scope. Unselected dialogue, camera, emotion, background, metadata, panel structure, and speakers are preserved.
- Made dialogue rewrite require an actual line change while rejecting no-op output, explanatory over-expansion, and weakened punchlines.
- Added post-response validation, one corrective retry, and fail-closed handling for invalid enhancement output.
- Verified the exact reported scenario through both OpenAI and Gemini API paths. OpenAI passed on the first response; Gemini's over-expanded first response was rejected and its automatic retry passed.
