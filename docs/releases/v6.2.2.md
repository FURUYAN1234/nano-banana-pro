# Nano Banana Pro v6.2.2

## English

- Four-panel prompt assembly now gives priority to cast count, identity markers such as glasses, wardrobe, exact scripted content, selected medium and page layout. It simplifies only unspecified background texture and decorative effects.
- Removed numeric quotas for camera azimuths and visual-style differences. A scripted frontal, quiet or repeated shot now remains as written, and unscripted direction may still use varied camera angles and staging.
- A paired Color and Monochrome visual check using the same saved scenario and character sheets showed no clone, missing glasses, clear uniform reversion, or obvious extra, mirrored or detached limbs in the visible framing. It is a two-page check, not a guarantee for every generation.

## 日本語

- 4コマのプロンプトでは、人数、眼鏡などの識別要素、衣装、台本、選択した媒体、ページ構成を優先し、未指定の背景テクスチャと装飾効果だけを整理します。
- カメラ方位と画風差の数値ノルマを外しました。台本に正面、静かなコマ、繰り返す構図がある場合はそのまま保持し、未指定の演出だけでカメラ角度や見せ方に変化を付けます。
- 同じ保存済み台本とキャラシートでカラーと白黒を1ページずつ目視確認し、見える範囲ではクローン、眼鏡欠落、明確な制服化、手足の増殖・反転・分離はありませんでした。2ページだけの確認であり、すべての生成結果を保証するものではありません。
