# Super FURU AI 4-koma System v6.7.3

## 日本語

- STEP2に「版権キャラクターにモザイクをかける」、STEP3に「ウオーターマークを表記する」を追加しました。両方とも初期状態はONです。透かしをOFFにすると、画像下部の左右のクレジット描画指示を外します。
- モザイク設定はシナリオ構築・精査・画像プロンプト・修正指示へ引き継ぎます。Geminiには対象の全身を粗い不透明なブロックで覆い、元の形・色・役割を保つ指示を追加しました。効果は生成ごとの確認が必要で、完全な再現を保証しません。
- API取得リンクを水色／明るい緑で見やすくし、OpenAIリンクの隣に「OpenAI APIマニュアル」を追加しました。同梱PDFを別タブで開きます。
- Geminiが画像を返さなかった場合、パラメーター不正と断定せず、画像未返却と応答情報を案内します。

### 検証

- [V1] 関連する43件の回帰テスト、lint、production buildを確認しました。両プロバイダー・カラー／白黒・チェックON/OFF、設定変更時の無効化、PDFリンクの配備先パス、画像未返却時の分類を含みます。
- [V2] OpenAIの実画像でモザイクと透かしOFFを確認しました。Geminiの先行画像で全身のモザイクと透かしOFFを確認し、利用者が現状での公開を承認しました。Geminiには対象置換・台詞重複が残る例があり、最終指示の再試行は画像未返却で終了しました。両者の同等画質や全品質項目の合格は主張しません。
- [V3] 同梱PDF・ローカル配信・ビルド成果物の一致を確認しました。Codex内蔵ブラウザーではPDFプレビューを表示できず、閲覧方法はブラウザーの設定に依存します。

## English

- Added default-on STEP2 copyrighted-character mosaic and STEP3 footer-watermark options. Disabling the footer option removes both bottom credit drawing instructions.
- Carry the mosaic choice through scenario construction, review, image prompts and repairs. Gemini receives a full-figure coarse opaque overlay instruction that preserves the subject's broad shape, colors and role. Generated results still require inspection.
- Improved API acquisition links with cyan and light-green styling and added an OpenAI API manual PDF link beside the OpenAI acquisition link.
- A Gemini response without an image now reports missing output and response evidence instead of falsely diagnosing invalid parameters.

Some Gemini examples still substituted the masked subject or duplicated dialogue. The final wording recheck returned no image. No equal-quality or universal visual pass is claimed.
