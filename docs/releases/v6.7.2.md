# Super FURU AI 4-koma System v6.7.2

## 日本語

- API画像の生成に成功しても、表示前に `Cannot read properties of undefined (reading 'width')` で停止する不具合を修正しました。すでにA4比率の画像をそのまま通す処理と、新規生成側の表示処理が食い違っていました。
- 新規生成と追加修正で同じ配置結果の判定を使います。正しいA4画像は再処理せず、比率がずれた画像だけ補正します。元画像の保持と履歴は維持しています。
- STEP4の内部エラーや原因未分類のエラーを、通信混雑やタイムアウトと決めつける案内を修正しました。
- OpenAI GPT Image 2.5 Sunburst / xhigh（2240×3168）とGemini 3.1 Flash Image（A4補正後848×1200）で、実生成・画面表示・履歴への保存を確認しました。漫画内容の品質検査には吹き出しなどの警告が残っており、本修正は内容の完全再現を保証するものではありません。

## English

- Fixed a crash after successful API image generation: the initial-generation consumer expected normalization geometry that is intentionally absent when an already-A4 image is passed through unchanged.
- Initial generation and follow-up edits now share layout-result handling. Correct A4 images remain unchanged; off-ratio images are normalized while preserving their source and history.
- STEP4 no longer mislabels internal or unclassified exceptions as network congestion or timeouts.
- Verified real generation, display and history with OpenAI GPT Image 2.5 Sunburst / xhigh at 2240×3168 and Gemini 3.1 Flash Image normalized to 848×1200. Content-quality warnings, including dialogue-balloon issues, remain distinct from this display fix.
