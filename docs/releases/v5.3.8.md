# Nano Banana Pro v5.3.8 - MiniMax H3 Workflow Clarification / MiniMax H3手順の明確化

## 日本語

- STEP4の「MiniMax H3・ComfyUI用プロンプトをコピー」案内を、実際の動画化フローに合わせて4手順へ更新しました。
- 指示文のコピーと同時に生成済み4コマ漫画を画像対応チャットへ添付・送信し、返ったプロンプトをコピーする手順を明記しました。
- ComfyUIで同じ漫画を`Reference Image`へ接続した後、画角と秒数を確認して英語プロンプトを`Prompt`へ貼り付けることを明記しました。
- MiniMax H3用の英語プロンプト本文、アプリ内の画像生成経路、APIキーの扱いは変更していません。

## English

- Updated the STEP4 MiniMax H3 and ComfyUI helper to present the actual video workflow as four clear steps.
- Clarified that users send the copied instruction together with the generated four-panel manga to an image-capable chat, then copy its returned prompt.
- Clarified that, after connecting the same manga as the ComfyUI `Reference Image`, users confirm framing and duration before pasting the English prompt into `Prompt`.
- The MiniMax H3 English prompt body, in-app image-generation path, and API-key handling are unchanged.
