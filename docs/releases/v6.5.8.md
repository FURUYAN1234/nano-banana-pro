# Nano Banana Pro v6.5.8

## 日本語

- Web版で手動生成する際の制作情報JSONと、API生成PNGへ埋め込む制作情報を別の経路へ分離しました。
- Web版用JSONは最終プロンプト完成時点で保存でき、API画像、モデルID、フォールバック状態、生成ID、出力画像ハッシュを要求・推測しません。
- API生成PNGは、実際のAPIモデルと出力画像ハッシュを含むAPI画像専用の制作情報を引き続き保存します。
- Web版経路へAPI画像専用項目を渡した場合に拒否する境界と、両経路が再び混同されないための正負の回帰テストを追加しました。

## English

- Separated the companion production record for manual Web generation from the production metadata embedded in API-generated PNG files.
- The Web companion JSON is available as soon as the final prompt is ready and does not require or infer an API image, model ID, fallback state, generation ID, or output-image hash.
- API-generated PNG files continue to store a dedicated API-image record with the actual model and output-image hash.
- Added a hard boundary that rejects API-only fields in the Web path, plus positive and negative regression tests preventing the two workflows from being merged again.
