# Nano Banana Pro v5.3.5 - API Session and Cast Integrity / APIセッションとキャスト整合性

## 日本語

- APIキー入力直後の接続前検証を、同じ入力を保ったまま45秒・最大3回の境界付き再試行に拡張し、読み込み直し依存をなくします。
- 全自動の遅延STEP2/STEP3応答が、手動で差し替えたシナリオを上書きしないよう実行世代を導入しました。
- 肩越し構図で明示された人物を前景に一度だけ割り当て、背景側から除外する汎用キャスト・インスタンス固定を追加しました。
- 年齢語の置換を独立した人物ロールだけに限定し、`青少年保護` などの複合語を書き換えないようにしました。

## English

- Expanded first-submit API preflight to bounded 45-second, three-attempt retries while preserving the same in-memory input, removing the need to reload.
- Added workflow epochs so delayed full-auto STEP2/STEP3 responses cannot overwrite a manually replaced scenario.
- Added a generic named OTS cast-instance lock that assigns an explicitly named over-the-shoulder subject to the foreground exactly once and removes it from the background list.
- Restricted age-term rewriting to standalone person roles so compound terms such as `青少年保護` remain verbatim.
