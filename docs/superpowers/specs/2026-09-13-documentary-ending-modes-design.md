# ドキュメンタリー結末モード設計

## 目的

「ストーリーの結末（オチの方向性）」に、原文忠実性を共有しながら結末の演出だけが異なる2種類のドキュメンタリーモードを設ける。

- `SeriousDocumentary`: シリアス・ドキュメンタリー（原文忠実＋オチだけシリアス漫画化・絵柄変更無し）
- `Documentary`: ギャグ・ドキュメンタリー（原文忠実＋オチだけギャグ漫画化）

既存の保存データで使われる `Documentary` は値を変更せず、ギャグ版として継続する。

## 必須動作

- 両モードとも1〜3コマ目は入力本文の事実、出来事、人物、因果関係を維持し、たとえ話への置換、無関係な舞台、架空の出来事、事実改変を禁止する。
- 4コマ目も事実を変えず、既存キャラクターの反応、感想、決意だけを漫画的な結末に使う。
- ギャグ版の4コマ目はツッコミ、誇張された反応、シュールな間を許可する。
- シリアス版の4コマ目は警告、決意、深刻な余韻、問題提起、静かな結論から内容に合うものを選ぶ。
- シリアス版は全4コマで、添付キャラクターシートの絵柄、線質、塗り、陰影、顔、頭身、デフォルメ度を維持する。シリアスさは表情、視線、身体演技、カメラ、構図、照明、間で表現する。
- シリアス版ではパネル別画風変更と外部作風JSONによる画風上書きを禁止する。
- キャラクターシートのレイアウト、説明文、表情一覧、見本ポーズ、白背景は漫画内容として複製しない。
- 白黒選択時は色だけを白・黒・網点へ変換し、キャラクターシート由来の線質、顔、頭身、陰影設計を維持する。
- 両モードの画像プロンプトに既存ドキュメンタリー・サニタイザーを適用し、表示中のシナリオ本文は書き換えない。

## アーキテクチャ

`src/lib/ending-mode-policy.js` を唯一のモード判定源とし、UIラベル、`documentary` 判定、結末トーン、参照絵柄固定を返す。STEP2、STEP3、画像プロンプト、AI精査、表示ラベルはこのポリシーを共有する。

シリアス版では `EMOTION` は感情と演技の手掛かりとしてだけ扱い、`PANEL STYLE LOCK`、頭身変更、画風変更、ギャグオーバーレイへ変換しない。API生成とWeb貼付は同じ最終プロンプトを使うため、両経路に同じ契約が適用される。

## エラー処理と互換性

- 未知の値は従来どおり通常モードとして扱う。
- 既存 `Documentary` は移行不要でギャグ版として解釈する。
- AI精査が失敗または不正形式なら元のプロンプトを保持する。
- 既存のシナリオ完全性、人物、小物、会話、カメラ、白黒、セーフティ検証は削除しない。

## 受入条件

- STEP2でシリアス版がギャグ版の直上に表示される。
- シリアス版のSTEP2指示からギャグ強制、絵柄急変、複数画風の要求が除かれる。
- シリアス版のChatGPT/Gemini最終プロンプトに全4コマ参照絵柄固定が入り、パネル別画風変更が入らない。
- ギャグ版は既存保存値で原文忠実＋4コマ目だけギャグを維持する。
- 両版にサニタイザーが適用され、通常モードとカラー／白黒契約に回帰がない。

## 対象外

キャラクター名・人数・記事・台詞に依存する規則、STEP4画像後処理、公開、note更新、バックアップ。ユーザー指定の実API検証1回だけは対象内とする。

## 追加スコープ: FourPanel v5.9.9 と標準H3汎用プロンプト

- 添付ZIPをバイト変更せず検証し、`FourPanel_NonLM_4step_20260913115712_v5.9.9.json` と `ComfyUI_H3_FourPanel_NonLM_20260913115712_v5.9.9.zip` を既存の別ボタンへ接続する。
- ZIP同梱はNanoBanana-H3、MiniMax-H3-Long-Video、Spectrum-MiniMax-H3の3点。PlagueKind-Nodes、H3-AudioRefine、対応Tritonは別途必須として画面に明記する。
- クリップボードに残っていた固有キャラクター・固有台詞の画像プロンプトは採用しない。標準H3用ボタンは、任意の4コマ画像から人物集合、同一性、話者、台詞、動作、カメラ、音を導出する汎用メタプロンプトをコピーする。
- 配布版から移植できる四コマ順序、各コマ人物固定、一人一台詞窓、発声前後の無音余白、台詞中の穏やかなカメラ、低音量BGMを取り込む。
- 公式MiniMax H3 Skillに従い、Ref2VAの6セクション順、4〜15秒、Shot 1は時刻なし、以後は`At MM:SS.mmm`、台詞原文保持、カメラ種別・必要時の振幅・速度、通常350〜500英語語を使用する。
- 標準グラフで自動化できない画像前処理、API台詞抽出・読み確認、行ごとの自動可変尺、候補比較、音声・映像監査、終端波形修復と、画像・台詞・秒数・フレーム数の手動設定を同じメニュー内で説明する。
