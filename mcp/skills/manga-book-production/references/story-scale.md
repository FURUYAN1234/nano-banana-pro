# 尺・章・複線を設計する

ページ数の確定はSKILL.mdに従う。数字指定が優先、区分だけなら短編32P・中編64P・長編192P、両方なければ確認する。区分の初期値は作品を始めるための目安で、出版共通の定義ではない。以下はその尺を構成へ変える手順で、小説の字数を漫画のページへ換算したものではない。

| 規模 | 組み方 | ありがちな失敗 |
| --- | --- | --- |
| 1P・ごく短い作品 | 中心となる体験を絞り、同じ行動に導入と展開の役割を兼ねさせる。反応と着地の面積を先に確保。 | 全工程を一コマずつ置いて窮屈にする／前提を全部省いて突然見せ場へ行く。 |
| 短編 | 一本の中心的な関係や問題を、必要な場面数で変化させる。過去説明は現在の選択へ効く分だけ。 | 人物紹介の後に予定どおり解決する／副筋が本題の紙面を奪う。 |
| 中編 | 中心の進行に、関係や価値観の動きを重ねる。段階ごとに試みと結果を変える。 | 短編を引き延ばす／長編並みの人物・世界・副筋を詰め込む。 |
| 長編・連載 | 作品全体、部／巻、章、場面の目的を階層で管理する。主筋・副筋・人物の経過が互いへ作用する。 | 各章で同じ問題に戻る／伏線だけ増やす／後半の都合で確定設定を書き換える。 |

## 中編で読む手応えを保つ

中心の問いに対して、試す方法、得る情報、人物同士の距離を段階的に変える。同じ言い間違いやすれ違いの反復なら、結果や受け止め方が積み上がっているかを見る。途中の安心、笑い、休息も、それまでの変化を感じるための場面にできる。

中盤が弱いときは事故や新人物を足す前に、主人公の手段が変わらない理由を調べる。副筋は主筋の選択、関係、読者の理解に効くものを選び、人数や本数の定数は作らない。

## 長編は全体と現在地を分ける

全体の到達方向と主要な節目を粗く把握し、現在制作する章を詳細化する。全巻の全台詞を先に固定せず、未確定を確定事実として扱わない。結末未定を許す依頼では複数の着地候補と現在の制約を残す。

必要な規模で、既存の制作記録に次を保つ。管理表は脚本の代用品ではない。

| 記録 | 必要な項目 |
| --- | --- |
| 作品・章の見取り図 | 主要な問い、現在の状態、次の試み、区間末の変化、全体との関係。 |
| 主筋と副筋 | 初登場、今の進行、主筋や他人物へ影響する接点、次に扱う箇所。 |
| 仕込みと回収 | 読者に示したコマ／章、現時点で読める意味、後の役目、未回収／回収済み／意図的に保留。 |
| 人物と知識 | 望み、守りたいもの、知った事実と時点、誤解、関係・選択の変化。 |
| 確定事実 | 時間、場所、所持品、世界の仕組み、約束、採用済み設定。未採用案とは分離。 |

章の終わりには、その区間を読んだ手応えと先を読みたい理由を考える。全体の謎を残すために、毎章何も判明せず終わる構成へしない。一方、毎章で全問題を解決して人物を初期状態へ戻す必要もない。巻分け・連載単位が指定されたら、その区切りの読後感も設計する。

視点切替では、その人物にしか示せない判断や体験が何かを見る。同じ情報を各人物が聞き直すだけなら圧縮できる。群像劇では必ず一人の主人公へ統合するのではなく、各視点が全体の中心へどう関わるかを確かめる。

## 構造を道具として選ぶ

- 三幕などの枠組みは、展開の偏りを見つける補助に使える。割合や出来事の位置を作品へ強制しない。
- 起承転結、累積、対比、円環、日常の一断面等も、依頼された読後感に合えば使う。全作品に敵・敗北・成長を要求しない。
- 謎を追う話では、作者の正解と読者・人物へ渡した手掛かりを分ける。後出し設定でしか解けない場合を意図した謎と混同しない。
- 成長しない主人公でも、周囲や読者の見方が変わる話を作れる。悲劇や未解決の結末を成功物語へ勝手に変えない。

## 改稿と続きの整合

一章を直したら、その変更が知識・所持品・関係・仕込みに及ぶ後続だけを辿る。後半の見せ場を都合よく作るために、すでに描いた選択を忘れさせない。遡る変更が必要なら影響する範囲と承認を明示し、完成画像へ無断で適用しない。

長編対応を確認するときは、全体概要が書けたことと、全章・全ページの詳細と内容が確認できたことを分けて報告する。短い試作一本で長編品質まで実証したとは言わない。

## ページ数の初期値の根拠と限界

2026-11-17の公式情報では、[小学館新人コミック大賞](https://shincomi.shogakukan.co.jp/)のストーリー漫画は32ページ前後、[ジャンプSQ. SPARK](https://jumpsq.shueisha.co.jp/mangasyou/index.html)は55ページ以内で、読み切りでも規定に幅がある。[集英社の単行本書誌例](https://www.shueisha.co.jp/books/items/contents.html?isbn=4-08-872822-X)には192ページの巻がある。これらは短・中・長編の普遍的分類ではない。

32Pは読み切りの目安、64Pはより段階を描ける中編の作業用初期値、192Pは単行本一巻程度を念頭に置いた長編の初期値として、このスキルで選んだ。特に64Pが業界統一基準であるとは説明しない。応募先・媒体・予算・巻数・本人指定がある場合はそちらを優先する。出版社へ応募する作業なら当該規定をその時点で再確認する。

複数巻・連載の依頼は、総ページ数と巻／話単位の配分を別々に記録する。画像制作へ移る場合には現在のMCP能力の上限を確認し、対応する区間単位へ受け渡す。スキルの長編構成対応を、そのページ数が一回のMCPジョブで生成できるという保証にしない。
