# シナリオを組み立てる

以下は短編・中編・長編に共通する設計上の道具。毎場面への全項目適用、固定ビート数、危機や成長の強制はしない。原理の出典と、このスキル独自の応用はstory-sources.mdで区別する。

## 出発点：面白い設定と、動く話を分ける

「恥ずかしい告白をする」「宝を見つける」は結果であり、そこまで読みたい理由がまだない。人物、場面、出来事、台詞のどこから発想してもよいが、詳しい台詞を書く前に、次の設計メモを短く作る。

| 設計するもの | 具体化する内容 |
| --- | --- |
| 読者の期待 | 誰の何を見届けたいか。笑い、切なさ、驚き等を起こす場面は何か。 |
| 現在の関係・状況 | 普段はどうしており、今回は何が違うか。読者へどの行動で伝えるか。 |
| 望みとためらい | 何をしたいが、何が怖い／難しいのか。動かないと何が続くか。 |
| 手段 | その人ならどう切り出す／探す／逃げるか。性格が選択に現れるか。 |
| 相手・環境の応答 | 都合のよい相づちでなく、別の望みや制約からどう反応するか。 |
| 到達点 | 最後に状況・関係・理解・読者の見え方の何が違うか。依頼の結末を守る。 |

本人が大切にするものを扱う。代償は失恋や死でなく、面子、いつもの帰り道、約束、気安さでもよい。日常観察や無言作品では、達成目標を無理に作らず「どの見え方・感情の差を味わう話か」で設計する。

## 1. 人物の特徴を選択に変える

シートがある人物は、記載された性格・話し方・価値観・関係・癖・行動傾向を、台詞・選択・相手への反応の根拠にする。衣装変更や舞台移動だけを人格変更の理由にしない。利用者による明示的な改変は優先し、元シートとの差を共有設定へ反映する。

記載がない項目は、外見・役割・物語の展開からAIが創作上の仮設定を補完し、詳細案で提案する。「シート記載」と「今回の創作補完」を区別して短い人物設定へ残し、以降のページでも一貫させる。見た目から唯一の人格が事実として決まるとは扱わず、実在人物の特性推定へ広げない。不足項目の全件質問は不要で、物語を左右する必須条件だけを既存指示と照合する。

優しい・照れ屋という形容だけでは行動が生まれにくい。「助けたいが頼まれる前に手を出しすぎる」「誘いたいが相手の都合を先に尋ねて引っ込める」のように、長所と不都合が同じ行動に出る形を考える。過去の傷を全員へ追加する必要はない。

主人公だけでなく応答する人物にも、その場で守りたいものやしたいことを持たせる。一方が話を進めるため、もう一方が必要以上に鈍感になったり悪意を持ったりしていないかを見る。

「今それを言えば済むのでは」という疑問には、言わない理由を行動で示す。明らかになった事実を聞かなかったことにして同じ誤解を引き延ばさない。理由が成立しなければ、その誤解を使う筋そのものを変える。

## 2. 冒頭で読者を参加させる

導入の仕事は設定の全説明ではない。いまの場面を理解する最小の情報と、続きを知りたい手掛かりを同時に渡す。

- 人物を紹介する日常動作に、その話の小さな困り事や意外な癖を重ねる。
- 関係を説明する代わりに、頼めること／頼めないこと、気づくこと、返し方を見せる。
- 読者が知らなくても楽しめる謎と、知らないと状況を読めない前提を分ける。場所・声の届く相手等は後者になりやすい。
- 冒頭から事件や告白を置く構成も使える。ただしその瞬間の意味を追う手掛かりを渡す。告白を後のページへ動かしただけでは改善にならない。

単なる片付け・飲み物・自己紹介を順に並べて尺を埋めない。それが後の選択、相手への見方、読者の期待にどう効くかを確かめる。静かな間は残せる。削ると失われる体験が何かを見る。

## 3. 因果から展開を作る

場面の骨を「状況 → 人物の働きかけ → 応答／結果 → 変わった判断 → 次の働きかけ」でつなぐ。これは説明用の形であり、全コマを同じ順に並べるテンプレートではない。

行動の後に別の出来事が起きるだけなら、つながりを作り直す。偶然は始まりや混乱を作れても、終盤の都合のよい解決を担わせない。登場人物の選択や既出の条件で着地できるかを確認する。

展開が弱いときは同じ粗筋の言い換えを増やさず、手段・応答・選択のどれを変えると話が動くか考える。必要なら少数の異なる筋を短く比較し、読者への届き方と尺に合うものを選ぶ。すでに有効な案があれば比較を儀式化しない。

## 4. 感情の変化を経験にする

見せ場で感じてほしい感情から、前に必要な経験を逆算する。読者に「好きらしい」と知らせることと、「この二人なら応援したい」と感じてもらうことは違う。特別な扱い、失敗への接し方、小さな選択とその受け止め方を描く。

強度を上げるときは、形容詞・赤面・長い台詞・事件の大きさだけを増やさない。隠していた本音が一段具体的になる、守っていた逃げ道を自分で手放す、受け手が予想と違う大切にし方を返す等、関係の変化を考える。どの作品にも同じ変化を強制しない。

恋愛では相手への具体的な関心と相互の応答、喜劇では予想と反応のずれ、謎では疑問・手掛かり・解釈の更新、冒険では選択とその結果を中心に組める。ジャンルに合う手段を選び、全部を同じ作品へ入れない。

## 5. 仕込み・変化・回収をつなぐ

後で意味を持つ行動・物・言葉には、初登場時にも自然な役目を与える。終盤で同じ物を出すだけでは回収にならない。人物や読者にとっての意味がどう変わったかを見る。

結末から逆に辿り、必要な気持ち・能力・約束・手掛かりが本文中にあるか確認する。人物設定欄にだけある能力や、最後に初登場する通信経路で解決しない。驚きは読み返せば筋が通るかで評価する。謎解きでない作品に全伏線の説明を強制しない。

## 6. 場面を紙面へ変える

ページや章を切る前に、重要な行動と反応が何回必要かを考える。コマ数はその容量。長い独白で複数段階を一度に説明したり、一コマで告白・驚き・返事・抱擁をすべて済ませたりしない。

各場面について「始めの状態／終わりの状態／間を変える行動」を短く記録する。変化は事件だけでなく、親しさ、確信、誤解、呼吸の変化でもよい。意図した反復では、同じ動作の見え方がどう違うかを書く。

間、反応、移動、紙面上の情報提示に必要なコマを割り当てる。次ページへの引きは未完の質問、選びかけた行動、予想と違う返事等から作れ、毎ページの大事件を必要としない。承認済みの動作・視点意図を、描画都合で消さない。

## 7. 台詞を説明から働きかけへ変える

台詞には、その相手へ今言う理由を持たせる。頼む、探る、ごまかす、安心させる、断る、受け入れる等の意図が場面から読めるか。全台詞を婉曲にせず、直接言うことが行動になる瞬間は直接言わせる。

- 相手も知っている設定を説明する会話は、必要な行動や短い言い争い等へ置き換えられないか見る。
- 内心の整理を相手へ全部口に出す不自然さを避ける。心内語ならその扱いを明示する。説明を減らして意味まで失わない。
- 話者名を隠しても、望み、言い直し方、気遣い方に違いがあるか。語尾の記号だけで区別しない。
- 読み上げて長さと応答を確かめ、話者、視線、手の動き、台詞が同時に成立する分量へ直す。

## 8. 推敲は原因の大きい順に行う

まず企画の狙いと中心の関係、次に因果と情報の配置、次に場面の長さと反応、最後に台詞の調子を直す。原因が導入不足なのに画像を再生成したり、甘い台詞を追加したりしない。

改稿前を残し、「どの読みにくさを、どの変更で直したか」を比較する。場面を抜く仮比較では物語の情報だけでなく、感情、笑い、空気、人物への親しみが失われないかを見る。説明が減っただけ、文字数が増えただけでは採用しない。

具体的な問題が解消したら、題材と無関係な規則を増やして磨き続けない。数値満点や固定回数の改稿、別APIの審査を必須にしない。成立・読者体験の根拠はscenario-check.mdへ、制作ごとの教訓は既存の作業記録へ残す。

## 9. 場面で何を感じてもらうか

見せ場を作る前に「ここを読んだ直後、どんな気持ちで次のコマへ進んでほしいか」を一文で考える。その場で誰が何に気づくか、読者にどの絵を先に渡すかを決める。複数ページでは、直前のコマで期待を作り、次のページのどの絵で見方が変わるかも考える。先のページまで同時に見える形式では、画面上の読順と情報の位置で調整する。

場面に合う手掛かりを選ぶ。下の例はその働きを説明するためのもの。使う動作や構図は人物と舞台に合わせる。

- **親しさ。** 閉店後、相手が来る前から椅子を一脚だけ出している。何をしてもらったかより、先回りして取った行動で二人の関係が伝わる。
- **不穏さ。** 店先の鉢だけが毎朝少しずつ戸口に近づいている。いつもの位置が分かる絵を先に置き、いつ本人が気づくかで期待を作る。
- **気まずさ。** 前は並べていた二人の傘を、口論のあと片方だけ離して立てる。説明台詞がなくても、同じ場所で取った行動の違いを読める。
- **安堵や寂しさ。** 閉店の札を返したあと、いつもの釣り銭皿を拭いてから空の棚に戻す。結末の説明を足す前に、何が終わり、何が残ったかを見せる行動を探す。

原則、AIが見せ方を選び、完成した詳細台本を一案で提示する。狙いの説明は肝心な箇所に絞る。ためらう理由があり、どちらも成立するのに読み味が違う場合だけ、一つの場面に絞って見せ方を変える。提示は「A案全文」「B案全文」「二案の差」「AIのおすすめと理由」の順。各案は共通のコマも含め、全ページの動作・反応・台詞を通読できる形にする。長編で今回の承認対象を章や話に区切っている場合は、その承認範囲の全文を両方に載せる。差の説明には、読者に何が早く伝わり、どんな余韻が残るかを書く。おすすめの案名を明記する。既存の台本確認にまとめ、「OK」で表示したおすすめ案を採用できるようにする。代案を選んだり別の希望を伝えたりできることも同じ箇所で案内する。利用者が別案を選んだら、影響するコマを直して続き方を点検し、変更した具体案を提示する。

作画後は前後のコマをつなげて読み、狙いが届くと判断した手掛かりを画像から挙げる。絵が手掛かりを描き落としたのか、元の台本の見せ方で伝わりづらいのかを考えて修正先を決める。読者の反応は試読で確かめられる。
