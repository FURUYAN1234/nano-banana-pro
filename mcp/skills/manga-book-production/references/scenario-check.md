# 提案・画像生成前のシナリオチェック

台本を直すための確認。項目名の列挙や「確認済み」だけで合格にしない。設定資料を隠し、読者が見るコマの順で読む。長編では全体構成と制作対象の章・ページの詳細を分けて確認する。

## A. 出来事が成立しているか

| 項目 | コマから確かめること |
| --- | --- |
| 場面 | 誰がどこにいて、誰に見聞きできるか。移動、時刻、同席者の変化が分かるか。 |
| 知識 | 人物ごとに何を知り、何を誤解しているか。読者だけの情報で反応していないか。 |
| 動機 | 今この行動を選ぶ理由があるか。結末のために不自然な見落としをさせていないか。 |
| 因果 | 行動の結果が次の反応・選択へつながるか。公開済みの事実を秘密の露見として扱っていないか。 |
| 道具・仕組み | 所持者・位置・送受信・開閉など、展開に必要な状態が示されているか。最後に便利な機能を生やしていないか。 |
| 言葉 | 話者と台詞が合い、発話・心内語・ナレーションを混同していないか。 |
| 継続と指定 | 前後の出来事、知識、衣装、小道具、関係がつながるか。尺・コマ数・人物・必須台詞・結末を守るか。改稿後の話の中心とタイトルが合い、扉・作品名・提案本文で旧題が混在していないか。 |

画像AIの補完を、台本にない因果の解決に使わない。意図した空想設定、笑いの誇張、自然な視覚的補完は、それ自体を不合格にしない。

## B. 読みたい・感じたい話になっているか

| 項目 | 本文中の根拠と、不足時の直し方 |
| --- | --- |
| 読者の入口 | 冒頭から誰のどんな状況を追えるか。重要な前提がないなら導入の行動へ組み込む。人物紹介を前に貼るだけにしない。 |
| 人物への関心 | 何を望み、何を大事にする人かが行動で読めるか。好意・反感・好奇心を持つ手掛かりを具体化する。全員を好人物にはしない。 |
| 話の進行 | 展開が変える判断・関係・期待は何か。同じやり取りの繰返しなら、結果が蓄積しているかを見る。 |
| 感情の準備 | 告白・決別・救出などの見せ場に至る経験があるか。設定上の両思いだけで読者がときめくと仮定しない。 |
| 驚きと納得 | 予想と違う展開が人物・既出条件から生じるか。結末だけの便利な偶然や、既存作品の特徴的な展開の借用になっていないか。 |
| 会話と間 | 事情の説明だけでなく応答があるか。絵で示した心情を毎回読み上げていないか。必要な沈黙や反応が残るか。 |
| 着地 | 依頼された体験が、どの行動・返答・見え方に結び付いて終わるか。甘い形容や説明で終わっていないか。 |
| 長い作品の現在地 | 各章の手応え、主筋の進行、副筋との作用、伏線・知識の管理があるか。全体案だけで未執筆の詳細を検査済みにしない。 |

Bは好みを絶対化する検査ではない。依頼された狙いに対する不足を、該当場面と読者への影響で説明する。静けさ、意図した反復、未解決の余韻、無言、冒頭の強い出来事を一律に排除しない。

## 判定と適用範囲

既存の制作記録に「対象の版／範囲、Aの具体的根拠、Bの具体的根拠、指摘と改稿、残る問題、判定」を短く残す。MCP連携時はproject IDと計画revision/hashも結び付ける。

矛盾がないことと、今回の読者体験が成立することを別々に判断する。未解決の必須前提や、狙いを損なう構成上の不足があれば要修正。数値得点は合格根拠にしない。提案前に実際に確認し、画像生成の直前には同じ計画であることを確認する。ユーザー承認はこの検査の代行ではない。

新しい画像生成は、対象の台本が成立し、ユーザーが具体案を了承してから。制作中に重大な矛盾が見つかったら画像投入を止め、台本へ戻る。明示停止があれば正規の停止と実状態を確認する。既存の成立した画像を微差や指示追加だけで再生成しない。

チェックは手順であり、未来の誤りを技術的に封じるものではない。人の読者評価を受けていない案を「面白さを実証済み」としない。
