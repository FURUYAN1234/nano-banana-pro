# 作例と検証課題

技法の名前を答えられることではなく、新しい依頼から読める台本を作れるか確かめる。下の例と課題はこのスキル用のオリジナルで、出典教材の物語例ではない。題材を本番の必須パターンへ昇格しない。

## 小さな改善例：関係を説明せずに見せる

弱い例：二人が「私たちは互いを大切にしている」と話し、そのまま仲良く帰る。関係の説明だけで、相手の反応や小さな発見がない。

改稿例・4コマの静かな日常：

1. 雨の店先。花を買った帰りの人が、折れた枝を巻き直した小さな花束を持つ。店員は最後の傘を手渡す。
2. 客は自分の肩を濡らし、傘を花束へ寄せる。店員がそれに気づく。
3. 店員は店から空の細長い箱を持ってきて、花束を入れる。客が傘を自分の上へ戻せる。
4. 客が差し出した花束の一本を、店員が受け取る。折れた枝の添え木は残る。二人は小さく会釈する。

この例が示すのは、相手が何を大切にしているかを見て応答する構成。花や雨が常に必要なのではない。大事件、説明台詞、恋愛、人生の成長を足さずに人物への関心を作る練習として使う。実画像での成立を検証した例ではない。

## 改訂時の実作課題

新規作成や大きな改訂時に、変更した判断に効く課題を選んで実際の文章を作る。毎回全課題や追加の有料APIを必須にしない。検証では以前の作例の言い換えを避け、異なる題材も使う。

- 1P：無言の日常漫画。登場人物二人以内、4コマ。大事件なしで関係が読める台本。余計な表紙・説明台詞・危機を足していないか。
- 短編：出会いまたは既存の関係が分かる恋愛漫画。告白の有無を先に固定せず、人物の行動から気持ちが動く場面を書く。設定欄を隠しても場面を追えるか。
- 中編：仕事や共同作業を題材にした読み切り。全体構成と要となる一場面を作る。途中の試みが変わり、関係の動きが問題解決へ効くか。
- 長編：複数章・複数視点の物語。作品全体と章の構成、主副筋の接点、知識・仕込みの記録例、冒頭の詳細を作る。各章の手応えと全体の進行を区別できるか。
- 例外：成長しない主人公、悲劇、意図した反復、非線形の時系列、承認済み台本の再開。規則が依頼を壊していないか。

## 検証の読み方

作者用の設計メモと、読者が読む台本を分ける。台本だけで、状況・人物の関心・行動のつながり・到達点を説明できるか確かめる。理解がずれた箇所には、読者へ示した情報が足りないのか、意図した謎なのかを記す。

前後比較では「導入あり」「伏線あり」等のラベルで合格にしない。どの行動が関係を伝え、どの反応が次を生んだかを示す。具体的な不足があればその原因の層へ戻り、改善と副作用を確認する。実施した一例の結果を全ジャンル・全長編へ一般化しない。

独立評価が許可され利用可能なら、評価者に新しい依頼とスキルを渡し、こちらの期待する答え・疑う問題・改訂理由は渡さずに作ってもらう。委任がなくても直接の実作確認はできるが、独立評価とは呼ばない。人の読者による評価とAI同士の評価も分ける。

## ページ数の選択を確認する課題

- 「短編の漫画」→32Pを明示して構成。「中編」→64P、「長編」→192P。区分の追加確認はしない。
- 「短編24P」→24P。「本文32P＋扉1P」→合計33P。「1P」→別表紙なし。
- 「漫画を作って」「数ページで」だけ→既存の合意がないか確認し、なければ尺を質問して構成を待つ。無回答を32Pの承認にしない。
- 「漫画を作って。長さは任せる」→理由と選んだ尺を示して進める。
- 前のターンで「表紙込み4P」と確定→再開時にページ数を質問しない。
