# 知見の取り込み方と出典

このスキルはStory Makerの同時インストール、ソースファイル、ネット接続を通常の脚本作業の前提にしない。必要な設計手順を同梱する。以下は調査時の由来であり、利用者に別アプリ導入を要求するものではない。

## 外部教材を使うとき

1. 著者本人・制作元・教育機関などの一次資料を優先し、実際に読めた範囲だけを根拠にする。未視聴の動画全体、検索結果の見出しだけで読了・習得としない。
2. 原理を理解し、今回の不足にどう効くかを自分の言葉で書く。本文、長い翻訳、図表、チェックリストの同一順序・言い換えだけの複製を同梱しない。作品例の人物・台詞・特徴的な出来事の組合せを新作へ移さない。
3. 出典で確認した原理と、漫画向けに独自に考えた手順・例を分ける。固有の理論名を独自発明のように説明せず、著者名とリンクを添える。出典表記があるだけで転載を認められたとは扱わない。
4. 一般的な原理でも、特定作品に近い設定・展開になっていないか完成案を確認する。名前や舞台だけの置換は独自の作例にしない。参照なしで新しい人物・問題・選択から組み立てる。
5. 小さな作例で試し、どの不足がどう改善したかを比較する。題材や尺を変えた確認も行い、失敗例と適用しない場面を残す。外部サービスへの追加投稿・API・有料教材取得は自動追加しない。
6. デプロイ時に確認できた教訓だけを統合する。説明が長くなる一方なら重複を削る。モデルの重みを訓練した、他環境でも同じ品質を保証したとは言わない。

## 実在の作品や製品を台本で扱うとき

正式名や実際の特徴は、制作元の製品ページ・公式告知などで確認する。正式名、登場人物が使う略称、漫画タイトルに採用した意図的なもじりを区別し、意図した表記は台本・扉・吹き出しでそろえる。初見の読者が話についていくための背景は、会話や行動に載せられる短い説明を選ぶ。事実として述べることは資料で確かめ、創作上の設定と取り違えない。

## Web一次資料（2026-11-17確認）

引用文や教材の図版は収録していない。下記の要旨と、本スキルの独立した設計・演習は同一物ではない。

- John August, [How to Write a Scene](https://johnaugust.com/wp-content/uploads/2014/06/how-to-write-a-scene.pdf)（本人の2ページ資料）。場面に必要な働き、登場人物・場所、長さ、書き起こし前の構想を扱う。ここから場面の役割を確認する観点を参考にした。漫画へのコマ配分や、静かな間を残す扱いは本スキルの応用。
- Craig Mazin, [Scriptnotes Episode 403](https://johnaugust.com/2019/scriptnotes-ep-403-how-to-write-a-movie-transcript)（公式掲載の文字起こし）。固定的な構造図に先立って、人物と主題、場面での状態の変化を考える説明を参照。全作品への成長・主題論の強制は採用せず、人物の選択から構成する補助にした。参照したのは文字起こしの構造・人物・場面に関する部分。
- Pixar / Khan Academy, [The Art of Storytelling](https://www.khanacademy.org/computing/pixar/storytelling)（公式のコース案内）。人物の望み・障害・代償、構造、提案とフィードバックを扱う構成を確認。各動画の全視聴はしていない。技法を読んだだけでなく、作例を提示して不足を直す学習方法の参考にした。
- Writing Excuses, [12.36: Structuring a Mid-Length Piece](https://writingexcuses.com/12-36-structuring-a-mid-length-piece/)（公式掲載の解説・文字起こし）。尺に合わせた筋・視点・描写の取捨選択を参照。漫画の固定ページ数や人物数へ置換していない。
- Writing Excuses, [12.37: Subplots](https://writingexcuses.com/12-37-subplots/)（公式掲載の解説・文字起こし）。副筋が全体へどう作用するかと、脇へそれすぎる問題を参照。全脇役に副筋を必須にしない。
- Writing Excuses / Peng Shepherd, [17.40: Questions & Answers About Structure](https://writingexcuses.com/17-40-questions-answers-about-structure-with-special-guest-peng-shepherd/)（公式掲載の解説・文字起こし）。複数巻の区切り、筋の優先順位、人物の動機と構成の結び付きに関する要旨を確認。story-scale.mdの記録表はこのスキル独自の整理で、原資料の図表ではない。

## 独自に構築した部分

本スキルの設計メモ、漫画のコマと章への受け渡し、検査の二段階、台本だけで読む検証課題、オリジナル作例は、実制作の失敗と複数の一般原理を踏まえた編集。原資料を見なくても使えるよう記述する。調査したこと、指示へ取り込んだこと、実際の脚本が良くなったことは別々に評価する。
