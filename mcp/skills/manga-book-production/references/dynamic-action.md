# 派手な動きのあるコマを設計する

派手なアクションを求められたときや、動きで話が決まる場面に使う。各コマの役割を短く決め、山場には相性のよい技法を重ねて、大きく・速く・強く見せる。地理を伝えるコマ、手元を読ませるコマ、落ち着くコマとの落差も使う。全コマに全技法を足す必要はない。

1. **動いた前後を決める。** 誰が何のために、どこから何に向かい、どこで接触し、何が変わるかを一文にする。助走・転換・決め・余韻から、いちばん見せたい一瞬を選ぶ。重要人物の複数に見せ場があるなら、受ける、避ける、運ぶ、投げ返すなど、各人が結果を変える動作を割り当てる。二人目を驚くだけの反応役にしない。体格、癖、道具で動きを描き分ける。
2. **ポーズそのものを大きく動かす。** 支持脚や支点、重心、胸郭と骨盤の逆ひねり、肘や膝の伸び縮み、前後の手足の遠近、髪や服の遅れを決める。圧縮から伸び、押し出し、空中での反転、踏み止まりのどれを強調するか選ぶ。手足を同じ方向へ並べず、力が走る線を頭から道具や足先まで追える一続きのシルエットを作る。人体や道具はつながる立体として保つ。
3. **見せたい動作から撮影位置を選ぶ。** 上下左右・正面背面・斜め、アオリ、俯瞰、真上、広角、望遠、ダッチアングル、寄り・引きは別の選択。たとえば畳すれすれの超広角で前景を誇張し、画面を傾けて転回の軸を通す。上からなら軌道や着地点を一枚で示し、望遠なら離れた人物や手元のタイミングを近くに見せる。カメラを切り返す前に位置関係や行動方向の目印を置く。角度を変えただけで派手になったと扱わない。
4. **流れが読み取れる効果を選ぶ。** 直線の流線は加速、弧は回転、短い集中線や白抜きの破裂形は接触に使い分ける。モーションブラーは移動方向と逆へ伸ばす背景や速度のある端に局所化し、見せる目、指、接点、道具の輪郭、必要な文字は判読できるよう残す。残像は同じ人の軌跡と読める明度や輪郭にする。白黒では黒ベタ、白抜き、網点の明暗を使い、布・紙・破片や背景の斜線も力の向きに揃える。動作の成立に必要な接点を擬音やエフェクトで隠さない。
5. **紙面で勢いを増幅する。** 大ゴマと小コマ、斜めの構図、前後の重なり、枠越え、外縁へのタチキリから、その場面の読順とインパクトを強めるものを組み合わせる。何の部位がどこへ越え、近くの顔や台詞のどこを空けるかを先に設計する。FURUの `PageComposition` でページ全体の前景は主焦点の一人に絞り、別コマの局所的な越境は、辺を共有する隣接コマへの `breakouts` で渡せる。本文の `Camera` と動作指定、ページ構成の三つを一致させる。

作画前に、台本だけで「動作の主体・支点・方向・接点・結果・止めて見せる所」が分かるか、実際の作画指示に出ているかを照合する。作画後は掲載寸法で、台詞・擬音を隠しても、誰が何をしたか、各見せ場が次のコマへつながるかを読む。実寸では、重心と手足の接続、接点、表情、効果の方向、受け側の読順を確認する。1ページで勢いが出て絵と話が成立していれば、自然な誇張や効果の形、枠から出る量の自然な違いを生かす。何の動きか見失う、もう一人の見せ場が消える、分身して見える、重要な台詞や接点が隠れる場合は、実害のある箇所と保つ範囲を示して直す。見本は「狙い」と「採用画像で読める動き」を分けて記録する。

### 短い判断例

- 二人が流れ込む紙を止める場面なら、片方は支点を使ってひねりながら紙を返し、もう片方は両手で箱を保持して回転しつつ受け止める。紙の曲線に沿って目を運び、紙と手の接点、箱の口を明瞭に残す。
- どちらか一人に傾いたカメラと放射線を足しただけで、もう一人が立って驚いている場合、後者の派手な動作指定は満たさない。エフェクトを盛る前に、その人自身が結果を変える全身動作を台本へ戻す。
- 対話や余韻が中心で静けさを求められたコマは、表情や間を優先する。アクション用の効果を機械的に使わない。
